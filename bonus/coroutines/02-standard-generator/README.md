# 02. Стандартный генератор последовательности

## Версия C++

Режим сборки — **C++23**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках.

## Что изучаем

Используем готовый владеющий диапазон вместо собственного владельца кадра. Сначала изучите предыдущий урок о времени жизни корутины.

## Примеры

- [main.cpp](main.cpp) — ленивые числа, transform и сохранение; результат `0 2 4`.
- [main2.cpp](main2.cpp) — вложенная последовательность и ошибка во время обхода.

## Как это работает

`std::generator<int>` выдаёт значения по мере обхода. `begin` запускает вычисление до первого `co_yield`, инкремент продолжает его, уничтожение генератора освобождает кадр. В конвейер владеющий генератор передаётся через `std::move`: копировать его нельзя. Для невладеющего доступа к живому генератору подходит `std::ranges::ref_view`. Это однопроходный input range: не начинайте обход второй раз и не храните старые итераторы для независимых проходов. Во втором примере `elements_of` разворачивает вложенный генератор; затем исключение из его тела выходит из обхода и перехватывается вызывающим кодом. Генератор не создаёт поток и сам по себе не означает асинхронность.

## Сборка и запуск

[Настройка компилятора и запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).
Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh bonus/coroutines/02-standard-generator/main.cpp
./build/bonus/coroutines/02-standard-generator/main
```

Для остальных вариантов замените `main.cpp` и имя исполняемого файла. На Windows вызовите `scripts/build-windows.sh` через MSYS2 Bash, затем соответствующий файл `build/bonus/coroutines/02-standard-generator/main.exe`. Готовые `tasks.json` и `launch.json` содержат оба варианта системы.

Ввода, сетевых служб и постоянных файлов не требуется, если ниже не указано другое. Каждый пример проверяет результаты; успех — строка `OK modern-example` и код `0`, ошибка проверки — код `1`.

## Типичные ошибки

Ссылка на выданный элемент может перестать быть пригодной после следующего шага или уничтожения генератора. Для длительного хранения скопируйте значение. Не захватывайте в отложенную корутину ссылки на уже уничтоженные объекты. Нельзя возобновлять завершённую корутину.
