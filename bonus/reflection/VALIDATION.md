## Ограничения этой проверки

Создание симлинка через std::filesystem в проверенной Windows-среде вернуло
Function not implemented. Урок 10 явно сообщил недоступность операции;
создание/копирование/переименование/обход/удаление обычных файлов проверены.
Это не считается подтверждением работоспособности создания симлинков на Windows.

Конфигурации F5 и пути проверены как данные; интерактивный запуск GDB и
возможности парсера редактора отдельно не проверялись. ASan/UBSan-пример
подготовлен для отдельного запуска на Linux/WSL и в этот прогон не входил.

Ubuntu 22.04, системный GCC 11 и сборка/установка GCC 16 на Linux в текущем
окружении не запускались. Подбор возможностей под C++17/20 не заменяет такого
прогона. Все необходимые шаги сохранены в [linux-setup.md](linux-setup.md).

## Повторение

Из корня репозитория:

```bash
python scripts/check-bonuses.py
```

На Linux используйте python3 и CXX_MODERN=/opt/gcc-16/bin/g++ после подготовки.
Для проверки только рефлексии — --section bonus/reflection; для системного
GCC 11 — --portable-only. Последний режим явно пропускает современные уроки.
JSON-отчёт каждого запуска создаётся в build/bonus-checks/report.json;
это локальный сгенерированный файл, он не хранится в Git.
