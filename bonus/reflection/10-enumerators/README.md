# 10. Перечисления и совпадающие значения

## Версия C++

`std::meta`, статическая рефлексия — **C++26**.
`auto`, `constexpr`, `enum class` — **C++11**.
`std::exception` — **C++98**.

Сборка примеров: **C++26**. Это режим проекта,
а не дата появления всех использованных конструкций.
Рефлексия здесь экспериментальная: нужны GCC 16+ и `-freflection`; конкретные требования заданы в файлах сборки.

## Что изучаем

enumerators_of перечисляет объявления элементов, включая разные имена
одинакового значения. По самому runtime-значению невозможно восстановить,
какое из этих имён было написано вызывающим кодом. Наш enum_name выбирает
первое совпадение. Произвольная комбинация битовых флагов также не обязана иметь
отдельный элемент: для неё нужен специальный алгоритм разложения.

Выбирайте один исходник с `main()`; варианты запускаются отдельно.

## Как это работает

Предварительно: Шаблоны, `constexpr`/`consteval` и предыдущие механизмы этого раздела.
Каждый исходник здесь — самостоятельный исполняемый пример.

enumerators_of возвращает **объявления** `ready`, alias, stopped.
Первые два имеют одно числовое значение 1, но разные имена; список содержит
три элемента. template for разворачивает вывод каждого имени и значения.

enum_name получает уже runtime-значение `enum`. По одному числу 1 невозможно
узнать, было ли исходно написано `ready` или alias: helper выбирает первое
совпадение `ready`. Неименованное 99 даёт пустое имя.

Для внешнего формата политику псевдонимов выбирают явно.
Порядок деклараций и их число не равны множеству уникальных чисел.
Флаги с комбинированными битами тоже требуют отдельного форматирования:
простое совпадение с одним enumerator может отсутствовать.

## Сборка и запуск

[Запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).

Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh bonus/reflection/10-enumerators/main.cpp
./build/bonus/reflection/10-enumerators/main
```

На Windows / MSYS2 Bash используйте `scripts/build-windows.sh` и расширение .exe.
Рабочая папка при F5/Ctrl+F5 — папка исходника. Особенности компилятора и зависимостей
описаны в [README раздела](../README.md).

### Результат и проверка

После показанных в коде значений последняя строка — `OK 10-enumerators`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section bonus/reflection`
(на Linux команда Python обычно называется python3).
