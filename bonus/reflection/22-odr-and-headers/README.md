# 22. Заголовки и несколько единиц трансляции

Предварительно: Шаблоны, `constexpr`/`consteval` и предыдущие механизмы этого раздела.
Стандарт и компилятор: GCC 16+ и `c++26`. Каждый исходник здесь — самостоятельный исполняемый пример.

## Что показывает пример

Общие определения отражаемого типа и шаблонов должны быть согласованы
во всех единицах трансляции. Отражение не отменяет ODR, связывание или доступность
определений. Здесь пример собирается из `src/main.cpp` и `src/support.cpp`, которые
включают один заголовок. Inline-функция и общий шаблон не создают дублируемых
обычных определений. Не используйте диагностическую строку имени в качестве
универсального межмодульного идентификатора.

## Разбор кода и границы применения

`src/main.cpp` и `src/support.cpp` включают общий `shared.hpp`.
Оба получают один Shared с двумя полями и согласованный шаблон подсчёта.
Возвращённые числа сравниваются, вывод: fields=2.

Каждый .cpp компилируется в своей единице трансляции. Заголовочная защита
работает внутри неё, а согласованность определений между ними требует ODR.
Рефлексия не отменяет эти обычные правила сборки.

В этом уроке запускают `src/main.cpp`; поддерживающий .cpp добавляет общий
скрипт сборки. Прямая сборка только `main` без support не определит
count_from_other_translation_unit.
Значения диагностических имён не заменяют стабильный межмодульный контракт.

## Запуск

Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh bonus/reflection/22-odr-and-headers/src/main.cpp
./build/bonus/reflection/22-odr-and-headers/src/main
```

На Windows / MSYS2 Bash используйте `scripts/build-windows.sh` и расширение .exe.
F5 — запуск с отладчиком; Ctrl+F5 — без отладчика.

В VS Code открывайте `src/main.cpp` и нажимайте F5/Ctrl+F5: доступны корневая и локальная конфигурации.
Рабочая папка при F5/Ctrl+F5 — папка исходника. Особенности компилятора и зависимостей
описаны в [README раздела](../README.md).

## Результат и проверка

После показанных в коде значений последняя строка — `OK 22-odr-and-headers`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section bonus/reflection`
(на Linux команда Python обычно называется python3).

## Самостоятельно

Измените общее объявление только в заголовке и убедитесь, что обе единицы видят одинаковое количество полей.
