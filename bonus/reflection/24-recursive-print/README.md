# 24. Практика: вывод вложенных структур

## Версия C++

статическая рефлексия — **C++26**.
`concepts/requires` — **C++20**.
`if constexpr` — **C++17**.
обобщённые лямбды — **C++14**.
`auto`, `constexpr`, лямбды — **C++11**.
`std::exception` — **C++98**.

Сборка примеров: **C++26**. Это режим проекта,
а не дата появления всех использованных конструкций.
Рефлексия здесь экспериментальная: нужны GCC 16+ и `-freflection`; конкретные требования заданы в файлах сборки.

## Что изучаем

Рекурсия останавливается на типах, поддерживающих потоковый вывод,
и разворачивает поля остальных поддерживаемых структур. ostream-параметр
позволяет проверять точный результат через `ostringstream`. Формат предназначен
для диагностики, а не обратимого хранения. Циклические графы через указатели,
контейнеры, закрытые и битовые поля требуют отдельных правил и ограничения глубины.

## Как это работает

Предварительно: Шаблоны, `constexpr`/`consteval` и предыдущие механизмы этого раздела.
Каждый исходник здесь — самостоятельный исполняемый пример.

`print_record` сначала проверяет наличие потокового вывода для конкретного `T`.
Для `int` выводится само число, для `Person`/`Address` рекурсивно разворачиваются
поля. `Person`{7, {10}} превращается в {`id=7`,`address`={`zip=10`}}.

ostream& позволяет получить тот же текст в `cout`, файл или `ostringstream`.
В `main` точная строка проверяется до печати — это отделяет формат от терминала.

Граница рекурсии определяется поддерживаемыми типами.
Указатель может выводиться адресом, а не автоматически разыменовываться.
Произвольные графы с циклом требуют отслеживания уже посещённых объектов.
Вывод не является JSON: здесь нет соответствующего экранирования и схемы чтения.

### Результат и проверка

После показанных в коде значений последняя строка — `OK 24-recursive-print`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section bonus/reflection`
(на Linux команда Python обычно называется python3).
