# 18. Отражение шаблонов и подстановка

## Версия C++

`std::meta`, статическая рефлексия — **C++26**.
`auto`, `constexpr` — **C++11**.
`std::exception` — **C++98**.

Сборка примеров: **C++26**. Это режим проекта,
а не дата появления всех использованных конструкций.
Рефлексия здесь экспериментальная: нужны GCC 16+ и `-freflection`; конкретные требования заданы в файлах сборки.

## Что изучаем

`template_of` связывает специализацию с шаблоном, `template_arguments_of`
возвращает его аргументы. `substitute` формирует отражение специализации из
шаблона и отражённых аргументов; `can_substitute` помогает проверять допустимость.
Аргумент-тип и аргумент-значение отражаются по-разному. Это не замена всем
правилам вывода параметров и разрешения перегрузок.

## Примеры

- [main.cpp](main.cpp).

Выбирайте один исходник с `main()`; варианты запускаются отдельно.

## Как это работает

Нужны шаблоны классов, специализация и отражения типов.

В `Box<int>` `template_of` находит `Box`, а `template_arguments_of` — `int`.
`substitute(^^Box, {^^double})` формирует отражение `Box<double>`.
Сплайсинг `typename [:generated:]` создаёт обычную типизированную переменную,
её `value` равно 2.5.

Это не изменение типа уже существующего объекта и не создание runtime-класса.
Аргументы метаподстановки должны быть допустимы для исходного шаблона.
Если возможен отказ, предварительно исследуйте `can_substitute` или
обрабатывайте предусмотренную compile-time-ошибку.

Для параметра-типа используют отражение типа, для параметра-значения —
отражение константы. Эти категории не взаимозаменяемы только потому,
что обе представлены info.

### Результат и проверка

Последняя строка успешного запуска — `OK 18-templates`.
Интерактивного ввода и файловых операций при запуске нет; успех — код `0`.
Ошибка проверки перехватывается: причина выводится в `stderr`, код — `1`.

Проверка всего раздела: `python scripts/check-bonuses.py --section bonus/reflection`
(на Linux команда Python обычно называется python3).

## Типичные ошибки

Отражение шаблона отличается от отражения его специализации. Подстановка должна удовлетворять ограничениям исходного шаблона; она не меняет тип уже созданного объекта.

### Самостоятельно

Добавьте параметр размера массива и передавайте его через `reflect_constant`, предварительно проверяя can_substitute.
