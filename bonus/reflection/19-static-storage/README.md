# 19. Статическое хранение вычисленных данных

## Версия C++

статическая рефлексия — **C++26**.
`std::string_view` — **C++17**.
`auto`, `constexpr` — **C++11**.
`std::vector`, `std::string`, `std::exception` — **C++98**.

Сборка примеров: **C++26**. Это режим проекта,
а не дата появления всех использованных конструкций.
Рефлексия здесь экспериментальная: нужны GCC 16+ и `-freflection`; конкретные требования заданы в файлах сборки.

## Что изучаем

Временные `string`/`vector` могут участвовать в вычислении, но указатель
на уничтоженный временный буфер нельзя вернуть в runtime. `define_static_string`,
define_static_array и define_static_object предоставляют поддерживаемое статическое
хранение для подходящих данных. Возвращённые значения следует считать неизменяемыми;
не используйте равенство адресов как логическую идентичность метаданных.

- [main.cpp](main.cpp).

## Как это работает

Предварительно: Шаблоны, `constexpr`/`consteval` и предыдущие механизмы этого раздела.
Каждый исходник здесь — самостоятельный исполняемый пример.

Конкатенация временных строк формирует generated_name во время компиляции.
`define_static_string` предоставляет сохраняющийся символьный массив,
поэтому `label` пригоден после завершения временных вычислений.
define_static_array аналогично сохраняет 2, 4, 6; размер — 3.

Вывод: generated_name 3. Возврат обычного указателя на `buffer` временного
`vector`/`string` не дал бы такого времени жизни.

Статическое хранение не означает возможность произвольно изменять результат.
Идентичность текста и совпадение адресов — разные свойства:
не используйте возможное объединение хранения как собственную систему id.
Для более сложных константных объектов есть define_static_object.

### Результат и проверка

После показанных в коде значений последняя строка — `OK 19-static-storage`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section bonus/reflection`
(на Linux команда Python обычно называется python3).

## Типичные ошибки

### Самостоятельно

Сформируйте список имён полей при компиляции и сохраните его для runtime-справки без висячих `string_view`.
