# 17. Размеры, выравнивание и смещения

Предварительно: Шаблоны, `constexpr`/`consteval` и предыдущие механизмы этого раздела.
Стандарт и компилятор: GCC 16+ и `c++26`. Каждый исходник здесь — самостоятельный исполняемый пример.

## Что показывает пример

size_of, alignment_of и offset_of описывают фактическое размещение
для текущей реализации. member_offset содержит отдельно байты и биты.
Пример использует standard-layout-структуру и сравнивает с обычными sizeof,
alignof, offsetof. Padding, ABI и порядок байтов остаются зависимыми от платформы;
эти сведения не превращают дамп памяти в переносимый формат. Для битовых полей
нужны отдельные bit_size_of и битовое смещение, а не указатель на поле.

## Разбор кода и границы применения

`Layout` содержит `char tag` и `int value`. Между ними может быть padding,
поэтому смещение `value` не обязано быть 1, а размер `Layout` — суммой размеров полей.
Пример сравнивает meta-запросы с обычными sizeof/alignof/offsetof.

Числа вывода зависят от ABI и платформы; проверяется согласованность,
а не жёстко заданное смещение. member_offset включает байтовую и битовую часть.

Порядок байтов, padding и представление значений — разные свойства.
Даже точное знание текущего layout не задаёт переносимый файловый формат.
Для битовых полей нельзя получить обычный указатель на член-объект;
нужны соответствующие запросы и правила доступа.

## Запуск

Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh bonus/reflection/17-layout/main.cpp
./build/bonus/reflection/17-layout/main
```

На Windows / MSYS2 Bash используйте `scripts/build-windows.sh` и расширение .exe.
F5 — запуск с отладчиком; Ctrl+F5 — без отладчика.

В VS Code открывайте `main.cpp` и нажимайте F5/Ctrl+F5: доступны корневая и локальная конфигурации.
Рабочая папка при F5/Ctrl+F5 — папка исходника. Особенности компилятора и зависимостей
описаны в [README раздела](../README.md).

## Результат и проверка

После показанных в коде значений последняя строка — `OK 17-layout`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section bonus/reflection`
(на Linux команда Python обычно называется python3).
