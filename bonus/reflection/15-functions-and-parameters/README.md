# 15. Функции, параметры и вызовы

## Версия C++

`std::meta`, статическая рефлексия — **C++26**.
`auto`, `constexpr`, `noexcept` — **C++11**.
`std::exception` — **C++98**.

Сборка примеров: **C++26**. Это режим проекта,
а не дата появления всех использованных конструкций.
Рефлексия здесь экспериментальная: нужны GCC 16+ и `-freflection`; конкретные требования заданы в файлах сборки.

## Что изучаем

Отражение объявления функции позволяет исследовать возвращаемый тип,
параметры, default arguments и `noexcept`. Сплайсер именует конкретную функцию,
после чего действуют обычные правила вызова. Перегруженное имя требует выбора
конкретной перегрузки. Имена параметров могут отсутствовать; наличие метаданных
не означает возможности исполнять произвольный runtime-набор аргументов без типизации.

`main2.cpp` выбирает `int`-перегрузку через типизированный указатель и получает
отражение конкретной функции через `reflect_function`. Её сплайсинг даёт обычный
вызов с проверяемыми компилятором аргументами.

## Примеры

- [main.cpp](main.cpp).
- [main2.cpp](main2.cpp).

Выбирайте один исходник с `main()`; варианты запускаются отдельно.

## Как это работает

Предварительно: Шаблоны, `constexpr`/`consteval` и предыдущие механизмы этого раздела.
Каждый исходник здесь — самостоятельный исполняемый пример.

Отражение `scale` показывает возвращаемый `int`, `noexcept` и два параметра.
Значение `factor` по умолчанию не уменьшает число объявленных параметров.
Вызов `[:function:](3, 4)` использует оба явных аргумента и получает 12.

main2 имеет две `operation`. Типизированный указатель `int(*)`(`int`) выбирает
одну перегрузку, `reflect_function` получает именно её. Сплайсинг вызова с 3
даёт 4. Набор перегрузок и одна выбранная функция — разные исходные данные.

Типы аргументов и результат всё ещё проверяет компилятор.
Метаданные не превращают произвольный список строк в корректный вызов;
runtime-преобразование, значения по умолчанию и диагностика входа
нужны на отдельном уровне интерфейса.

## Сборка и запуск

[Запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).

Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh bonus/reflection/15-functions-and-parameters/main.cpp
./build/bonus/reflection/15-functions-and-parameters/main
```

На Windows / MSYS2 Bash используйте `scripts/build-windows.sh` и расширение .exe.
Рабочая папка при F5/Ctrl+F5 — папка исходника. Особенности компилятора и зависимостей
описаны в [README раздела](../README.md).

### Результат и проверка

После показанных в коде значений последняя строка — `OK 15-functions-and-parameters`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section bonus/reflection`
(на Linux команда Python обычно называется python3).

## Типичные ошибки

### Самостоятельно

Добавьте неназванный параметр и проверяйте has_identifier перед выводом. Отдельно исследуйте метод с `const`-квалификатором.
