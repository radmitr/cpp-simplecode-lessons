# 01. Интроспекция, метаданные и время выполнения

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Стандарт и компилятор: c++17. Каждый исходник здесь — самостоятельный исполняемый пример.

## Что показывает пример

Интроспекция отвечает на вопросы о типе; метаданные описывают сущности;
генерация кода использует эти сведения для построения операций. Здесь имя поля
и указатель на него заданы вручную. Проверка свойства типа выполняется компилятором,
а чтение значения id происходит при запуске. До C++26 стандарт не предоставлял
универсального обхода именованных полей произвольной структуры. RTTI, traits,
ручные описатели и встроенная рефлексия решают разные части задачи.

## Запуск

Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh bonus/reflection/01-introspection-overview/main.cpp
./build/bonus/reflection/01-introspection-overview/main
```

На Windows / MSYS2 Bash используйте scripts/build-windows.sh и расширение .exe.
В VS Code открывайте main.cpp и нажимайте F5: доступны корневая и локальная конфигурации.
Рабочая папка F5 — папка исходника. Особенности компилятора и зависимостей
описаны в [README раздела](../README.md).

## Результат и проверка

После показанных в коде значений последняя строка — `OK 01-introspection-overview`.
Проверки check(...) выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с NDEBUG.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section bonus/reflection`
(на Linux команда Python обычно называется python3).
