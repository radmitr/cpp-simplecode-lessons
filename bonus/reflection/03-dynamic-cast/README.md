# 03. Проверяемые преобразования `dynamic_cast`

## Версия C++

`nullptr` — **C++11**.
`std::exception`, `std::bad_cast` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Неудачное преобразование указателя возвращает `nullptr`, ссылки — выбрасывает
bad_cast. Пример использует полиморфную базу и открытое наследование. Повышающее
преобразование к доступной однозначной базе обычно не требует `dynamic_cast`.
Понижающие и перекрёстные преобразования зависят от реального объекта и графа
наследования. Это проверка отношения типов при запуске, а не получение метаданных полей.

## Примеры

- [main.cpp](main.cpp).

Выбирайте один исходник с `main()`; варианты запускаются отдельно.

## Как это работает

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Каждый исходник здесь — самостоятельный исполняемый пример.

`pointer` действительно обозначает `Derived`, поэтому downcast возвращает
адрес исходного `object`. `otherPointer` обозначает `Other`: попытка получить
`Derived*` возвращает `nullptr`, а `Derived&` — бросает bad_cast.

~~~cpp
if (auto* value = dynamic_cast<Derived*>(base)) {
    // Проверенный доступ к нужному производному типу.
}
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Для такого runtime-downcast база полиморфна. `nullptr`-результат проверяют
до использования; `static_cast` не добавляет эту динамическую проверку.
`dynamic_cast` не создаёт копию и не передаёт владение. Сложное множественное
наследование также требует подходящей доступной и однозначной структуры баз.

### Результат и проверка

После показанных в коде значений последняя строка — `OK 03-dynamic-cast`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section bonus/reflection`
(на Linux команда Python обычно называется python3).
