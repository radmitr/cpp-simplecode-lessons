# 13. Переподключение, backoff и отмена

C++17. Windows: MinGW64; Linux: POSIX.

Сервер начинает слушать только через 700 мс после запуска.
Клиент создаёт новый сокет при каждой попытке подключения.

В retry.hpp реализованы:

- не более шести попыток;
- сетевой дедлайн каждой попытки 100 мс;
- паузы 100, 200, 400, 800, 800 мс;
- отменяемая пауза через condition_variable, без постоянной проверки в цикле.

Пауза растёт экспоненциально до ограничения. В большом приложении обычно
добавляют случайный разброс (jitter), чтобы многие клиенты не повторяли
подключение одновременно. В этом небольшом примере паузы фиксированы.

Соберите программы заранее. Чтобы увидеть повторные попытки, запустите
клиент первым и сразу после него сервер во втором терминале.
Если сервер уже готов, первая попытка закономерно может быть успешной.
После исчерпания попыток клиент заканчивает работу с ошибкой — запустите его снова.

Для демонстрации отмены запускайте без сервера:

~~~text
client 42013 --cancel
~~~

Через 150 мс другой поток запросит отмену. Результат:

~~~text
Retry cancelled
~~~

RetryControl хранит флаг под mutex и вызывает notify_all().
wait_for() с предикатом проснётся при отмене, даже если запрос пришёл раньше.
Уже начатый connect() не прерывается этим флагом: его ограничивает короткий
сетевой дедлайн. Отмена относится к повторным подключениям, не к последующему обмену.

std::future от launch::async дожидается потока отмены до уничтожения control.
После подключения клиент отправляет одну строку и проверяет echo.
Повторная отправка изменяющих состояние команд требует отдельной политики:
это тема урока 15.

## Сборка и запуск

Команды выполняются из корня проекта. Порт по умолчанию — 42013.
Сначала соберите обе программы.

Linux:

~~~bash
bash scripts/build-linux.sh bonus/networking/lesson-13-reconnect/server.cpp
bash scripts/build-linux.sh bonus/networking/lesson-13-reconnect/client.cpp
~~~

В первом терминале:

~~~bash
./build/bonus/networking/lesson-13-reconnect/server
~~~

Во втором терминале после Listening:

~~~bash
./build/bonus/networking/lesson-13-reconnect/client
~~~

Windows, PowerShell:

~~~powershell
& C:\msys64\usr\bin\bash.exe scripts/build-windows.sh bonus/networking/lesson-13-reconnect/server.cpp
& C:\msys64\usr\bin\bash.exe scripts/build-windows.sh bonus/networking/lesson-13-reconnect/client.cpp
~~~

В первом терминале:

~~~powershell
& .\build\bonus\networking\lesson-13-reconnect\server.exe
~~~

Во втором терминале после Listening:

~~~powershell
& .\build\bonus\networking\lesson-13-reconnect\client.exe
~~~

Этот обычный запуск проверяет соединение с готовым сервером.
Для наблюдения повторов поменяйте порядок: сначала клиент, затем сразу сервер.
Соберите оба исходника до запуска; попытки ограничены по времени.

При открытии папки урока в VS Code используйте Networking: Run server,
затем Networking: Run client. Задачи соберут нужные исходники и запустят их
в разных терминалах. Для отладки клиента оставьте сервер в терминале
и нажмите F5 на client.cpp. Дополнительные аргументы можно передавать из терминала.
После добавления исходников обновите C/C++: Update IntelliSense.
