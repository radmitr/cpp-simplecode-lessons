# 02. Таблицы, столбцы и типы

C++17 · PostgreSQL · libpq · Windows/MinGW64 и Linux.

SQL-команда CREATE TABLE описывает структуру данных. Одна строка таблицы —
один товар; столбцы хранят его свойства.

- bigint — целое число; GENERATED ALWAYS AS IDENTITY генерирует id.
  Уникальность гарантирует PRIMARY KEY, а не сама IDENTITY.
- text — текст; NOT NULL запрещает отсутствие значения.
- numeric(10, 2) хранит точное десятичное число: всего до 10 цифр, две после точки.
  Это полезно для сумм, когда округление двоичной плавающей точки нежелательно.
- boolean — true/false; DEFAULT true применяется, если столбец пропущен.
- timestamptz хранит момент времени; отображение зависит от часового пояса сеанса.
  now() возвращает время начала текущей транзакции.

Результат:

~~~text
1 | Notebook | 12.50 | t
~~~

CREATE TEMP TABLE создаёт временную таблицу только для этого соединения.
После его закрытия таблица исчезает; следующий запуск начинает с чистых данных.
Обычная CREATE TABLE сохраняет таблицу в базе между подключениями.
Несколько постоянных таблиц можно объединить схемой — пространством имён.

[Типы данных](https://www.postgresql.org/docs/current/datatype.html).

## Сборка и запуск

Сначала [установите зависимости и запустите учебный сервер](../README.md).
Команды из корня репозитория собирают main.cpp и запускают результат.

Linux / MSYS2 MinGW64:

~~~bash
bash bonus/databases/postgresql/scripts/run.sh 02
~~~

Windows PowerShell:

~~~powershell
& C:\msys64\usr\bin\bash.exe bonus/databases/postgresql/scripts/run.sh 02
~~~

В VS Code откройте main.cpp и нажмите F5. Сервер должен быть запущен заранее.
