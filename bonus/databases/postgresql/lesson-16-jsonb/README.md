# 16. JSONB

C++17 · PostgreSQL · libpq · Windows/MinGW64 и Linux.

JSONB хранит JSON в разобранном двоичном представлении PostgreSQL.
Он полезен для гибких дополнительных свойств, когда фиксированные поля
таблицы не покрывают все варианты.

Документ передаётся параметром $2::jsonb, поэтому сервер проверяет его синтаксис.
Выборка и изменение выполняются средствами SQL:

- settings->'name' возвращает JSON.
- settings->>'name' возвращает текст.
- @> проверяет содержание JSON-фрагмента.
- jsonb_set заменяет значение по пути {threshold}.

~~~text
sensor | 25
Threshold: 30
~~~

JSONB не сохраняет исходное форматирование и порядок ключей;
при повторении ключа сохраняется последнее значение.
Не используйте порядок сериализованных ключей как часть проверки равенства.

Важные связи и обязательные поля обычно проще выразить обычными столбцами,
внешними ключами и CHECK. Для частого поиска внутри JSONB можно изучить
GIN-индекс; выбор индекса зависит от операторов запроса.

[JSON-типы](https://www.postgresql.org/docs/current/datatype-json.html).

## Сборка и запуск

Сначала [установите зависимости и запустите учебный сервер](../README.md).
Команды из корня репозитория собирают main.cpp и запускают результат.

Linux / MSYS2 MinGW64:

~~~bash
bash bonus/databases/postgresql/scripts/run.sh 16
~~~

Windows PowerShell:

~~~powershell
& C:\msys64\usr\bin\bash.exe bonus/databases/postgresql/scripts/run.sh 16
~~~

В VS Code откройте main.cpp и нажмите F5. Сервер должен быть запущен заранее.
