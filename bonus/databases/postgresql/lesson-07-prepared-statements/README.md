# 07. Подготовленные запросы

C++17 · PostgreSQL · libpq · Windows/MinGW64 и Linux.

PQprepare создаёт на сервере именованный запрос find_product.
PQexecPrepared выполняет его несколько раз с разными значениями $1.

~~~text
1: Pen
2: Book
~~~

Параметры по-прежнему передаются отдельно от SQL. Подготовка и выполнение —
разные вызовы: сначала текст запроса и имя, затем имя и значения.

Именованный prepared statement принадлежит соединению: другое соединение
его не видит. После переподключения подготовку нужно повторить.
DEALLOCATE удаляет подготовленный запрос; закрытие соединения тоже его освобождает.

PQexecParams удобен для отдельного вызова. Подготовка полезна для многократного
исполнения одной формы запроса, но не гарантирует ускорения каждого запроса:
сервер может выбирать общий или специализированный план.
Параметризация нужна для корректности независимо от выигрыша в скорости.

[libpq: PQprepare / PQexecPrepared](https://www.postgresql.org/docs/current/libpq-exec.html).

## Сборка и запуск

Сначала [установите зависимости и запустите учебный сервер](../README.md).
Команды из корня репозитория собирают main.cpp и запускают результат.

Linux / MSYS2 MinGW64:

~~~bash
bash bonus/databases/postgresql/scripts/run.sh 07
~~~

Windows PowerShell:

~~~powershell
& C:\msys64\usr\bin\bash.exe bonus/databases/postgresql/scripts/run.sh 07
~~~

В VS Code откройте main.cpp и нажмите F5. Сервер должен быть запущен заранее.
