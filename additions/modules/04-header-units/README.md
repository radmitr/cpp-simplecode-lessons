# 04. Header units и макросы

## Версия C++

C++20 — режим сборки; механизмы и даты их появления указаны в исходниках. Учебный компилятор — GCC 16+.

## Что изучаем

Сравниваем импорт заголовочной единицы и именованный модуль. Нужны обычные заголовки и CMI.

## Примеры

- [main.cpp](main.cpp) импортирует заголовочную единицу.
- [settings.hpp](settings.hpp) компилируется заранее; содержит макрос и inline-функцию.

## Как это работает

Скрипт сначала компилирует `settings.hpp` с `-x c++-header -fmodules`, затем
импортёр. У header unit нет отдельного объектного файла в этой конфигурации;
CMI располагается в приватном `gcm.cache` урока. `import "settings.hpp";`
находит предварительно собранный заголовок по тому же разрешённому пути.

Прямой импорт header unit делает доступными объявления заголовка и его макросы:
`DEMO_FACTOR` равен `3`, `scaled(7)` возвращает `21`. Именованный модуль не передаёт
макросы таким образом. Макрос, заданный у импортёра перед импортом, не меняет уже
скомпилированное содержимое header unit: варианты настройки требуют согласованной
пересборки. Include guard здесь сохраняет обычную пригодность заголовка для `#include`.

`header-units.txt` допускает только имена локальных `.h`/`.hpp` без каталогов.
Это явное описание подготовки, а не попытка автоматически превратить каждый
системный заголовок в модуль. Header units полезны при переходе со старых заголовков,
но не каждый сторонний заголовок пригоден к такому импорту.

## Сборка и запуск

Из корня проекта:

```bash
bash scripts/build-linux.sh additions/modules/04-header-units/main.cpp
./build/additions/modules/04-header-units/main
```

На Windows используйте `scripts/build-windows.sh` через MSYS2 Bash и файл `.exe`.
[Настройка F5/Ctrl+F5](../../../README.md#сборка-и-запуск-в-vs-code).
Внешние службы и интерактивный ввод не нужны, если ниже не оговорено иное.
Успех — `OK reference-example` и код `0`; ошибка проверки — код `1`.

## Типичные ошибки

Не импортировать заголовок до подготовки его CMI. Не считать header unit именованным модулем с `export module`. Не рассчитывать на настройку его содержимого макросами импортёра.
