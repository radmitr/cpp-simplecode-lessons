# 03. Разделы модуля и global module fragment

## Версия C++

C++20 — режим сборки; механизмы и даты их появления указаны в исходниках. Учебный компилятор — GCC 16+.

## Что изучаем

Разделяем интерфейс и внутренний код одного модуля. Нужны повторный экспорт и раздельная компиляция.

## Примеры

- [main.cpp](main.cpp) использует прямоугольник.
- [types.cppm](types.cppm) — интерфейсный раздел.
- [details.cppm](details.cppm) — раздел реализации и заголовок в global module fragment.
- [geometry.cppm](geometry.cppm) — первичный интерфейс.
- [implementation.cpp](implementation.cpp) — реализация публичных функций.

## Как это работает

`geometry:types` — раздел того же модуля `geometry`, а не самостоятельный модуль.
Первичный интерфейс повторно экспортирует его через `export import :types;`.
Пользователь импортирует `geometry`, получает `Rectangle`, `area` и `border`.
Внутренний раздел `:details` импортируется единицей реализации; внешний пользователь
не должен импортировать его напрямую. Имена разделов действуют внутри своего модуля.

В `details.cppm` строка `module;` открывает global module fragment. Следующий
`#include <algorithm>` обрабатывается в глобальном модуле, до `module geometry:details;`.
Это позволяет использовать обычный заголовок для реализации без текстового
подключения его объявлений в область именованного модуля. Макросы, необходимые
заголовку, задают перед соответствующим `#include`, а не после `import`.

Порядок manifest: разделы → первичный интерфейс → реализация → импортёр.
Для `3×4` выводятся `12 14`. Учебные значения малы; пример не является библиотекой
с проверкой любого переполнения размеров.

GCC документирует неполноту правил видимости разделов реализации. Поэтому успех
сборки не доказывает полноценную изоляцию во всех пограничных случаях.
Private module fragment (`module :private;`) — отдельный механизм; установленный
GCC его не поддерживает, и пример не выдаёт его за проверенный сценарий.

## Сборка и запуск

Из корня проекта:

```bash
bash scripts/build-linux.sh additions/modules/03-partitions-and-global-fragment/main.cpp
./build/additions/modules/03-partitions-and-global-fragment/main
```

На Windows используйте `scripts/build-windows.sh` через MSYS2 Bash и файл `.exe`.
[Настройка F5/Ctrl+F5](../../../README.md#сборка-и-запуск-в-vs-code).
Внешние службы и интерактивный ввод не нужны, если ниже не оговорено иное.
Успех — `OK reference-example` и код `0`; ошибка проверки — код `1`.

## Типичные ошибки

Не экспортировать раздел реализации и не импортировать `geometry:types` извне как отдельный публичный модуль. Не путать global module fragment с namespace или private module fragment.
