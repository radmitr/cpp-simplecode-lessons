# 06. Кооперативная отмена корутины

## Версия C++

C++20 — режим сборки; механизмы и даты их появления указаны в исходниках. Учебный компилятор — GCC 16+.

## Что изучаем

Разделяем запрос остановки, возобновление и освобождение кадра. Нужны RAII и `stop_token`.

## Примеры

- [main.cpp](main.cpp) — самостоятельный пример; успешное завершение — код `0`.

## Как это работает

Первый `resume()` увеличивает `steps` до `1` и приостанавливает задачу. `Guard`
ещё жив внутри кадра. `request_stop()` устанавливает запрос; второй такой вызов
возвращает `false`. Сам запрос не вызывает `resume()` и не уничтожает кадр.
Следующее явное возобновление проверяет token, выходит из цикла, уничтожает Guard
и возвращает `1`.

Во второй области задача приостанавливается после ещё одного шага. Деструктор
владельца уничтожает её кадр: Guard освобождает ресурс, но код после ожидания
не выполняется. Уничтожение приостановленной корутины и кооперативное нормальное
завершение — разные действия. Итоговые счётчики — `steps=2 cleaned=2`.

Для реального асинхронного ввода требуется также отменить регистрацию ожидания
или дождаться её завершения. Пока внешний источник хранит handle, нельзя просто
уничтожить кадр: позднее событие могло бы вызвать `resume()` по мёртвому адресу.
Этот пример использует только ручное ожидание и поэтому не обещает универсальной
отмены таймеров/сокетов. Межпоточное управление показано отдельно.

## Сборка и запуск

Из корня проекта:

```bash
bash scripts/build-linux.sh additions/coroutines/06-cooperative-cancellation/main.cpp
./build/additions/coroutines/06-cooperative-cancellation/main
```

На Windows используйте `scripts/build-windows.sh` через MSYS2 Bash и файл `.exe`.
[Настройка F5/Ctrl+F5](../../../README.md#сборка-и-запуск-в-vs-code).
Внешние службы и интерактивный ввод не нужны, если ниже не оговорено иное.
Успех — `OK reference-example` и код `0`; ошибка проверки — код `1`.

## Типичные ошибки

Не считать `stop_token` принудительным прерыванием. Не вызывать `destroy()` у исполняющегося кадра и не оставлять handle уничтоженного кадра во внешней очереди.
