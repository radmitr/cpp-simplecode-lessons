# 01. Корутина, приостановка и владение кадром

## Версия C++

Режим сборки — **C++20**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках.

## Что изучаем

Пошагово получаем числа из функции, которую можно приостанавливать. Нужны RAII, перемещение и исключения.

## Примеры

- [main.cpp](main.cpp) — ленивое начало, два значения, конец и перемещение владельца.
- [main2.cpp](main2.cpp) — досрочное освобождение и перенос исключения вызывающему коду.

## Как это работает

Кадр корутины — память, в которой сохраняются её параметры, локальные объекты
и точка продолжения. `promise_type` задаёт правила выдачи значений, приостановки
и обработки исключений; это часть протокола корутин, отдельная от `std::promise`.

Вызов `numbers()` создаёт объект корутины; из-за `initial_suspend` тело ещё не выполняется. `next()` возобновляет его, `co_yield` сохраняет число и приостанавливает выполнение, после чего вызывающий код читает `value()`. На следующем `next()` исполнение продолжается после `co_yield`. `final_suspend` оставляет завершённый кадр для владельца; деструктор `Sequence` вызывает `destroy()` и освобождает кадр. Досрочное уничтожение тоже уничтожает локальные объекты корутины. `unhandled_exception` сохраняет исключение, а `next` повторно выбрасывает его в вызывающем коде. Все действия происходят в одном потоке; асинхронный запуск здесь отсутствует.

## Типичные ошибки

Handle не является автоматически владеющим указателем: владелец должен быть один. Конструктор перемещения передаёт кадр, присваивание перемещением сначала уничтожает прежний кадр; копирование запрещено. После `done()` возобновление запрещено; обёртка проверяет это. Значение разрешено читать только после успешного `next()`. Нельзя уничтожать кадр, пока другой поток выполняет его. Аргументы-ссылки и захваты могут пережить свои исходные объекты, поэтому входные данные примера передаются по значению.
