# 03. Значение, ошибка и остановка

## Версия C++

C++26 — режим сборки; механизмы и даты их появления указаны в исходниках. Учебный компилятор — GCC 16+.

## Что изучаем

Проверяем три альтернативы завершения и преобразование ошибки/остановки в обычное значение.

## Примеры

- [main.cpp](main.cpp) — самостоятельный пример; успешное завершение — код `0`.

## Как это работает

Один запуск заканчивается через `set_value`, `set_error` либо `set_stopped`.
`sync_wait(just(7))` даёт непустой `optional<tuple<int>>`; значение находится в tuple.
Пустой optional означает остановку, а не значение `0`. Sender без значений
возвращает tuple без элементов, что также отличается от остановки.

`upon_error` обрабатывает канал ошибки: код `5` становится обычным значением `8`.
`upon_stopped` аналогично возвращает запасное `9`. Не каждый канал проходит через
обычный `then`: он вызывается для успешного значения. Ошибка из `then` преобразуется
в ошибочное завершение, и `sync_wait` повторно бросает исключение в вызывающем потоке.

Остановка — отдельный результат протокола, а не обязательное исключение и не
принудительное убийство потока. Для `sync_wait` используется `MaybeValue{true, 0}` из [common.hpp](../common.hpp):
тип объявляет и значение, и остановку, но этот запуск выбирает остановку.
Сам `sync_wait` требует ровно один вариант успешного завершения в сигнатурах;
передать ему один `just_stopped()` без такого варианта нельзя.
`just_stopped()` ниже проходит через `upon_stopped`, добавляющий успешное значение.
Реальная операция с token должна самостоятельно учитывать запрос отмены и закончить
согласованным способом. Обработчик ошибки может продолжить работу, но необработанное
исключение нельзя игнорировать, принимая отсутствие значения за успех.


По умолчанию проверяется стандартный API. При его отсутствии код `77` означает пропуск.
Для работающего внешнего профиля сначала выполните `python3 scripts/prepare-reference-libraries.py`,
затем добавьте `REFERENCE_LIBRARIES=1` перед командой сборки.
[Версии, зависимости и различия профилей](../reference-libraries.md).

## Сборка и запуск

Из корня проекта:

```bash
bash scripts/build-linux.sh additions/execution/03-completion-channels/main.cpp
./build/additions/execution/03-completion-channels/main
```

На Windows используйте `scripts/build-windows.sh` через MSYS2 Bash и файл `.exe`.
[Настройка F5/Ctrl+F5](../../../README.md#сборка-и-запуск-в-vs-code).
Внешние службы и интерактивный ввод не нужны, если ниже не оговорено иное.
Успех — `OK reference-example` и код `0`; ошибка проверки — код `1`.

## Типичные ошибки

Не вызывать `.value()`/`get<0>` до проверки optional. Не считать `upon_error` обработчиком остановки. Не путать остановку с завершением операции без полезных значений.
