# 06. Компилятор, заголовок meta и проверка возможностей

## Версия C++

`std::meta`, статическая рефлексия — **C++26**.
`std::exception` — **C++98**.

Сборка примеров: **C++26**. Это режим проекта,
а не дата появления всех использованных конструкций.
Рефлексия здесь экспериментальная: нужны GCC 16+ и `-freflection`; конкретные требования заданы в файлах сборки.

## Что изучаем

`cxx-standard.txt` выбирает C++26, общий скрипт добавляет `-freflection`
и проверяет GCC 16+. `common/reflection.hpp` останавливает неподходящую сборку
через feature-test macro. На Windows используется MinGW64; на Linux по умолчанию
`/opt/gcc/16/bin/g++`, переопределяемый `CXX_MODERN`.
[Установка GCC на Ubuntu](../linux-setup.md).
Наличие флага `-std=c++26` у старого GCC само по себе не означает поддержку рефлексии.

## Примеры

- [main.cpp](main.cpp).

Выбирайте один исходник с `main()`; варианты запускаются отдельно.

## Как это работает

Нужны режимы компилятора, feature-test-макросы и `static_assert`.

Проверка feature-test macro выполняется до runtime.
Наличие заголовка meta и флаг `-std=c++26` по отдельности ещё не доказывают,
что нужная часть рефлексии реализована; пример проверяет минимальный порог
`__cpp_impl_reflection` и реальный запрос `is_type(^^int)`.

В GCC проекта дополнительно включается `-freflection`. Флаг задаётся
метаданными сборки рядом с исходником; F5/Ctrl+F5 использует общий скрипт.
Успешный запуск печатает reflection enabled и номер major GCC.

Ошибка на ^^ или `template for` часто означает неподходящий компилятор/флаги.
Не исправляйте новый синтаксис случайной заменой на ^: это другой оператор.
Требования к компилятору и зависимостям описаны в
[подготовке окружения](../dependencies.md).

## Сборка и запуск

[Запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).

Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh additions/reflection/06-toolchain/main.cpp
./build/additions/reflection/06-toolchain/main
```

На Windows / MSYS2 Bash используйте `scripts/build-windows.sh` и расширение `.exe`.
Рабочая папка при F5/Ctrl+F5 — папка исходника. Особенности компилятора и зависимостей
описаны в [README раздела](../README.md).

### Результат и проверка

Последняя строка успешного запуска — `OK 06-toolchain`.
Интерактивного ввода и файловых операций при запуске нет; успех — код `0`.
Ошибка проверки перехватывается: причина выводится в `stderr`, код — `1`.

Проверка всего раздела: `python scripts/check-additions.py --section additions/reflection`
(на Linux команда Python обычно называется python3).

## Типичные ошибки

Наличие `<meta>` отдельно от нужного флага и feature-test-макроса не подтверждает поддержку. Параметры IntelliSense и реальной сборки проверяйте раздельно.

### Самостоятельно

Запустите сборку со старым `CXX_MODERN` и проверьте понятную ошибку выбора версии.
