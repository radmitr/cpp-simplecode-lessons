# 04. Лямбда в потоке

В `main.cpp` лямбда захватывает `result` по ссылке: `[&result]`.
Новый поток вызывает `sum(2, 5)` и записывает полученное число в `result`.

Главный поток выполняет свой цикл, затем вызывает `t.join()`
и только после этого читает `result`. Результат: `sum` `result`: 7.

Закомментированные варианты показывают обычный вызов `sum`,
прямой запуск `sum` через `thread` и запуск заранее сохранённой лямбды.
`std::thread` не сохраняет возвращаемое значение функции.
Выбирайте один вариант за раз, учитывая объявление `result` и ожидание потока.

Альтернативный способ получения результата: [future и async](../bonus/05-future-async/).

## Разбор лямбды

~~~cpp
std::thread t([&result]() {
    result = sum(2, 5);
});
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

`[&result]` хранит ссылку на внешнюю переменную. () означает отсутствие
параметров лямбды, тело вызывает `sum` и записывает её `return`.
Сам объект лямбды передаётся в `thread` как обычный вызываемый объект.

При [`result`] сохранялась бы копия. Для её изменения потребовалось бы mutable,
но исходный `result` всё равно не получил бы значение.
Здесь `result` изначально не инициализирован: это допустимо только потому,
что перед первым чтением работник записывает 7 и `main` ждёт его через `join`.

`auto` f = [...] сохраняет ту же лямбду под именем; `thread t(f)` запускает её.
Прямой `thread t(sum, 2, 5)` не предоставляет доступа к возвращённым 7.
Для получения результата без внешней переменной есть `async`/`future`.
Захват по ссылке подходит только при обеспеченном времени жизни `result`.
