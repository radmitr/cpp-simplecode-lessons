# 02. Аргументы потока

## Версия C++

`std::thread`, `std::chrono` — **C++11**.
`std::string`, `std::size_t` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

`main.cpp` передаёт функции `doWork` аргументы 2, 3 и строку our_message.
Рабочий поток выводит строку, вычисляет 2 + 3 и завершается примерно через 11 секунд.

## Примеры

- [main.cpp](main.cpp).

Выбирайте один исходник с `main()`; варианты запускаются отдельно.

## Как это работает

Главный поток каждые 500 мс печатает счётчик в бесконечном цикле.
Поэтому программа сама не завершается и до `th.join()` не доходит.
Остановите её через Ctrl+C или остановку отладки.

Для эксперимента замените `true` в условии цикла на i < 25:
цикл закончится, после чего `join()` дождётся потока.

### Что передаётся и когда

~~~cpp
std::thread th(doWork, 2, 3, "our_message");
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

`doWork` — вызываемая функция, 2 передаётся `a`, 3 — `b`, строка — msg.
Это описание будущего вызова `doWork(2, 3, "our_message")` в новом потоке.
Сами аргументы `std::thread` обычно сохраняет по значению.
Строковый параметр `doWork` имеет тип `std::string` и получает текст сообщения.

`doWork` сначала печатает msg, через паузу — STARTED, затем сумму 5,
после следующей паузы — STOPPED. Название STARTED в выводе обозначает
выбранную автором точку функции, а не фактический момент создания потока.

После STOPPED рабочий поток завершён, но `main` продолжает бесконечный цикл.
`join` ниже цикла не может сработать, потому что до него не доходит управление.
Изменение числа аргументов или `sleep_for` не исправляет условие `true`.
Ctrl+C прекращает опыт; это не демонстрация корректного штатного shutdown.
