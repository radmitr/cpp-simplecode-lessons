# 02. Аргументы потока

main.cpp передаёт функции doWork аргументы 2, 3 и строку our_message.
Рабочий поток выводит строку, вычисляет 2 + 3 и завершается примерно через 11 секунд.

Главный поток каждые 500 мс печатает счётчик в бесконечном цикле.
Поэтому программа сама не завершается и до th.join() не доходит.
Остановите её через Ctrl+C или остановку отладки.

Для эксперимента замените true в условии цикла на i < 25:
цикл закончится, после чего join() дождётся потока.
