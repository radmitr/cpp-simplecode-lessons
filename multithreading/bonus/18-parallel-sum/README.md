# 18. Число потоков и время вычисления

C++17. Программа суммирует один и тот же массив из 4000000 чисел:

- последовательно в главном потоке;
- двумя новыми потоками;
- четырьмя новыми потоками.

Каждый способ выполняется три раза, выводится среднее время.
Все варианты обязаны получить 1998000000. Порядок сравнения фиксирован.

## Как разделена работа

Для каждого работника вычисляется непересекающийся диапазон [begin, end).
Исходный массив во время подсчёта не изменяется.
Каждый поток записывает сумму в свой элемент partial; это разные объекты,
поэтому mutex для их записей не нужен. Главный поток суммирует partial
только после всех join().

Время параллельных вариантов включает создание и завершение потоков,
а также выделение вспомогательных контейнеров.
Создание исходного массива не входит в измеряемый интервал.
Используется steady_clock, не зависящий от перевода системных часов.

## Почему больше потоков не обязательно быстрее

Нужно учитывать накладные расходы, пропускную способность памяти,
кэш, нагрузку системы и доступное процессорное время.
hardware_concurrency() — лишь подсказка, иногда равная нулю.
Программа не требует ускорения: проверяется только правильность суммы.

Это учебное измерение, а не воспроизводимый научный бенчмарк:
нет изоляции процессов, случайного порядка прогонов или статистики разброса.

## Оптимизация при сборке

F5 и общие скрипты проекта используют -O0 для удобства отладки.
Не делайте выводы о производительности оптимизированного C++ по этим числам.
Для отдельного сравнения соберите с -O2. Из корня репозитория на Linux:

~~~bash
mkdir -p build/multithreading/bonus/18-parallel-sum
g++ -std=c++17 -O2 -pthread multithreading/bonus/18-parallel-sum/main.cpp -o build/multithreading/bonus/18-parallel-sum/main-optimized
./build/multithreading/bonus/18-parallel-sum/main-optimized
~~~

На Windows, из MSYS2 Bash и также из корня репозитория:

~~~bash
mkdir -p build/multithreading/bonus/18-parallel-sum
C:/msys64/mingw64/bin/g++.exe -std=c++17 -O2 -pthread multithreading/bonus/18-parallel-sum/main.cpp -o build/multithreading/bonus/18-parallel-sum/main-optimized.exe
./build/multithreading/bonus/18-parallel-sum/main-optimized.exe
~~~

Для обычного учебного запуска откройте main.cpp и нажмите F5 или Ctrl+F5.
