# 05. std::future и std::async

В уроке с лямбдой результат записывался в переменную по ссылке.
Здесь `std::async` запускает вычисление `sum(2, 5)` и возвращает
`std::future<int>` — объект, через который можно дождаться результата и получить его.

~~~cpp
std::future<int> result = std::async(std::launch::async, sum, 2, 5);
const int value = result.get();
~~~

std::launch::async явно выбирает выполнение в отдельном потоке.
Без него реализация вправе отложить вызов до ожидания результата.
Пока вычисление выполняется, main может заниматься другой работой.

get() ждёт готовности и возвращает 7. Получить результат через get()
у одного std::future можно только один раз. Вручную вызывать join() здесь не нужно.

Вторая задача выбрасывает исключение. Оно сохраняется и повторно выбрасывается
в main на вызове failed.get(), где его обрабатывает catch.
Это отличается от неперехваченного исключения в функции обычного std::thread,
которое приводит к std::terminate().

В примере возвращённый `future` сохраняется в переменной `result`.
Если его не сохранить, временный объект уничтожится в конце выражения.
Уничтожение последнего `future`, связанного с задачей `launch::async`,
может ждать окончания этой задачи. Поэтому следующая строка кода
не обязательно начнёт выполняться параллельно с запущенной задачей.
