# 15. std::osyncstream — C++20

Три потока печатают по три сообщения, каждое собирается несколькими вставками.
Без согласования такие части сообщений могли бы перемешиваться.

Внутри каждой итерации создаётся отдельный объект:

~~~cpp
std::osyncstream line(std::cout);
line << "Worker " << id << ": ";
line << "message " << number << '\n';
~~~

Вставки накапливаются в собственном буфере line.
При выходе из блока объект передаёт накопленный текст в общий поток
без перемешивания с буферами других osyncstream, использующих тот же буфер назначения.
Пауза между вставками специально подчёркивает, что сборка сообщения может занимать время.

Порядок целых сообщений неизвестен. Должно быть 9 строк Worker
и завершающая строка All 9 messages finished.
main выводит последнюю строку обычным cout после всех join().

Для этой гарантии все одновременные записи в тот же поток должны использовать
соответствующие синхронизированные буферы. Нельзя ожидать, что osyncstream
автоматически защитит параллельные прямые вставки другого потока в cout.

osyncstream защищает передачу вывода. Он не защищает ваши общие переменные
и не заменяет mutex вокруг произвольных операций с данными.
Передача буфера также не обязательно означает немедленный flush устройства.

Откройте main.cpp и нажмите F5 или Ctrl+F5.
cxx-standard.txt автоматически выбирает C++20.
