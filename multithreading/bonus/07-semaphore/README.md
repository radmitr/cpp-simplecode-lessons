# 07. std::counting_semaphore — C++20

Пример парковки: пять машин, но одновременно на ней могут находиться
не больше двух. Каждая машина — отдельный поток.

## acquire, release и try_acquire

Семафор slots создаётся с двумя разрешениями.
acquire() забирает одно, при отсутствии разрешений ждёт.
release() возвращает разрешение; release(2) возвращает сразу два.
try_acquire() делает попытку без ожидания и возвращает bool.

В начале main забирает оба разрешения и пробует взять третье:
try_acquire возвращает false, после чего main возвращает оба разрешения.
Затем запускаются пять потоков, которые занимают места и освобождают их.

В `std::counting_semaphore<2> slots(2)` два числа имеют разный смысл:

- `<2>` требует, чтобы реализация поддерживала счётчик хотя бы до 2.
  Фактический верхний предел, возвращаемый `max()`, может быть больше.
- `(2)` задаёт начальное число разрешений — два свободных места.

Две машины могут занять эти места одновременно. Третья ждёт, пока одна
из них не вернёт разрешение. Ограничение в два места сохраняется,
потому что каждый поток возвращает ровно одно ранее взятое разрешение.

## Почему здесь ещё есть mutex

Семафор допускает на парковку сразу два потока. Оба могут одновременно
попытаться изменить общие счётчики или напечатать сообщение.
Поэтому отдельный `mutex` защищает:

- `parked` — сколько машин сейчас на парковке;
- `peak` — наибольшее число машин, замеченное за время работы;
- `completed` — сколько машин уже уехало;
- печать сообщений, чтобы их части не перемешивались.

Ни один поток не удерживает этот mutex во время acquire() или сна.

В конце должно быть Completed: 5, parked равен 0, peak не больше 2.
Точный порядок машин и достигнутый пик зависят от планирования.
Пауза изображает пребывание машины на парковке.

У мьютекса освобождение выполняет тот же поток, который его захватил.
У семафора разрешение может вернуть другой поток, если программа так устроена.
В нашей парковке разрешение возвращает сама уезжающая машина.
Лишний вызов `release()` нарушит подсчёт свободных мест, а превышение `max()`
нарушит требования семафора. `try_acquire()` может вернуть `false`
даже при наличии разрешения, поэтому false — это только неудачная попытка.

acquire() здесь — метод семафора. Это другой смысл, чем memory_order_acquire
у атомарных операций; порядок памяти в этом уроке не рассматривается.
