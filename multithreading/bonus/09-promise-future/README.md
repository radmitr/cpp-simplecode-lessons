# 09. std::promise и std::future

Продолжение бонуса [future и async](../05-future-async/), C++17.
Здесь std::thread запускается вручную, а рабочий поток явно передаёт
значение или исключение через std::promise<int>.

## Передача результата

main создаёт promise и получает связанный future через get_future().
std::move(output) передаёт promise функции calculate по значению:
promise нельзя скопировать, но можно переместить.
После перемещения main работает с future, а promise находится в рабочем потоке.

output.set_value(a + b) сохраняет результат и делает его доступным.
result.get() в главном потоке ждёт готовности и возвращает значение 7.
set_value можно успешно выполнить только один раз для этого общего состояния;
get у обычного future также вызывается один раз.

## Передача ошибки

Второй запуск получает отрицательный аргумент. calculate выбрасывает
invalid_argument, перехватывает его через catch (...) и передаёт
std::current_exception() в set_exception().
В главном потоке result.get() повторно выбрасывает сохранённое исключение.

Оба случая обрабатываются, после чего worker.join() ждёт завершения потока.
Готовность результата не гарантирует, что функция потока уже вернулась:
set_value может быть вызван раньше её окончания.

Если promise уничтожится, не передав результат или исключение,
связанный future получит ошибку broken_promise.
Неперехваченное исключение, вышедшее из функции обычного std::thread,
само через future не передаётся: оно приводит к std::terminate().

Программа должна вывести Result: 7, затем Caught: Arguments must be non-negative.
Откройте main.cpp и нажмите F5 или Ctrl+F5.
