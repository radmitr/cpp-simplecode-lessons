# 05. Методы класса в потоке

## Версия C++

`std::size_t` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Как это работает

- `main.cpp`: лямбда с `[&]` вызывает `m.sum(2, 5)` у исходного `m`.
  Главный поток читает `result` после `join()`, результат равен `7`.
- `main2.cpp`: `std::thread(&MyClass::doWork, m)` сохраняет копию `m`
  и вызывает метод у неё.
- `main3.cpp`: `std::thread(&MyClass::doWork2, m, 123)` тоже копирует `m`
  и дополнительно передаёт методу аргумент `123`.
- `main4.cpp`: `std::ref(m)` передаёт исходный объект без его копирования.

### Три применения символа &

`&MyClass::doWork2` создаёт указатель на нестатический метод. Для вызова
нужно передать ещё и объект. В `int&` символ означает ссылку,
а `[&]` задаёт захват используемых внешних переменных по ссылке.
В `main.cpp` это `m` и `result`.

`std::ref` объявлен в `<functional>`. Он не продлевает жизнь объекта:
`m` должен существовать до завершения потока. В этих примерах `join()`
выполняется до выхода из `main`.

Копия `m` содержит отдельные обычные поля. Если поля — указатели или
`shared_ptr`, операция копирования не обязательно создаёт самостоятельные
копии связанных данных. При работе с исходным объектом `join()` обеспечивает
ожидание завершения; одновременные изменения потребовали бы синхронизации.
