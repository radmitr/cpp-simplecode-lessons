# 05. Методы класса в потоке

Все четыре файла — самостоятельные программы. Открывайте и запускайте их по очереди.

- main.cpp: лямбда с [&] вызывает m.sum(2, 5) у исходного m.
  result читается после join(), результат равен 7.
- main2.cpp: thread(&MyClass::doWork, m) сохраняет копию m и вызывает метод у неё.
- main3.cpp: thread(&MyClass::doWork2, m, 123) тоже копирует m,
  но дополнительно передаёт аргумент 123.
- main4.cpp: std::ref(m) передаёт исходный объект без копирования m.

&MyClass::doWork2 — указатель на метод класса. Это другой смысл символа &,
чем ссылка в int& или захват по ссылке в [&].
std::ref объявлен в <functional>. При передаче по ссылке объект должен жить
до завершения потока; в этих примерах это обеспечивается join() перед выходом из main.

Закомментированные лямбды позволяют сравнить две формы запуска метода.
