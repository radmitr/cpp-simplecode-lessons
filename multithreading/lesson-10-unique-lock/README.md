# 10. `std::unique_lock`

[main.cpp](main.cpp) — исходный пример урока. Закомментированная версия
`print()` оставлена для сравнения с работающей функцией.

В активном `print()` объект `ul` создаётся с `std::defer_lock`:
он связан с `mtx`, но пока не захватывает его.
Затем поток спит 2 секунды и вызывает `ul.lock()`.
Один поток печатает, второй ждёт. При выходе из `print()` объект `ul`
освобождает `mtx`.

В закомментированной версии после печати выполняется `ul.unlock()`,
а затем ещё одна пауза без удержания мьютекса. Это альтернативная реализация:
две функции `print(char)` одновременно определить нельзя.

## Зачем нужен unique_lock

Для активного примера подошёл бы и `lock_guard`, созданный после первой паузы.
`unique_lock` позволяет создать управляющий объект заранее, захватить мьютекс
позже и освободить его до конца области видимости.
Деструктор освобождает мьютекс только если объект всё ещё им владеет.
Сам мьютекс должен существовать дольше управляющего им объекта.
