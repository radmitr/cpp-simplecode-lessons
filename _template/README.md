# Шаблон нового урока

[Lesson-00-](Lesson-00-/README.md) содержит минимальный main.cpp и локальные
настройки VS Code. Это заготовка, а не самостоятельная тема курса.

При создании урока выберите раздел, скопируйте папку и дайте ей имя по теме.
В tasks.json/launch.json проверьте относительные пути к scripts/ и build/:
они зависят от глубины новой папки. Подготовьте README с разбором реального
кода, ожидаемым поведением, особенностями вариантов и запуском.

Новые main2.cpp/main3.cpp — отдельные программы, а не дополнительные файлы
для компоновки с main.cpp. Для другого стандарта добавьте cxx-standard.txt;
доступные настройки описаны в [scripts/README.md](../scripts/README.md).
После добавления исходников обновите IntelliSense и указатель [LESSONS.md](../LESSONS.md).
