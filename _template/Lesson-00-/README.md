# Минимальная программа C++

`main.cpp` настраивает кодировку консоли Windows и возвращает 0.
Сейчас программа ничего не печатает и не ожидает ввода — это нормальный
результат пустого шаблона.

## Что означают строки

`iostream` подключает стандартные потоки. Ветка #ifdef _WIN32 подключает
Windows API только на Windows; на Linux функция настройки остаётся пустой.
`SetConsoleCP`/`SetConsoleOutputCP` задают UTF-8 для консольного ввода/вывода.
Они не переводят произвольные файлы и байтовые строки автоматически в UTF-8.

`int main` — точка входа; `return` 0 сообщает об успешном завершении.
По умолчанию используется C++17. В новом коде предпочитайте явные имена из `std`,
даже если исходный шаблон содержит `using namespace std`.

## Запуск и дальнейшие действия

F5 — запуск с отладчиком; Ctrl+F5 — без отладчика.

Откройте `main.cpp` и нажмите F5/Ctrl+F5. Замените пустое тело учебным примером
и перепишите README под его фактическое поведение.
