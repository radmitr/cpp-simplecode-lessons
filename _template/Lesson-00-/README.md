# Минимальная программа C++

## Версия C++

Точка входа и условная компиляция доступны с C++98. Windows API — внешняя
платформенная библиотека, не часть стандарта C++. Сборка шаблона: **C++17**.

## Что изучаем

[main.cpp](main.cpp) вызывает `console::setupConsoleEncoding()` для настройки
кодировки консоли Windows и возвращает `0`.
На Linux функция настройки пуста. Программа ничего не печатает,
не ждёт ввода и не создаёт файлов: это заготовка.

## Примеры

- [main.cpp](main.cpp).

Выбирайте один исходник с `main()`; варианты запускаются отдельно.

## Как это работает

Общий [console.hpp](../../common/console.hpp) подключает Windows API только на Windows.
`SetConsoleCP/SetConsoleOutputCP` выбирают UTF-8 для консольного ввода/вывода;
они не преобразуют произвольный файл автоматически.

`int main()` — точка входа, `return 0` — успешное завершение.
В новом примере используйте явные имена `std::cout` и другие `std::...`.
Добавьте комментарий о версии выбранного API, например `// C++20 — std::jthread.`.

## Типичные ошибки

Пустой вывод здесь не ошибка. Не переносите заготовку в исходный урок курса
для нового сценария: самостоятельные дополнения должны находиться в `additions/`.
