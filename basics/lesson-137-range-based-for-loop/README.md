# Урок 137. Цикл по диапазону

Предварительно: Массивы, контейнеры, ссылки и auto.

## Примеры

- [main.cpp](main.cpp): Обходит массив по значению, изменяет его через auto&& и читает list через const auto&.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-137-range-based-for-loop/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Сначала видны исходные числа массива, затем шесть значений -1 и элементы списка 3, 44, 65, 30, 2.

## Что важно понять

auto копирует элемент, auto& позволяет менять его, const auto& читает без копии. В данном массиве auto&& связывается с существующими элементами как ссылка. Закомментированный for each — расширение MSVC, не синтаксис стандартного C++.
