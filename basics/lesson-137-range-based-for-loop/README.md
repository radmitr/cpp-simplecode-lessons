# Урок 137. Цикл по диапазону

Предварительно: Массивы, контейнеры, ссылки и `auto`.

## Примеры

- [main.cpp](main.cpp): Обходит массив по значению, изменяет его через `auto&`& и читает `list` через `const auto&`.

Каждый `main*`.cpp — отдельная программа.

## Механизм и разбор

`for` (`auto` var : arr) копирует значение каждого `int`.
Цикл с `auto&`& связывается с элементами исходного массива и присваивает -1,
поэтому следующий вывод показывает шесть -1.
`const auto&` в обходе `list` позволяет читать без отдельной копии элемента.

~~~cpp
for (auto& value : values) {
    value = -1;
}
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Компилятор организует итераторы начала/конца диапазона. Добавление элементов
или `erase` во время такого обхода может инвалидировать его скрытые позиции.
`auto&`& полезен для общего кода, но не означает, что каждый элемент
обязательно перемещается.

Расширение MSVC `for` each в комментариях — другой синтаксис, не стандартный
range-based `for`. Время жизни временных диапазонов также зависит от формы
выражения и версии C++; не возвращайте ссылки на уже уничтоженные владельцы.

## Что важно понять

`auto` копирует элемент, `auto&` позволяет менять его, `const auto&` читает без копии. В данном массиве `auto&`& связывается с существующими элементами как ссылка. Закомментированный `for` each — расширение MSVC, не синтаксис стандартного C++.
