# Урок 138. Псевдонимы типов: `typedef`

## Версия C++

`std::vector` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Предварительно: Объявления типов и `vector`.

## Примеры

- [main.cpp](main.cpp): Объявляет int_vector и float_vector как псевдонимы специализаций `std::vector`.

Каждый `main*.cpp` — отдельная программа.

## Как это работает

`typedef` даёт существующему типу дополнительное имя:

~~~cpp
typedef std::vector<int> int_vector;
typedef std::vector<float> float_vector;
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Обе строки из исходника объявляют псевдонимы, а не новые несовместимые классы.
Альтернативная запись C++11 через `using` показана в
[бонусе параметров шаблонов](../../templates/bonus/17-template-parameters/README.md).
Поэтому `vector<int>` и int_vector можно использовать там, где ожидается один тип.
У `using` обычно проще читать сложные типы и объявлять alias templates.

`size_t` из комментария — также имя типа размера, но его конкретный базовый
целый тип зависит от реализации. Не привязывайте переносимый код
к `unsigned __int64`. Используйте `std::size_t` из `<cstddef>`.
Текущий `main` только создаёт контейнеры и завершается без содержательного вывода.

## Типичные ошибки

Псевдоним не создаёт новый отдельный тип. Современная альтернативная запись — `using int_vector = std::vector<int>`. `size_t` не следует считать фиксированным типом `unsigned __int64`: его конкретное определение зависит от платформы.
