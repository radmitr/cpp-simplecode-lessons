# Урок 138. Псевдонимы типов: typedef

Предварительно: Объявления типов и vector.

## Примеры

- [main.cpp](main.cpp): Объявляет int_vector и float_vector как псевдонимы специализаций std::vector.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-138-typedef-keyword/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Программа создаёт контейнеры и завершается без вывода.

## Что важно понять

Псевдоним не создаёт новый отдельный тип. Современная альтернативная запись — using int_vector = std::vector<int>. size_t не следует считать фиксированным типом unsigned __int64: его конкретное определение зависит от платформы.
