# 002. Устройство программы

## Версия C++

C++98 — структура программы, `main()` и return. Сборка проекта: **C++17**.

## Что изучаем

Разбираем минимальное устройство программы и точку входа.

Предыдущие уроки не требуются; нужна [настроенная среда](../../README.md#требования).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа.

## Как это работает

`#include <iostream>` подключает объявления потокового вывода. `int main()` — функция, с которой среда запуска начинает выполнение программы. Фигурные скобки ограничивают её тело. Инструкция с `cout` печатает `Привет МИР!`, `endl` завершает строку, `return 0` заканчивает программу успешно.

Комментарий не выполняется. Директива `#include` обрабатывается до компиляции, а вызовы внутри `main()` выполняются после запуска готового файла.

- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

[Запуск в VS Code](../../README.md#сборка-и-запуск-в-vs-code) ·

Откройте `main.cpp` этого урока. Ввод не нужен. Программа печатает `Привет МИР!` и пустую строку.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Путать исходник `main.cpp` и исполняемый файл. `main` пишется строчными буквами; инструкции завершаются точкой с запятой.
