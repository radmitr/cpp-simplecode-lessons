# 007. Ввод через `std::cin`

## Версия C++

C++98 — ввод через `std::cin` и проверка состояния потока. Сборка проекта: **C++17**.

## Что изучаем

Читаем два целых числа из стандартного ввода.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

Сначала программа предлагает ввести `Var` и выполняет `cin >> Var`, затем так же читает `Var2`. Оператор `>>` пропускает начальные пробельные символы и преобразует текст в целое число. После обоих чтений программа выводит значения.

Если вместо числа пришёл текст, выход за диапазон `int` или ввод закончился раньше времени, поток переходит в состояние ошибки. Добавленные проверки заканчивают программу с кодом `1` до использования неудачно прочитанного значения.

## Сборка и запуск

[Запуск в VS Code](../../README.md#сборка-и-запуск-в-vs-code) ·
[Команды Windows/Linux из терминала](../../README.md#сборка-из-терминала).

Откройте `main.cpp` этого урока. Введите два целых числа, например `2 3` — в одной строке или в разных. В выводе будут оба значения. Неверный или неполный ввод даёт сообщение `Invalid input` и код `1`.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Ожидать чтения целой строки с пробелами через `>>`; продолжать вычисление после ошибки ввода.
