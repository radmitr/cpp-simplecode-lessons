# Урок 146. Функторы: operator()

Предварительно: Классы, методы и перегрузка операторов.

## Примеры

- [main.cpp](main.cpp): Хранит счётчик вызовов внутри объекта-функтора.
- [main2.cpp](main2.cpp): Складывает два числа через operator()(int, int).
- [main3.cpp](main3.cpp): Накапливает сумму и количество чётных значений массива.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-146-functors/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Варианты показывают счётчик 0–4, результат 5 и сумму 226 при количестве 5.

## Что важно понять

Функтор может хранить состояние между вызовами. Копия объекта имеет собственное состояние; это важно при передаче в алгоритмы, которые могут копировать обработчики.
