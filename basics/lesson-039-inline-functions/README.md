# 039. Функции inline

## Версия C++

C++98 — `inline`-функция; встраивание не гарантируется. Сборка проекта: **C++17**.

## Что изучаем

Ключевое слово inline относится к объявлению функции и допускает одинаковые определения в разных единицах трансляции при соблюдении правил языка.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят фрагмент общего исходника; весь объединённый пример целиком здесь не воспроизводится.

## Как это работает

Здесь выделена исходная `inline int Sum_a(int a, int b)`, возвращающая `a + b`. В `main()` вызывается `Sum_a(1, 2)`, но возвращаемое `3` нигде не сохраняется и не печатается. Поэтому отсутствие вывода нормально.

`inline` не приказывает компилятору обязательно вставить тело на место вызова и не гарантирует ускорения. Решение об оптимизации принимает компилятор. Пример с несколькими файлами уже есть в [бонусе «ODR, inline и связывание»](../bonus/24-odr-and-linkage/README.md).
