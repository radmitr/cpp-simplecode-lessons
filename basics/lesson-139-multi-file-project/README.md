# Урок 139. Многофайловая программа

Предварительно: Функции, классы, объявления, определения и пространства имён.

## Примеры

- [src/main.cpp](src/main.cpp): Точка входа: вызывает `sum` и метод `MyClass`.
- [src/sum.cpp](src/sum.cpp): Определяет функцию, объявленную в `include/sum.h`.
- [src/MyClass.cpp](src/MyClass.cpp): Определяет метод класса из `include/MyClass.h`.

Каждый `main*`.cpp — отдельная программа. В уроках 139–140 вспомогательные .cpp из src/ собираются вместе с `src/main.cpp`.

## Механизм и разбор

Заголовок сообщает другим .cpp объявления `sum` и `MyClass`.
Компилятор отдельно обрабатывает каждую единицу трансляции, затем линкер
связывает обращения с их единственными обычными определениями.

~~~text
src/main.cpp → вызовы
src/sum.cpp → тело sum
src/MyClass.cpp → тело метода MyClass
~~~

#include не компилирует автоматически другой .cpp. Именно общая сборка
собирает нужный набор src/*.cpp и добавляет include в поиск заголовков.
Если определение пропущено, возникает ошибка линковки, даже если декларация видна.

Не включайте обычные .cpp друг в друга для исправления отсутствующих символов.
Для шаблонов/`inline` действуют отдельные правила доступности определения;
они разобраны в бонусе ODR и связывания.

## Запуск и результат

F5 — запуск с отладчиком; Ctrl+F5 — без отладчика.

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5/Ctrl+F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-139-multi-file-project/src/main.cpp"
```

На Linux используйте `scripts/build-linux.sh` с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Выводятся результат 5 и сообщение Hello, World!.

## Что важно понять

Открывайте `src/main.cpp` для F5/Ctrl+F5. Общий скрипт собирает все src/*.cpp и добавляет include/. Компиляция одного `main.cpp` без остальных определений приводит к ошибке линковки. Заголовки предоставляют объявления; обычное определение функции не следует дублировать в нескольких единицах трансляции.
