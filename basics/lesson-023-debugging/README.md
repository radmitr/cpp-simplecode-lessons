# 023. Пошаговая отладка

## Версия C++

C++98 — вызовы функций и локальные переменные. Сборка проекта: **C++17**.

## Что изучаем

На небольшой функции удобно проследить выполнение в отладчике.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа.

## Как это работает

В `main()` создаются `a = 5` и `b = 6`. Сначала выполняется непосредственное сложение, затем `c = Sum(a, b)` повторяет его через функцию. У функции свои параметры; `return` передаёт сумму обратно в `main()`. Итоговый результат равен `11`.

Поставьте точку останова перед вызовом, запустите с отладчиком и выполните вход в функцию. Внутри видны её параметры и локальные переменные. После возврата активным снова становится вызов `main()`.

- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

## Сборка и запуск

[Запуск в VS Code](../../README.md#сборка-и-запуск-в-vs-code) ·
[Команды Windows/Linux из терминала](../../README.md#сборка-из-терминала).

Откройте `main.cpp` этого урока. Ввод не нужен. Печатаются приветствие и строка результата `11`; промежуточные присваивания удобно смотреть при F5.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Путать пошаговое выполнение с обычным запуском без отладчика; ожидать, что локальные параметры функции остаются доступными после возврата.
