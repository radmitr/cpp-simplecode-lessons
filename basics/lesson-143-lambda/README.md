# Урок 143. Лямбда-выражения

Предварительно: Урок 142 и параметры функций.

## Примеры

- [main.cpp](main.cpp): Сохраняет лямбду в `std::function` и передаёт её в `doWork`.
- [main2.cpp](main2.cpp): Передаёт лямбду прямо в вызов `doWork`.
- [main3.cpp](main3.cpp): Сохраняет лямбду в `auto` и получает её возвращаемое значение.

Каждый `main*`.cpp — отдельная программа.

## Механизм и разбор

Лямбда — выражение, создающее объект с оператором вызова.
[] задаёт захваты, (`int` a) — параметры, { ... } — тело.
Объявление `auto f` = [] { `return` 1.2232; }; создаёт объект,
а `f()` отдельно выполняет его код.

`main.cpp` хранит обработчик в `std::function`, main2 передаёт временную лямбду,
main3 выводит возвращённое `double` 1.2232. Передача обработчика не означает
автоматический запуск в другом потоке: вызывающий `doWork` сам решает, когда его вызвать.

Без захвата [] нет доступа к обычным локальным переменным внешней функции.
Незахватывающая лямбда может преобразовываться в подходящий указатель на функцию,
захватывающая хранит состояние. Generic `auto`-параметры и время жизни
рассмотрены в бонусе lambda-lifetime.

## Запуск и результат

F5 — запуск с отладчиком; Ctrl+F5 — без отладчика.

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5/Ctrl+F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-143-lambda/main.cpp"
```

На Linux используйте `scripts/build-linux.sh` с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Первые варианты печатают элементы `vector` через обработчик; `main3.cpp` выводит 1.2232.

## Что важно понять

Лямбда создаёт объект собственного типа с `operator()`. `auto` сохраняет этот тип, `std::function` предоставляет общую обёртку. Захват локальных переменных разбирается в уроке 144.
