# 013. Выбор switch

## Версия C++

C++98 — `switch`, `case`, `default` и `break`. Сборка проекта: **C++17**.

## Что изучаем

Оператор switch выбирает действие по значению целого выражения.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

Программа читает `a`. Метки `case 1` и `case 2` задают отдельные варианты; `default` обрабатывает остальные значения. `break` завершает `switch`, чтобы выполнение не продолжилось в следующих вариантах.

Метки `case` — константные значения. Здесь их удобно использовать для небольшого меню. Для произвольных диапазонов и сложных условий обычно подходит `if`.

Откройте `main.cpp` этого урока. Введите `1`, `2` или другое целое. Программа напечатает сообщение выбранной ветви. Неверный ввод даёт код `1`.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Убирать `break`, не учитывая переход в следующую ветвь; считать `default` обязательным или первым выполняемым действием.
