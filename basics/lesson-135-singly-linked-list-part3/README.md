# Урок 135. Односвязный список: полный интерфейс

Предварительно: Уроки 133–134, копирование, перемещение и потоки.

## Примеры

- [main.cpp](main.cpp): Добавляет вставку, удаление, поиск, копирование/перемещение и потоковые операторы.

Каждый main*.cpp — отдельная программа.

## Механизм и разбор

Последовательность начала main: push_front создаёт 101, 7, 5;
insert(50, 1) даёт 101, 50, 7, 5; removeAt(2) удаляет 7,
pop_back удаляет 5. Затем добавляются 0, -10, -101.

Копия list2 должна владеть своей цепочкой узлов. Перемещение может передать
head и размер, оставив источник корректным пустым объектом.
Готовое копирование нельзя свести к присваиванию двух адресов.

Потоковый ввод читает строку целых значений; введите, например, 1 2 3,
затем 2 на следующей строке. findFirst сообщает первый индекс, отсутствие —
отрицательное значение. Метод не перечисляет все совпадения.

Индексный доступ остаётся линейным даже при широком интерфейсе.
Отдельно продумывайте исключение при частичном копировании цепочки:
наличие конструктора копирования ещё не доказывает отсутствие всех утечек
при ошибке выделения или копировании элемента.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-135-singly-linked-list-part3/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

После демонстрации операций введите строку целых чисел, например 1 2 3, затем отдельной строкой число 2 для поиска. Программа сообщает первый найденный индекс.

## Что важно понять

Копирование владеющего списка должно создавать независимые узлы, перемещение — передавать владение. Индексный доступ остаётся линейным. ssize_t — платформенный тип; стандартный переносимый вариант для знаковой разности — std::ptrdiff_t.
