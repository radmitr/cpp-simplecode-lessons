# Урок 133. Односвязный список: узлы и доступ

## Версия C++

`nullptr` — **C++11**.
`std::out_of_range` — **C++98**.

Сборка примеров: **C++17**. Режим сборки и дата появления возможностей различаются.

## Что изучаем

Предварительно: Указатели, шаблоны, классы и деструкторы.

## Примеры

- [main.cpp](main.cpp): Добавляет три узла и демонстрирует индексный доступ, включая ошибочный индекс.
- [main2.cpp](main2.cpp): Читает размер, заполняет список и обходит его по индексам.

Каждый `main*.cpp` — отдельная программа.

## Как это работает

Узел хранит данные и адрес следующего узла, `head` — начало цепочки.
`push_back` должен дойти до конца и присоединить новый узел.
`operator[]` тоже идёт от `head`, поэтому обращение к позиции `i` требует `i` шагов.

Обход `list`[`i`] для всех `i` суммирует эти переходы и может стоить `O(n²)`.
Последовательный обход по ссылкам узлов мог бы быть `O(n)`.
Пустой список обозначается отсутствием первого узла, не «нулевым элементом».

В `main` ошибочный `list[1000]` специально не перехвачен: аварийное завершение
здесь ожидаемое поведение, а не бесконечное ожидание ввода.
Автоматически сгенерированное копирование владеющей цепочки скопировало бы
сырые ссылки на те же узлы. Варианты 133–134 для такого копирования
не предназначены; полноценный набор операций появляется в 135.

## Типичные ошибки

Это собственная структура данных, а не `std::list`. Индексный доступ проходит по узлам: обход через повторные `operator[]` имеет квадратичную стоимость. Эти варианты не предоставляют безопасного копирования владеющего списка; не копируйте их объекты.
