# Урок 133. Односвязный список: узлы и доступ

Предварительно: Указатели, шаблоны, классы и деструкторы.

## Примеры

- [main.cpp](main.cpp): Добавляет три узла и демонстрирует индексный доступ, включая ошибочный индекс.
- [main2.cpp](main2.cpp): Читает размер, заполняет список и обходит его по индексам.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-133-singly-linked-list-part1/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

main.cpp печатает 5, 10, 22, затем обращается к list[1000] и завершается из-за неперехваченного out_of_range. Для main2.cpp введите небольшой неотрицательный размер.

## Что важно понять

Это собственная структура данных, а не std::list. Индексный доступ проходит по узлам: обход через повторные operator[] имеет квадратичную стоимость. Эти варианты не предоставляют безопасного копирования владеющего списка; не копируйте их объекты.
