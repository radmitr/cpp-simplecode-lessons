# 43. Именованная инициализация агрегата

## Версия C++

Designated initializers (`.field = value`) — C++20. Режим сборки — **C++20**. Достаточно GCC 11+.

## Что изучаем

Задаём поля агрегата по именам и явно видим пропущенные настройки. Нужны структуры и инициализация.

## Примеры

- [main.cpp](main.cpp) — выбранные поля и значения по умолчанию; вывод `Ada 8080 5`.

## Как это работает

В `Options{.name="Ada", .retries=5}` поле `port` пропущено и получает свой
default member initializer `8080`. Отсутствующий такой инициализатор обычно
приводит к инициализации поля пустым списком; ссылочное поле без значения недопустимо.

В C++20 обозначения должны идти в порядке объявления полей: можно пропустить
`port`, но нельзя после `retries` вернуться к `name`. Каждый designator называет
прямое нестатическое поле агрегата. Это действие создания объекта, а не последующее
присваивание его полям и не вызов конструктора с именованными аргументами.

Агрегат в C++20 не имеет пользовательски объявленных/унаследованных конструкторов,
закрытых/защищённых прямых полей, виртуальных функций или виртуальных баз.
Обычные открытые базовые классы допустимы, но инициализация баз designator-ом
не входит в используемый здесь интерфейс C++20.

## Сборка и запуск

[Настройка и запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).
Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh basics/bonus/43-designated-initializers/main.cpp
./build/basics/bonus/43-designated-initializers/main
```

На Windows из MSYS2 Bash используйте `scripts/build-windows.sh` и файл
`build/basics/bonus/43-designated-initializers/main.exe`. Конфигурации F5/Ctrl+F5 находятся в `.vscode/`.

Интерактивного ввода и сетевых служб нет. Программы не создают пользовательские файлы.
Каждый вариант проверяет результат:
последняя строка `OK reference-example`, код завершения `0`;
нарушение проверки или необработанная ошибка — код `1`.

## Типичные ошибки

Нельзя смешивать в одном списке C++20 именованные и позиционные элементы, повторять
поле, применять C-синтаксис `[index] = value` или вложенное `.outer.inner = value`.
Добавление пользовательского конструктора может перестать делать класс агрегатом.
