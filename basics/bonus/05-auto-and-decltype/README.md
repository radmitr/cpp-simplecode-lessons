# 05. `auto`, ссылки и `decltype(auto)`

## Версия C++

`decltype(auto)` — **C++14**.
`auto`, `decltype` — **C++11**.
`std::vector`, `std::exception` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Обычный `auto` часто снимает ссылочность и верхний `const`, создавая копию.
`auto&` сохраняет ссылку. `decltype` для непомещённого в скобки имени переменной
даёт объявленный тип, а `decltype((value))` учитывает категорию выражения и здесь
даёт `int&`. Поэтому лишние скобки в `return` с `decltype(auto)` могут неожиданно
вернуть ссылку, в том числе висячую. Для публичного интерфейса явно подумайте,
нужны значения или ссылки.

## Как это работает

Нужны ссылки, `const`, выражения и возвращаемые значения функций.

`auto copy = values[0]` создаёт самостоятельный `int`, `auto& reference` —
псевдоним существующего элемента. После `copy = 9` и `reference = 7`
первый элемент `vector` равен 7.

~~~cpp
static_assert(std::is_same_v<decltype(value), int>);
static_assert(std::is_same_v<decltype((value)), int&>);
decltype(auto) result = (value);
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

У `decltype` есть специальное правило для непомеченного скобками имени.
Дополнительные скобки меняют рассматриваемое выражение и сохраняют ссылку.
Поэтому `result = 10` в `main` меняет сам `value`; вывод: 10 7.

`auto` не означает динамический тип: конкретный тип известен при компиляции.
Обычный `auto` часто снимает верхнеуровневую ссылку/`const`; `auto&` сохраняет связь.
При возврате `decltype(auto)` особенно важны скобки: ссылка на локальный объект
останется висячей после выхода из функции.

## Типичные ошибки

`auto` без `&` обычно создаёт копию. Для имени `value` выражения `decltype(value)` и `decltype((value))` дают разные типы. Не возвращайте через `decltype(auto)` ссылку на уничтожаемый локальный объект.
