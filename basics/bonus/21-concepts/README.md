# 21. Concepts и `requires`

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Стандарт и компилятор: `c++20`. Каждый исходник здесь — самостоятельный исполняемый пример.

## Что показывает пример

Concept формулирует проверяемое ограничение шаблона, `requires`-expression
описывает допустимые выражения. Условие `same_as<T>` здесь намеренно строгое:
например, `short` + `short` имеет тип `int`. Проверка синтаксической допустимости
не доказывает математические свойства операции или отсутствие исключений.
Покажите сообщения для неподходящего типа, не оставляя основной пример несобираемым.

## Разбор кода и полезные варианты

Addable проверяет не просто наличие +, а точное требование к типу результата:

~~~cpp
template<class T>
concept Addable = requires(T a, T b) {
    { a + b } -> std::same_as<T>;
};
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

`int` удовлетворяет требованию, `NoAdd` — нет. `add(2, 3)` даёт 5.
У `char` арифметика часто возвращает `int`, поэтому похожий тип может
не пройти именно `same_as<T>`, хотя выражение + существует.

Две записи `requires` у `count` имеют разные роли: внешняя вводит
ограничение шаблона, внутренняя — выражение проверки операции `value.size()`.
Проверка не вызывает `size` во время компиляции для реального runtime-объекта.
Удовлетворение синтаксическому concept не доказывает все смысловые свойства,
например ассоциативность сложения или корректность пользовательского контейнера.

## Запуск

Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh basics/bonus/21-concepts/main.cpp
./build/basics/bonus/21-concepts/main
```

На Windows / MSYS2 Bash используйте `scripts/build-windows.sh` и расширение .exe.
F5 — запуск с отладчиком; Ctrl+F5 — без отладчика.

В VS Code открывайте `main.cpp` и нажимайте F5/Ctrl+F5: доступны корневая и локальная конфигурации.
Рабочая папка при F5/Ctrl+F5 — папка исходника. Особенности компилятора и зависимостей
описаны в [README раздела](../README.md).

## Результат и проверка

После показанных в коде значений последняя строка — `OK 21-concepts`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section basics/bonus`
(на Linux команда Python обычно называется python3).
