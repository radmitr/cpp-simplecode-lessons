# 07. `enum class` и битовые флаги

## Версия C++

`constexpr`, `enum class` — **C++11**.
`std::exception` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Scoped `enum` не преобразуется в число неявно и не выбрасывает имена
элементов в окружающую область. Для флагов задавайте отдельные биты, отличайте
проверку любого бита от проверки всех битов. Произвольное число, преобразованное
в `enum`, не обязательно соответствует именованному элементу. Если перегружаете
битовые операторы, оставляйте такую семантику только специально выбранным типам.

## Как это работает

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Каждый исходник здесь — самостоятельный исполняемый пример.

`Mode::read` — отдельное типизированное значение. `bits` явно переводит его
в `unsigned` для побитовых операций. read = 1, write = 2, execute = 4
занимают разные биты, поэтому read | write даёт combined flags=3.

~~~cpp
const bool readable = (flags & bits(Mode::read)) != 0;
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

& оставляет общий установленный бит, сравнение с нулём превращает результат
в `bool`. Оператор | не появляется у `enum class` автоматически:
здесь объединяются уже преобразованные `unsigned`.

Явный underlying type задаёт представление, но не проверяет входящие
целые числа на принадлежность именованным значениям. При чтении файла/протокола
неизвестные биты нужно обрабатывать отдельно.
Для битовых флагов используют степени двойки; обычное последовательное
перечисление не обязательно можно безопасно объединять как маску.

### Результат и проверка

После показанных в коде значений последняя строка — `OK 07-enum-class`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section basics/bonus`
(на Linux команда Python обычно называется python3).
