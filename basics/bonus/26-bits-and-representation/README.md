# 26. Биты, endian и bit_cast

## Версия C++

`std::bit_cast`, `std::endian` — **C++20**.
`std::byte` — **C++17**.
`std::array`, `auto` — **C++11**.
`std::exception` — **C++98**.

Сборка примеров: **C++20**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Беззнаковые типы подходят для явно заданных битовых операций. Число
позиций сдвига должно быть меньше ширины типа. bit_cast копирует представление
между типами подходящего размера и тривиальной копируемости, не нарушая aliasing
через разыменование несовместимого указателя. Он не выполняет числовое
преобразование и не меняет порядок байтов. Переносимый формат задаёт порядок
явно, как io/bonus/02-portable-binary.

## Как это работает

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Каждый исходник здесь — самостоятельный исполняемый пример.

flags = 0b0101 означает установленные биты 0 и 2.
Маска & проверяет отдельный бит без преобразования в строку.
bit_cast копирует представление uint32_t в массив `std::byte` того же размера,
обратное преобразование восстанавливает исходное число.

~~~cpp
const bool enabled = (flags & 0b0001u) != 0;
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Это не смена порядка байтов и не переносимый сетевой формат.
На little-endian и big-endian массивы байтов могут различаться при одном flags.
`std::endian::native` сообщает характеристику реализации; значение other
в этой программе не расшифровывается подробнее.

bit_cast требует равных размеров и подходящих trivially-copyable типов.
Для произвольного назначения не каждый набор битов обязан обозначать
допустимое значение. Для сериализации отдельно задают размеры полей,
endianness и допустимые значения; дамп объекта может содержать padding.

### Результат и проверка

После показанных в коде значений последняя строка — `OK 26-bits-and-representation`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section basics/bonus`
(на Linux команда Python обычно называется python3).

## Типичные ошибки

### Самостоятельно

Сформируйте little-endian-представление uint32_t вручную и сравните с native-представлением только при подходящем endian.
