# 01. Вычисления во время компиляции: constexpr и consteval

Нужны функции, переменные, целые числа и массивы. Стандарт — C++20, он задан
в cxx-standard.txt. GCC 11 поддерживает используемые здесь средства;
экспериментальные флаги и GCC 16 не нужны.

## Что означают ключевые слова

- const запрещает менять объект через это имя. Инициализатор может вычисляться при запуске. Некоторые const-переменные целого типа с константным инициализатором также допустимы в константных выражениях.
- constexpr у переменной требует константного инициализатора и делает переменную const.
- constexpr у функции разрешает вычислять подходящий вызов при компиляции. Ту же функцию можно вызвать с данными времени выполнения.
- consteval у функции требует константного выражения для её обычного вызова. Возвращённое значение можно сохранить в изменяемую переменную.
- static_assert проверяет условие при компиляции; это не проверка пользовательского ввода во время запуска.

constexpr появился в C++11, consteval — в C++20. Здесь весь урок собирается
как C++20, чтобы сравнивать оба средства одним компилятором.

## main.cpp: обязательные константные контексты

square(3) задаёт constexpr-переменную count и размер std::array.
Два static_assert проверяют результаты. compileTimeSquare(5) возвращает 25
при компиляции, затем обычная переменная result увеличивается до 26.

Ожидаемый вывод:

```text
constexpr square: 9
array size: 9
consteval result after increment: 26
```

Размер массива и static_assert требуют константных выражений независимо
от оптимизации. В обычном выражении оптимизатор тоже может заранее посчитать
constexpr-вызов, но это не означает, что язык требует такого вычисления.

## main2.cpp: данные времени выполнения

Введите целое число от -100 до 100. Например, для 7 вывод заканчивается
runtime square: 49. const int result получает значение из введённых данных;
изменять result нельзя, но использовать его в static_assert нельзя тоже.
Неверный ввод или выход за диапазон дают Invalid input и код 1.
Диапазон ограничен, чтобы умножение int не переполнялось.

Три ошибочные строки оставлены закомментированными. По одной раскомментируйте
их для проверки диагностики: runtime-значение не подходит для constexpr-
инициализатора, обычного consteval-вызова и static_assert. После эксперимента
верните комментарий, чтобы программа снова собиралась.

## Запуск

Из корня на Linux:

```bash
bash scripts/build-linux.sh basics/bonus/01-constexpr-consteval/main.cpp
./build/basics/bonus/01-constexpr-consteval/main
bash scripts/build-linux.sh basics/bonus/01-constexpr-consteval/main2.cpp
printf '7\n' | ./build/basics/bonus/01-constexpr-consteval/main2
```

На Windows / MSYS2 Bash используйте build-windows.sh и расширение .exe.
F5 работает из корня проекта и папки этого бонуса.

## Ограничения и продолжение

Вычисление при компиляции не отменяет правила языка: переполнение знакового
целого недопустимо и в константном выражении. Не всякое действие, допустимое
при запуске, разрешено при вычислении константного выражения; набор возможностей
зависит от версии C++. Здесь используются только простое умножение и массив.

Упражнение: добавьте constexpr-функцию суммы чисел от 1 до n и проверьте
небольшие аргументы через static_assert. Затем вызовите её с введённым n.
