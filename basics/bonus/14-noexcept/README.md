# 14. noexcept, деструкторы и перемещение

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Стандарт и компилятор: c++17. Каждый исходник здесь — самостоятельный исполняемый пример.

## Что показывает пример

noexcept — обещание функции, а не обработчик исключений. Если исключение
выходит из noexcept-функции, вызывается terminate. noexcept(expression) проверяет
потенциальную исключительность выражения, не выполняя его. Контейнеру может быть
выгодно копировать вместо рискованного перемещения для сохранения гарантии.
move_if_noexcept иллюстрирует этот выбор. В обычном примере terminate намеренно
не вызывается, чтобы все проверки могли завершиться.

## Результат и проверка

После показанных в коде значений последняя строка — `OK 14-noexcept`.
Проверки check(...) выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с NDEBUG.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section basics/bonus`
(на Linux команда Python обычно называется python3).

## Самостоятельно

Добавьте условный noexcept к обёртке и проверьте, что он зависит от выполняемой операции, а не от желания автора.
