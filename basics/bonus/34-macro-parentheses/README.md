## Как это работает

Макрос `MULTIPLY(x, y)` определён как `((x) * (y))`.
Вызов `MULTIPLY(2 + 3, 4 + 1)` подставляет `((2 + 3) * (4 + 1))` и даёт `25`.
Если написать определение без скобок `x * y`, после подстановки получилось бы
`2 + 3 * 4 + 1`, то есть `15`. Это пояснение неверного определения:
в исполняемом файле используется вариант со скобками.

Макрос подставляет токены до компиляции; функция сначала вычисляет аргументы.
Не следует передавать макросу побочные эффекты, не понимая, сколько раз аргумент
повторяется в его определении. Здесь аргументы содержат только сложение чисел.

## Типичные ошибки

Не считать скобки вокруг аргументов декоративными; не забывать скобки вокруг всего результата макроса.
