# 06. auto, ссылки и decltype(auto)

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Стандарт и компилятор: c++17. Каждый исходник здесь — самостоятельный исполняемый пример.

## Что показывает пример

Обычный auto часто снимает ссылочность и верхний const, создавая копию.
auto& сохраняет ссылку. decltype для непомещённого в скобки имени переменной
даёт объявленный тип, а decltype((value)) учитывает категорию выражения и здесь
даёт int&. Поэтому лишние скобки в return с decltype(auto) могут неожиданно
вернуть ссылку, в том числе висячую. Для публичного интерфейса явно подумайте,
нужны значения или ссылки.
