# 29. Генераторы, распределения и воспроизводимость

## Версия C++

`std::mt19937`, `std::uniform_int_distribution` — **C++11**.
`std::exception` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Engine создаёт последовательность псевдослучайных значений, distribution
преобразует её под нужную задачу. Фиксированный seed полезен для повторения теста;
переинициализация генератора в каждом вызове разрушает ожидаемую последовательность.
Алгоритмы распределений могут различаться между библиотеками, поэтому тест
не фиксирует их конкретные результаты. `random_device` не гарантирует одинаковые
источники энтропии на всех платформах; `mt19937` не предназначен для секретов.

## Как это работает

Нужны циклы, диапазоны чисел и воспроизводимые проверки.

Два `mt19937` с seed 12345 дают одинаковое первое значение движка.
`uniform_int_distribution<int>(1, 6)` преобразует последовательность движка
в броски кубика, включая обе границы.

~~~cpp
std::mt19937 engine(12345);
std::uniform_int_distribution<int> die(1, 6);
int value = die(engine);
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Программа делает сто бросков и проверяет каждый: 1…6, сумма 100…600.
Она не проверяет точную сумму: алгоритм distribution может различаться
между стандартными библиотеками при одинаковом стандартизованном движке.

Не создавайте движок заново с одним seed на каждой итерации:
тогда будете начинать одну последовательность сначала.
`random_device` не обещает криптографическую защиту любой реализации,
`mt19937` для паролей и токенов не подходит.
Выражение `engine()` % 6 может давать смещение вероятностей; distribution
берёт на себя корректное отображение диапазона.

### Результат и проверка

После показанных в коде значений последняя строка — `OK 29-random`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Конкретные результаты распределения могут различаться между реализациями библиотеки.
Проверка всего раздела: `python scripts/check-bonuses.py --section basics/bonus`
(на Linux команда Python обычно называется python3).

## Типичные ошибки

Движок и распределение решают разные задачи. Одинаковое зерно воспроизводит последовательность движка, но не гарантирует одинаковое преобразование распределения между библиотеками. `mt19937` не предназначен для криптографических секретов.

### Самостоятельно

Добавьте нормальное распределение и отдельно проверяйте параметры/границы программы, не требуя точного набора чисел.
