# 31. Место вызова `source_location`

## Версия C++

`std::source_location` — C++20. Режим сборки — **C++20**. Достаточно GCC 11+.

## Что изучаем

Получаем файл, строку и функцию вызывающего кода без ручной передачи `__FILE__`/`__LINE__`. Нужны функции и аргументы по умолчанию.

## Примеры

- [main.cpp](main.cpp) — прямой вызов и передача исходного места через обёртку; вывод начинается с `caller captured:`.

## Как это работает

`capture()` получает аргумент по умолчанию `source_location::current()`. Для такого
аргумента фиксируется место **вызова** `capture`, а не строка объявления функции.
Проверка сравнивает его с ожидаемым номером следующей строки.

`wrapper` принимает свой аргумент по умолчанию и явно передаёт его дальше.
Если убрать передачу и вызвать внутри просто `capture()`, будет записана строка
внутри `wrapper`. Если вызвать `current()` в обычном теле функции, фиксируется
место этого выражения, а не внешний вызывающий код.

`file_name`, `function_name`, `line`, `column` позволяют строить диагностическое
сообщение. Пути, написание имени функции и поддержка столбца зависят от реализации;
нулевые номера допустимы, когда информация неизвестна. `source_location` описывает
одну точку исходника и не заменяет [стек вызовов](../../../io/bonus/23-stacktrace/README.md).

## Сборка и запуск

[Настройка и запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).
Из корня проекта, Linux:

```bash

./build/basics/bonus/31-source-location/main
```

На Windows из MSYS2 Bash используйте `scripts/build-windows.sh` и файл
`build/basics/bonus/31-source-location/main.exe`. Конфигурации F5/Ctrl+F5 находятся в `.vscode/`.

Интерактивного ввода и сетевых служб нет. Программы не создают пользовательские файлы.
Каждый вариант проверяет результат:
последняя строка `OK reference-example`, код завершения `0`;
нарушение проверки или необработанная ошибка — код `1`.

## Типичные ошибки

Не рассчитывать на одинаковый текст путей между компьютерами и не использовать
имя функции как стабильный идентификатор формата данных. Значение по умолчанию
`source_location{}` не эквивалентно `current()`: оно не запрашивает место вызова.
