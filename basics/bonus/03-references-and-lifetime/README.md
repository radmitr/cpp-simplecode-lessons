# 03. Ссылки, `const` и время жизни

## Версия C++

`nullptr` — **C++11**.
`std::string`, `std::exception` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Ссылка — другое имя существующего объекта; `const`-ссылка запрещает
изменять его через эту ссылку, но видит изменения через другие имена. Указатель
может быть нулевым и переназначаться. Прямая привязка `const`-ссылки к временному
продлевает его жизнь в показанной области, но возврат ссылки на локальный объект
или сохранение ссылки из параметра этого не обеспечивает. `int* const` и `const int*`
ограничивают разные вещи. Не выполняйте примеры с висячими ссылками как обычный код.

## Как это работает

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Каждый исходник здесь — самостоятельный исполняемый пример.

В `main` `value` начинается с 7, `alias` ссылается на него, `observed` даёт
константный доступ к тому же объекту. После `alias = 9 observed` видит 9:
`const` запрещает изменение через эту ссылку, но не создаёт снимок.

~~~cpp
int& alias = value;
const int& observed = value;
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Локальная `const`-ссылка temporary напрямую связывается с временной строкой
и продлевает её жизнь до конца своей области. Возвращённая из функции ссылка
на её локальную переменную такой гарантии не даёт.
Указатель в примере сначала `nullptr`, затем указывает на `value`.
Вывод перед OK: 9 extended lifetime. Ссылка не «перепривязывается» присваиванием:
`alias` = другойInt изменит `value`, а не выберет новый объект.

### `main2.cpp`: константный указатель и указатель на константный объект

`increment(int* const value)` не переназначает адрес, но может увеличить
число через `++*value`. `print(const int* value)` читает число, а менять
его через этот указатель запрещено. Вызовы работают с одной переменной:
исходные `5` превращаются в `6`.

Ввод не нужен. Вывод `6`, затем `OK moved-example-057`; код `0`.
Пример использует возможности C++98. Для работы обеим функциям передаётся
действительный адрес живого `int`: разыменование нуля недопустимо.

### Результат и проверка

В `main.cpp` после показанных значений последняя строка — `OK 03-references-and-lifetime`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section basics/bonus`
(на Linux команда Python обычно называется python3).
