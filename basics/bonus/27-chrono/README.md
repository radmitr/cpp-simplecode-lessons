# 27. `chrono`: длительности и монотонные часы

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Стандарт и компилятор: `c++17`. Каждый исходник здесь — самостоятельный исполняемый пример.

## Что показывает пример

duration хранит значение и единицу периода. duration_cast в целые секунды
отбрасывает дробную часть; дробный representation сохраняет её. steady_clock
подходит для интервалов, system_clock — для календарного времени; это разные
задачи. Не ожидайте одинаковых результатов измерения на разных машинах.
Вывод, прогрев и оптимизация влияют на бенчмарк, поэтому пример не сравнивает
алгоритмы по одиночному почти нулевому измерению.

## Разбор кода и полезные варианты

duration хранит число тиков и масштаб, time_point — момент на шкале часов.
1500ms — длительность, `steady_clock::now()` — момент.
Разность двух моментов даёт длительность.

~~~cpp
auto whole = std::chrono::duration_cast<std::chrono::seconds>(1500ms);
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

В `main whole.count()` равно 1: целочисленное преобразование отбрасывает
дробную часть. `duration<double>`(`timeout`).`count()` даёт 1.5 секунды.
Сам `count` не хранит текст единицы измерения — смотрите тип duration.

steady_clock выбирают для интервала, system_clock — для связи с календарным
временем. Системные часы могут корректироваться. Нельзя просто вычитать
time_point разных часов без корректного преобразования.
sleep_for/таймаут также не гарантируют пробуждение ровно на границе интервала.

## Результат и проверка

После показанных в коде значений последняя строка — `OK 27-chrono`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section basics/bonus`
(на Linux команда Python обычно называется python3).
