# 12. shared_ptr, weak_ptr и циклы владения

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Стандарт и компилятор: c++17. Каждый исходник здесь — самостоятельный исполняемый пример.

## Что показывает пример

shared_ptr разделяет владение через управляющий блок. weak_ptr
наблюдает этот блок, не продлевая жизнь объекта; lock атомарно пытается получить
нового владельца. Не стройте несколько управляющих блоков из одного сырого
указателя. Цикл сильных ссылок сам не исчезнет. Счётчик владения не делает
содержимое Node потокобезопасным; use_count не является протоколом синхронизации.

## Разбор кода и полезные варианты

У parent есть сильная ссылка child, а обратная child->parent — слабая.
Так дерево может обращаться к родителю без цикла владения.
Внутри блока parent.use_count() равен 1: weak_ptr не добавил владельца.
После выхода из блока observed.expired() истинно, lock() возвращает пустой shared_ptr.

~~~cpp
if (auto parent = child->parent.lock()) {
    // Здесь полученный владелец удерживает объект живым.
}
~~~

Раздельная проверка expired(), а потом использование сырого указателя
не удерживает объект между этими действиями. lock объединяет проверку
существования с получением владельца.

Не создавайте shared_ptr(raw) для указателя, уже принадлежащего другому
управляющему блоку: появятся два независимых удаления.
Aliasing-конструктор shared_ptr может обозначать подобъект, удерживая
другого владельца; это специальный механизм, а не разрешение дублировать блоки.

## Запуск

Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh basics/bonus/12-shared-weak-ptr/main.cpp
```

Рабочая папка F5 — папка исходника. Особенности компилятора и зависимостей
описаны в [README раздела](../README.md).

## Результат и проверка

После показанных в коде значений последняя строка — `OK 12-shared-weak-ptr`.
Проверки check(...) выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с NDEBUG.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section basics/bonus`
(на Linux команда Python обычно называется python3).
