# 19. Пакеты параметров и fold expressions

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Стандарт и компилятор: c++17. Каждый исходник здесь — самостоятельный исполняемый пример.

## Что показывает пример

Пакет описывает несколько аргументов, fold expression разворачивает
оператор над ними. Начальное значение определяет поведение пустой суммы.
Сложение разнородных типов зависит от обычных преобразований и допустимости
оператора. Свёртка по запятой выполняет вызовы по порядку, логическая свёртка
сохраняет короткое замыкание. Не путайте число аргументов sizeof...(T) с размером данных.

## Разбор кода и полезные варианты

class... T и values... описывают переменное число параметров.
Сумма использует начальный 0, поэтому sum() допустима и равна нулю,
а sum(1, 2, 3) даёт 6.

~~~cpp
return (0 + ... + values);
~~~

Это левая бинарная свёртка: ((0 + v1) + v2) + v3.
Тип результата выводится из выражения; 0 участвует в обычных преобразованиях.
Логическая свёртка all_positive сохраняет короткое замыкание &&;
для пустого пакета её нейтральное значение true.

call_all сворачивает запятую: сначала счётчик увеличивается на 1,
затем на 2. Это последовательность вызовов, а не создание потоков.
Для других операторов порядок вычисления операндов нельзя автоматически
выводить из вида записи свёртки. sizeof...(T) даёт число аргументов.

## Запуск

Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh basics/bonus/19-parameter-packs/main.cpp
./build/basics/bonus/19-parameter-packs/main
```

На Windows / MSYS2 Bash используйте scripts/build-windows.sh и расширение .exe.
В VS Code открывайте main.cpp и нажимайте F5: доступны корневая и локальная конфигурации.
Рабочая папка F5 — папка исходника. Особенности компилятора и зависимостей
описаны в [README раздела](../README.md).

## Результат и проверка

После показанных в коде значений последняя строка — `OK 19-parameter-packs`.
Проверки check(...) выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с NDEBUG.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section basics/bonus`
(на Linux команда Python обычно называется python3).
