# 11. unique_ptr: фабрики, массивы и deleter

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Стандарт и компилятор: c++17. Каждый исходник здесь — самостоятельный исполняемый пример.

## Что показывает пример

Фабрика возвращает владельца по значению. Параметр unique_ptr по
значению принимает владение; для наблюдения обычно достаточно ссылки/указателя
на сам объект. get не передаёт ответственность за delete, release передаёт её
вызывающему без освобождения. reset освобождает старый ресурс. Deleter должен
соответствовать способу получения ресурса и не выпускать исключений; время
жизни данных, на которые он ссылается, должно быть достаточным.

## Разбор кода и полезные варианты

Фабрика make_number возвращает владельца int со значением 7.
get() даёт заимствованный указатель, а consume(std::move(pointer))
передаёт владельца по значению: после вызова pointer пуст, ресурс освобождён
при уничтожении параметра consume.

~~~cpp
int* borrowed = pointer.get();   // Без передачи владения.
// delete borrowed;             // Нельзя удалять ресурс действующего владельца.
~~~

Массив `make_unique<int[]>`(3) инициализируется нулями. Пользовательский Deleter
считает удаления; reset в локальном блоке удаляет int ровно один раз,
последующий деструктор уже пустого unique_ptr ничего не удаляет.

release, в отличие от get, снимает ответственность с unique_ptr;
возвращённый сырой ресурс надо немедленно передать новому владельцу
или освободить подходящей операцией. Для FILE*, дескрипторов и библиотечных
объектов используют соответствующий deleter, а не случайный delete.

## Результат и проверка

После показанных в коде значений последняя строка — `OK 11-unique-ptr`.
Проверки check(...) выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с NDEBUG.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section basics/bonus`
(на Linux команда Python обычно называется python3).
