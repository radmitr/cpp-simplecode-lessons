# 08. Структурированные привязки и псевдонимы

## Версия C++

структурированные привязки — **C++17**.
псевдонимы using — **C++11**.
`std::map`, `std::string`, `std::exception` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

`auto` [`x`,`y`] создаёт скрытый объект-копию и привязывает имена к его
элементам; `auto&` работает с исходным объектом. В `map` ключ остаётся `const` даже
при `auto&`. Structured bindings не являются рефлексией: число и форма привязок
задаются в исходнике, имена произвольных полей не перечисляются. `using` создаёт
псевдоним существующего типа, а не новый несовместимый тип.

## Как это работает

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Каждый исходник здесь — самостоятельный исполняемый пример.

`auto` [`copyX`, `copyY`] = `point` создаёт скрытую копию `Point`, имена обращаются
к её компонентам. `auto&` [`x`, `y`] = `point` связывается с исходным объектом.
Поэтому `x = 9` меняет `point.x`, а `copyX` остаётся 1.

~~~cpp
for (auto& [name, score] : scores) {
    ++score;
}
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

В `map` ключ name остаётся `const`, хотя score изменяем. Из Ada=7 получается
Ada=8. Привязки помогают называть компоненты pair/tuple/агрегата,
но сами не перечисляют именованные поля произвольного типа.

Ссылочные привязки не продлевают жизнь исходного `map` или `Point`.
Обращение после уничтожения владельца или инвалидирования элемента
небезопасно. Для независимого снимка выбирайте копирование осознанно.

### Результат и проверка

После показанных в коде значений последняя строка — `OK 08-structured-bindings`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section basics/bonus`
(на Linux команда Python обычно называется python3).
