# 16. Шаблоны функций и вывод параметров

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Стандарт и компилятор: c++17. Каждый исходник здесь — самостоятельный исполняемый пример.

## Что показывает пример

Один параметр T должен согласоваться с обоими аргументами. Явное
larger<double> разрешает обычные преобразования в выбранный тип. При разрешении
перегрузок важны качество преобразований и правила выбора, а не универсальное
«обычная функция всегда выигрывает». Реализация возвращает значение, чтобы не
создавать висячую ссылку на временный аргумент.

## Запуск

Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh basics/bonus/16-function-templates/main.cpp
./build/basics/bonus/16-function-templates/main
```

На Windows / MSYS2 Bash используйте scripts/build-windows.sh и расширение .exe.
В VS Code открывайте main.cpp и нажимайте F5: доступны корневая и локальная конфигурации.
Рабочая папка F5 — папка исходника. Особенности компилятора и зависимостей
описаны в [README раздела](../README.md).

## Результат и проверка

После показанных в коде значений последняя строка — `OK 16-function-templates`.
Проверки check(...) выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с NDEBUG.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section basics/bonus`
(на Linux команда Python обычно называется python3).
