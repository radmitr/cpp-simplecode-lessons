# 39. Пакеты структурированных привязок

## Версия C++

Режим сборки — **C++26**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках. Для C++26 реализация ещё может быть неполной.

## Что изучаем

Разбираем агрегат на первый элемент и оставшуюся группу; используем привязку как условие. Нужны привязки C++17 и пакеты шаблонов.

## Примеры

- [main.cpp](main.cpp) — пакет из двух элементов, ссылки и `constexpr`; вывод `1 5`.
- [main2.cpp](main2.cpp) — успешное и неуспешное условие; вывод `7`.

## Как это работает

Пакет привязок объявляется внутри шаблонной функции или шаблонной лямбды. В `auto [first, ...tail]` имя `tail` обозначает пакет оставшихся элементов, а не контейнер. Свёртка суммирует его. Вариант `auto&` сохраняет ссылки на исходный массив; присваивание через привязку изменяет массив. В условии `if (auto [value, ok] = result)` проверяется преобразование всего объекта `result` в `bool`, а не только последняя привязка. `constexpr`-привязки полей агрегата позволяют проверять значения через `static_assert`. В GCC 16 поддержка constexpr-ссылок tuple-like-привязок неполная, поэтому здесь используется простой агрегат.

## Сборка и запуск

[Настройка компилятора и запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).
Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh basics/bonus/39-structured-bindings-packs/main.cpp
./build/basics/bonus/39-structured-bindings-packs/main
```

Для остальных вариантов замените `main.cpp` и имя исполняемого файла. На Windows вызовите `scripts/build-windows.sh` через MSYS2 Bash, затем соответствующий файл `build/basics/bonus/39-structured-bindings-packs/main.exe`. Готовые `tasks.json` и `launch.json` содержат оба варианта системы.

Ввода, сетевых служб и постоянных файлов не требуется, если ниже не указано другое. Каждый пример проверяет результаты; успех — строка `OK modern-example` и код `0`, ошибка проверки — код `1`.

## Типичные ошибки

Размер пакета определяется размером разбираемого типа при компиляции. В одной привязке допускается один пакет. Не возвращайте ссылки на элементы уничтоженного локального объекта.
