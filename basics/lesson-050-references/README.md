# 050. Ссылки на объекты

## Версия C++

C++98 — ссылки на переменные. Сборка проекта: **C++17**.

## Что изучаем

Ссылка даёт другое имя уже существующему объекту.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

`a = 5`, `pa = &a` и `aref = a` описывают число, указатель на него и ссылку на него. `pa` и `&aref` показывают один адрес; `*pa` и `aref` читают одно значение `5`.

Присваивание `aref = aref + 2` меняет `a` на `7`. Следующее `aref = aref - 2` возвращает `a` к `5`. Ссылка после инициализации не переназначается другому объекту: присваивание через неё меняет исходный объект.

Откройте `main.cpp` этого урока. Ввод не нужен. Печатаются два одинаковых адреса и два значения `5`. Последующие изменения `5 → 7 → 5` выполняются, но отдельно не печатаются.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Путать `int&` в объявлении ссылки и `&` получения адреса; считать второе изменение равным `5 - 2`, забывая предыдущее увеличение.
