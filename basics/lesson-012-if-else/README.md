# 012. Ветвление if и else

## Версия C++

C++98 — ветвление `if` / `else`. Сборка проекта: **C++17**.

## Что изучаем

Условный оператор выбирает ветвь программы.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

Сначала `rain = false` приводит к выполнению ветви без дождя. Затем программа читает `a` и сравнивает его с `5`. В цепочке `if / else if / else` выполняется только одна подходящая ветвь: меньше, равно или больше.

Проверки идут сверху вниз. `else` связан с соответствующим `if`, а фигурные скобки объединяют несколько инструкций в одну ветвь. Неверный ввод отсекается до сравнений.

[Запуск в VS Code](../../README.md#сборка-и-запуск-в-vs-code) ·

Откройте `main.cpp` этого урока. Введите целое число. Для `4`, `5` и `6` будут выбраны разные сообщения о сравнении с `5`. При неверном вводе код завершения `1`.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Ставить лишнюю точку с запятой сразу после условия или считать, что выполняются все ветви.
