# Урок 59. Изменение динамического массива

Предварительно: Урок 58, ссылки на указатель и размер, функции, обработка исключений.

## Примеры

- [main.cpp](main.cpp): Реализует вставку, удаление и доступ к элементам через перераспределение массива.

Каждый main*.cpp — отдельная программа.

## Механизм и разбор

Сырой динамический массив нельзя растянуть на месте стандартной операцией.
Добавление/вставка создаёт новый буфер, копирует сохранённые элементы,
затем заменяет адрес и размер. Ссылка на указатель позволяет функции
изменить сам arr вызывающего кода, а не только локальную копию адреса.

В main push_back добавляет 111, push_front — 222, insert в позицию 2 — 333;
соответствующие удаления возвращают исходные значения.
Вставка по индексу 1000 намеренно завершается исключением и кодом 1.

После замены буфера старые указатели/ссылки на элементы недействительны.
Допустимость позиции вставки и позиции чтения различается: вставить в конец
часто можно при index == size, прочитать элемент с таким индексом нельзя.
vector реализует похожий интерфейс с управлением памятью и ёмкостью.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-059-dynamic-array-resize-delete-add-get/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

После последовательности изменений печатается содержимое массива. Последняя вставка по индексу 1000 попадает в catch и завершает программу с кодом 1.

## Что важно понять

Код 1 здесь ожидаем: это демонстрация проверки границ. Большинство изменений требуют нового выделения памяти и копирования; для прикладного кода обычно подходит std::vector.
