# Урок 142. Хранение вызываемых объектов: `std::function`

## Версия C++

`std::function`, `auto` — **C++11**.
`std::vector` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Предварительно: Урок [«65. Указатели на функции»](../lesson-065-function-pointers/README.md), функции, сигнатуры и `vector`.

## Примеры

- [main.cpp](main.cpp): Хранит `foo`/`bar` и функцию сложения в `std::function`.
- [main2.cpp](main2.cpp): Передаёт обработчик или набор обработчиков для обработки элементов `vector`.

Каждый `main*.cpp` — отдельная программа.

## Как это работает

`std::function` хранит вызываемый объект с заданной сигнатурой.
`std::function<int(int, int)>` принимает два `int` и даёт `int`: `sum(2, 3)` возвращает 5.
`std::function<void(int)>` описывает обработчик одного элемента.

main2 передаёт в общий обход сначала один обработчик, затем `vector`
обработчиков. Алгоритм обработки остаётся прежним, изменяется переданная работа.

`std::function` может хранить обычную функцию, копируемую лямбду или функтор.
Пустой объект проверяют через `bool`; вызов пустого бросает bad_function_call.
Хранение может требовать памяти и косвенного вызова.
Если конкретный тип известен, `auto` или шаблон часто сохраняет его без стирания.
Для некопируемых замыканий классический `std::function` C++17 не подходит.

## Типичные ошибки

`std::function` хранит вызываемый объект подходящей сигнатуры. Вызов пустой обёртки выбрасывает `std::bad_function_call`. В примере контейнеры передаются по значению: их копирование отдельно от стоимости вызова обработчика.
