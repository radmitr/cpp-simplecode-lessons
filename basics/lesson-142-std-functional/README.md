# Урок 142. Хранение вызываемых объектов: std::function

Предварительно: Урок 65, функции, сигнатуры и vector.

## Примеры

- [main.cpp](main.cpp): Хранит foo/bar и функцию сложения в std::function.
- [main2.cpp](main2.cpp): Передаёт обработчик или набор обработчиков для обработки элементов vector.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-142-std-functional/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Первый вариант вызывает foo, bar и выводит result=5. Второй применяет выбранные обработчики к числам.

## Что важно понять

std::function хранит вызываемый объект подходящей сигнатуры. Вызов пустой обёртки выбрасывает std::bad_function_call. В примере контейнеры передаются по значению: их копирование отдельно от стоимости вызова обработчика.
