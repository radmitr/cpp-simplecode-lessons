# 018. Выход из цикла: break

## Версия C++

C++98 — выход из цикла через `break`. Сборка проекта: **C++17**.

## Что изучаем

Инструкция break немедленно завершает ближайший цикл.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа.

## Как это работает

Первый `for` не ограничен условием в заголовке: выход задаёт проверка внутри тела. В исходном порядке сначала печатается `i`, поэтому значение `5` попадает в вывод перед `break`. Во втором цикле `while (true)` проверка расположена после увеличения счётчика: там печатаются `0–4`.

Расположение `break` относительно вывода и увеличения влияет на видимые значения. `break` не завершает всю функцию — после цикла выполняются следующие инструкции.

- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

[Запуск в VS Code](../../README.md#сборка-и-запуск-в-vs-code) ·

Откройте `main.cpp` этого урока. Ввод не нужен. Первый цикл печатает `0–5`, второй `0–4`; оба завершаются через `break`.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Считать, что `break` завершает программу, или переносить проверку, не учитывая изменение последнего выведенного значения.
