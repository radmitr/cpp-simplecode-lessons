# 011. Сравнения и логические операции

## Версия C++

C++98 — сравнения, логические операторы и сокращённое вычисление. Сборка проекта: **C++17**.

## Что изучаем

Сравнения возвращают логический результат, а логические операторы объединяют условия.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

[main.cpp](main.cpp) — самостоятельная программа.

## Как это работает

Для `a = 3`, `b = 3` и `c = 4` проверяются отношения и равенство. `==` сравнивает значения, `!=` проверяет неравенство, `!` меняет логический результат на противоположный. `&&` требует истинности обоих условий, `||` — хотя бы одного.

Поток печатает `false` как `0` и `true` как `1`. У `&&` и `||` есть сокращённое вычисление: правая часть не вычисляется, если результат уже известен из левой.

- В комментарии логическое отрицание исправлено с `!=` на `!`; `!=` остаётся оператором неравенства.
- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

## Типичные ошибки

Использовать присваивание `=` вместо сравнения `==`; путать `!=` и отдельный логический оператор `!`.
