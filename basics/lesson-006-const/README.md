# 006. Константы

## Версия C++

C++98 — константы `const`. Сборка проекта: **C++17**.

## Что изучаем

Именованные константы обозначают значения, которые программа не должна менять.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

`COUNT_DAYS_IN_WEEK` содержит `7`, `NEW_LINE` — символ перевода строки, `TAB` — табуляцию. Модификатор `const` запрещает присвоить этой переменной новое значение после инициализации. Поток использует символьные константы так же, как непосредственно записанные `'\n'` и `'\t'`.

Константу нужно инициализировать при объявлении. `const` не означает, что любое вычисление автоматически выполняется во время компиляции; для этой темы есть [бонус «constexpr и consteval»](../bonus/01-constexpr-consteval/README.md).

## Типичные ошибки

Пытаться присвоить новое значение `const`-переменной или путать строковый литерал `"\n"` с символьным `'\n'`.
