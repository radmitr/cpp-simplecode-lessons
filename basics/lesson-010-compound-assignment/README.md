# 010. Составное присваивание

## Версия C++

C++98 — составные операторы присваивания. Сборка проекта: **C++17**.

## Что изучаем

Составное присваивание меняет значение существующей переменной.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа.

## Как это работает

Выполняются пары обычных и сокращённых инструкций: `a = a + 20` и `a += 20`, затем вычитание, умножение и деление. Обе инструкции каждой пары реально выполняются: это не два альтернативных варианта, между которыми программа выбирает.

После `a = 0`, `a++` и `a--` значение снова `0`. Дальнейшая цепочка даёт `20 → 40 → 30 → 20 → 40 → 80 → 40 → 20`. Исходник не выводит `a`: чтобы увидеть шаги, поставьте точку останова и смотрите переменную в отладчике.

- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

## Типичные ошибки

Ожидать автоматической печати `a`; считать соседние обычную и сокращённую записи одним действием.
