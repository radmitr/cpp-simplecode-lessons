# 20. if `consteval` и явное копирование auto

## Версия C++

Режим сборки — **C++23**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках.

## Что изучаем

Выбираем вычисление при компиляции или при запуске и явно создаём независимую копию. Нужны `constexpr`, ссылки и обычные функции.

## Примеры

- [main.cpp](main.cpp) — две ветки вычисления, результаты `20` и `2`.
- [main2.cpp](main2.cpp) — две копии строки и исходная строка, результаты `old old new`.

## Как это работает

В `main.cpp` один вызов попадает в инициализацию `constexpr`, другой читает `volatile`-переменную и выполняется при запуске. `if consteval` выбирает соответствующую ветку. Это проверка контекста вычисления, а не типа аргумента. Обе ветки должны быть корректны; в положительной ветке разрешён вызов `consteval`-функции. В `main2.cpp` `auto(text)` и `auto{text}` создают отдельные значения: изменение исходной строки не меняет копии. Для объекта, который нельзя копировать, такая операция не подходит.

## Типичные ошибки

Не путать `if consteval` с `if constexpr`: последний выбирает код по константному условию. `constexpr` у функции не заставляет каждый её вызов выполняться при компиляции. `auto(x)` не создаёт ссылку на `x`.
