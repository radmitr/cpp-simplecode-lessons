# 16. Пользовательские литералы

## Версия C++

Пользовательские литералы и использованные здесь `constexpr`-операторы — C++11. Режим сборки — **C++17**. Достаточно GCC 11+.

## Что изучаем

Задаём суффикс числу или строке, чтобы сразу получить нужный тип. Нужны перегрузка функций, пространства имён и ограничения целых чисел.

## Примеры

- [main.cpp](main.cpp) — `2_m` и `7_mm`, проверка переполнения; вывод `2007`.
- [main2.cpp](main2.cpp) — строковый литерал с нулевым байтом и точной длиной; вывод `3 b`.

## Как это работает

Компилятор превращает `2_m` в вызов `operator""_m(2ULL)`. Оператор переводит метры
в миллиметры и возвращает `Length`, а не безымянное число. Суффикс `_mm` уже
обозначает нужную единицу. Перед умножением проверяется диапазон. Если результат
обязан быть константным выражением, например в инициализаторе `constexpr`,
недопустимый аргумент приводит к ошибке компиляции. Обычный вызов во время
выполнения бросает `out_of_range`; пример перехватывает это ожидаемое исключение.

Для строки форма `(const char*, size_t)` получает адрес символов и их число без
завершающего нуля, но с внутренними нулевыми байтами. В `"a\0b"_text` длина равна `3`.
Здесь `Text` ссылается на строковый литерал со статическим временем жизни.

Операторы объявлены в пространствах имён. Локальный `using namespace units`
делает суффиксы доступными только в показанной области. Для целого обработанный
числовой аргумент имеет тип `unsigned long long`, для вещественного — `long double`;
это не произвольная перегрузка на `int` или `double`. Стандартные суффиксы `s`/`ms`
для времени и `s` для строки появились в C++14 и уже используются в соответствующих уроках.

## Сборка и запуск

[Настройка и запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).
Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh basics/additions/16-user-defined-literals/main.cpp
./build/basics/additions/16-user-defined-literals/main
```

Для второго примера соберите `main2.cpp` и запустите `main2` из того же каталога сборки.
На Windows из MSYS2 Bash используйте `scripts/build-windows.sh` и файл
`build/basics/additions/16-user-defined-literals/main.exe`. Конфигурации F5/Ctrl+F5 находятся в `.vscode/`.

Интерактивного ввода и сетевых служб нет. Программы не создают пользовательские файлы.
Каждый вариант проверяет результат:
последняя строка `OK reference-example`, код завершения `0`;
нарушение проверки или необработанная ошибка — код `1`.

## Типичные ошибки

Пользовательские суффиксы должны начинаться с `_`; не использовать зарезервированные
имена с двойным подчёркиванием. `-2_m` означает унарный минус над результатом `2_m`,
а не отрицательный аргумент литерального оператора; у `Length` такой минус не задан.
Возвращаемый тип должен действительно обеспечивать нужные ограничения: один суффикс
ещё не создаёт полноценную систему размерностей.
