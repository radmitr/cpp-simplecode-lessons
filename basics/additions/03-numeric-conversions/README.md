# 03. Числа, диапазоны и преобразования

## Версия C++

`auto` — **C++11**.
`std::exception`, `std::size_t` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Проверяйте допустимость преобразования до него. Смешивание `signed` и
`unsigned` может превратить отрицательное значение в большое положительное.
Переполнение знакового целого — неопределённое поведение; беззнаковая арифметика
модульная, но это не обязательно желаемый результат. Числа с плавающей точкой
имеют ограниченную точность; сравнение должно учитывать масштаб и требования
задачи, а не универсальную одну epsilon. `static_cast` делает преобразование явным,
но сам по себе не проверяет диапазон.

## Как это работает

Нужны целые и вещественные типы, индексы и арифметика.

В проверке индекса сначала проверяется `negative >= 0` и только затем
выполняется `static_cast<std::size_t>`. Короткое замыкание && не даёт
преобразовать отрицательное число как допустимый индекс.

~~~cpp
index >= 0 && static_cast<std::size_t>(index) < length
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

`can_add_one` сравнивает с `max` **до** сложения. Проверять переполнение
после знакового a + 1 уже поздно: само переполнение недопустимо.
Беззнаковая арифметика работает по модулю, но её циклическое значение
не обязательно корректно для размера или баланса.

5 / 2 даёт 2; 5.0 / 2 — 2.5. Для обычной двоичной `double`-среды
0.1 + 0.2 отличается от 0.3 из-за представления дробей.
Проверка numeric_limits описывает реализацию: число значащих битов `int`
нельзя универсально заменить предположением «везде 32 бита».
Приближённое сравнение чисел требует допуска, выбранного по смыслу задачи.

### `main2.cpp`: расширение и отбрасывание дробной части

`int whole = 5` преобразуется в `double` со значением `5`.
Затем `2.75` преобразуется в `int` двумя явными формами:
`(int)fraction` и `static_cast<int>(fraction)`. Обе дают `2`:
дробная часть отбрасывается в направлении нуля, округления до ближайшего нет.
`static_cast` явно называет вид преобразования, но сам не проверяет диапазон.

Ввод не нужен. Вывод `5 2 2` и `OK moved-example-061`; код `0`.
Все возможности этого варианта есть в C++98. Нельзя переносить пример
на дробь за диапазоном `int`: такое преобразование не становится безопасным
от добавления `static_cast`.

(на Linux команда Python обычно называется python3).

## Типичные ошибки

Проверяйте знак индекса до преобразования в `size_t`. Переполнение знакового целого не является переносимым циклическим счётом. Приведение к `int` отбрасывает дробную часть, но само по себе не проверяет представимость результата.

### Самостоятельно

Напишите checked_add для двух `int` без выполнения переполняющего выражения. Проверьте обе границы диапазона.
