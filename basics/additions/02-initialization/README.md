# 02. Инициализация и `initializer_list`

## Версия C++

списковая инициализация, `std::initializer_list` — **C++11**.
`std::vector`, `std::exception` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Фигурные скобки запрещают многие сужающие преобразования и могут
предпочесть initializer_list-конструктор. Поэтому `vector(3, 7)` создаёт три семёрки,
а `vector{3, 7}` — два заданных элемента. `int{}` инициализируется нулём; простой
локальный `int` без инициализации читать нельзя. Список `initializer_list` хранит
`const`-элементы и имеет ограниченное время жизни: не сохраняйте ссылку на временный список.

## Как это работает

Нужны конструкторы, массивы и `vector`.

Скобки участвуют в выборе конструктора, а не просто оформляют список:

~~~cpp
std::vector<int> sizeAndValue(3, 7);
std::vector<int> elements{3, 7};
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Поэтому печатается (3,7): 3; {3,7}: 2.
`int zero{}` равен нулю. `int narrowing{number}` при `double number = 3.5`
закомментирован, потому что такая инициализация списком запрещает сужение.
Явный `static_cast<int>(number)` разрешает выбранное преобразование и даёт 3.

{} не гарантирует самый желаемый конструктор: перегрузка `initializer_list`
может иметь приоритет. У пользовательского типа всегда смотрите набор
конструкторов. Пустые () в записи `T object();` могут объявить функцию;
форма T object{} обычно избегает этой неоднозначности.

### `main2.cpp`: список значений и объявление функции

`sum(std::initializer_list<int> values)` принимает список значений.
`sum({1, 2, 3})` даёт `6`, `sum({})` — `0`.
Элементы `initializer_list` доступны как константные; хранить ссылку на такой
временный список за пределами его времени жизни нельзя.

`Object instance{}` создаёт объект с полем `7`.
`Object function()` **объявляет функцию**, возвращающую `Object`,
а не создаёт объект. В коде это подтверждает `static_assert` с `is_function`.
Функция не вызывается, поэтому её определение здесь не требуется.
Компилятор может предупредить о неоднозначной для читателя записи — это
ожидаемая диагностика учебного объявления.

Вывод: `Object: 7; list sum: 6` и `OK initializer-list`.
Ввода и файлов нет; успех — `0`, провал проверки — `1`.
Для сборки замените `main` на `main2` в командах этого урока.

## Типичные ошибки

Не путать `vector<int>(3,7)` с `vector<int>{3,7}`: первый создаёт три семёрки, второй — два элемента. `Object function()` объявляет функцию. Списковая инициализация отвергает сужение; явное приведение требует отдельной проверки диапазона.

Сравните `auto` a = {1, 2}, `auto` b{1} и `std::array`. Для каждого запишите ожидаемый тип через `static_assert`.
