# 28. Часовые пояса и местное время

## Версия C++

База часовых поясов и `zoned_time` — C++20. Режим сборки — **C++20**. Для этой конфигурации нужен GCC 16+.

## Что изучаем

Связываем абсолютный момент с гражданским временем выбранного региона. Сначала изучите календарь.

## Примеры

- [main.cpp](main.cpp) — один момент на двух шкалах; вывод `12:00 UTC -> 07:00 America/New_York`.
- [main2.cpp](main2.cpp) — весенний пропуск и осеннее повторение времени; вывод `60` минут.

## Как это работает

`sys_seconds` задаёт абсолютный момент, `local_seconds` — местные календарные часы
без выбранного пояса. `locate_zone` находит именованный пояс в базе IANA.
`zoned_time` объединяет пояс и момент; зимой 1 января 2024 года 12:00 UTC
соответствует 07:00 в `America/New_York`.

Момент переводится в местное время однозначно, обратное преобразование — не всегда.
При весеннем переводе часов показанного региона 02:30 не существовало;
при осеннем 01:30 встречалось дважды. `get_info(local)` сообщает `unique`,
`nonexistent` или `ambiguous`; `to_sys(local)` без выбора бросает соответствующее исключение.
Для повторяющегося времени `choose::earliest/latest` выбирает один из двух моментов.
Для пропущенного времени обе формы выбора возвращают границу перехода;
это не означает, что введённые часы существовали.

Примеры используют фиксированные исторические даты, а не текущие часы компьютера.
Обновление базы может менять исторические правила; база и библиотека являются
отдельными требованиями. Локальное время нельзя заменять постоянным смещением:
у именованного пояса оно зависит от даты.

## Сборка и запуск

[Настройка и запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).
Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh basics/additions/28-time-zones/main.cpp
./build/basics/additions/28-time-zones/main
```

Для второго примера соберите `main2.cpp` и запустите `main2` из того же каталога сборки.
На Windows из MSYS2 Bash используйте `scripts/build-windows.sh` и файл
`build/basics/additions/28-time-zones/main.exe`. Конфигурации F5/Ctrl+F5 находятся в `.vscode/`.

Интерактивного ввода и сетевых служб нет. Программы не создают пользовательские файлы.
Каждый вариант проверяет результат:
последняя строка `OK reference-example`, код завершения `0`;
нарушение проверки или необработанная ошибка — код `1`.
Для запуска нужна доступная библиотеке база IANA tzdata с `America/New_York`. Программы читают её через `chrono`, не обновляют и не скачивают. Отсутствие базы — ошибка с кодом `1`.

## Типичные ошибки

`current_zone()` зависит от настроек компьютера, поэтому для воспроизводимости
здесь явно задан пояс. Отсутствующая зона или база вызывает ошибку, а не неявный
переход к UTC. База не скачивается примером; требуется установленная IANA tzdata.
Объекты `time_zone` принадлежат базе; не освобождайте полученный указатель через `delete`.
