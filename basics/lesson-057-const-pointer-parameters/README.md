# 057. const в параметрах и указателях

## Версия C++

C++98 — `const` в параметрах-указателях. Сборка проекта: **C++17**.

## Что изучаем

const в объявлении параметра-указателя может запрещать менять адрес, сохраняя доступ к элементам.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Как это работает

`FillArray(int* const arr, const int size, const int max)` не может переназначить локальный `arr`, но может выполнять `arr[i] = ...`. Константность `size` и `max` также относится к локальным параметрам. Вызов использует `size = 5`, `max = 100` и заполняет массив случайными значениями `0–99`.

`ShowArray` выводит элементы, затем `main()` освобождает память через `delete[] arr`. Для запрета изменения элементов через указатель нужен другой тип — `const int*`. Это не то же самое, что `int* const`.

- Добавлен пропущенный `delete[] arr`; исправлены название темы в комментарии и диапазон `0–max-1`. Сохранены `FillArray`, `ShowArray` и параметры `5/100`.
- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

## Типичные ошибки

Путать константность указателя и элементов; передавать `max = 0` в выражение `rand() % max`; забывать освобождение выделенного массива.
