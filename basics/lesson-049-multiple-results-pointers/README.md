# 049. Несколько результатов через указатели

## Версия C++

C++98 — возврат нескольких результатов через указатели. Сборка проекта: **C++17**.

## Что изучаем

Несколько объектов можно изменить за один вызов через указатели или ссылки.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа.

## Как это работает

Первый вариант `foo(int*, int*, int*)` получает адреса `a = 0`, `b = 0`, `c = 1` и меняет их на `555`, `1` и `-20`. Вызов передаёт `&a`, `&b` и `&c`.

Второй вариант `foo2(int&, int&, int&)` работает с другими переменными `a2 = 0`, `b2 = 4`, `c2 = 34`. Он задаёт `a2 = 10`, удваивает `b2` до `8` и уменьшает `c2` до `-66`. Адресный оператор при таком вызове не нужен: параметры объявлены ссылками.

- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

## Сборка и запуск

[Запуск в VS Code](../../README.md#сборка-и-запуск-в-vs-code) ·

Откройте `main.cpp` этого урока. Ввод не нужен. Печатаются значения до и после обоих вызовов: итог указателей `555, 1, -20`; итог ссылок `10, 8, -66`.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Считать два варианта работающими с одним набором переменных; забывать разыменование в варианте с указателями.
