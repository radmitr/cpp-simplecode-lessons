# Урок 141. Объединения `union`

Предварительно: Представление чисел, память и пользовательские типы.

## Примеры

- [main.cpp](main.cpp): Записывает разные члены одного `union` и выводит все поля.

Каждый `main*`.cpp — отдельная программа.

## Механизм и разбор

У членов `union` общая область хранения; размер должен позволять хранить
наиболее требовательный член с нужным выравниванием, а не сумму всех полей.
Запись в один член меняет активное представление.

Текущий `printMyUnion` выводит и неактивные члены. Такой приём нельзя считать
переносимым способом получить корректные значения другого типа.
Наблюдаемые «странные числа» не являются гарантированным преобразованием `int`/`double`.

Для безопасного выбора одного из типов подходит `std::variant` с учётом
активного варианта. Для копирования представления подходящих trivially-copyable
типов есть bit_cast в C++20 с отдельными ограничениями.
У `union` с нетривиальными полями дополнительно требуется управлять
их созданием и уничтожением; простой сырой дамп этой задачи не решает.

## Запуск и результат

F5 — запуск с отладчиком; Ctrl+F5 — без отладчика.

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5/Ctrl+F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-141-union/main.cpp"
```

На Linux используйте `scripts/build-linux.sh` с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Файл демонстрирует общую память членов, но вывод неактивных членов нельзя считать переносимым или предсказывать как корректный результат.

## Что важно понять

Пример читает неактивные члены `union`: в общем случае это неопределённое поведение в стандартном C++, даже если компилятор допускает такое расширение. Для безопасного выбора одного из нескольких типов предназначен `std::variant`; `union` требует отслеживать активный член.
