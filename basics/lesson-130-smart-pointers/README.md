# Урок 130. Учебный умный указатель

Предварительно: Шаблоны, деструкторы, new/delete и перегрузка операторов.

## Примеры

- [main.cpp](main.cpp): Владеет одним объектом через SmartPointer<T>; запрещает копирование и освобождает память в деструкторе.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-130-smart-pointers/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

После Constructor выводятся значение 5 и адрес, а при выходе из main — Destructor.

## Что важно понять

Это ограниченный учебный владелец одного объекта: нет полной семантики std::unique_ptr, поддержки массивов и перемещения. Основной принцип объясняет бонус 02-raii.
