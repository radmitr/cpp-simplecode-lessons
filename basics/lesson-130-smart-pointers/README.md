# Урок 130. Учебный умный указатель

Предварительно: Шаблоны, деструкторы, `new`/`delete` и перегрузка операторов.

## Примеры

- [main.cpp](main.cpp): Владеет одним объектом через `SmartPointer<T>`; запрещает копирование и освобождает память в деструкторе.

Каждый `main*`.cpp — отдельная программа.

## Механизм и разбор

`SmartPointer<int>` принимает владение `new int(5)`.
`operator*` даёт доступ к `int`, `operator-`> показывает сохранённый адрес,
деструктор освобождает ресурс при выходе из области видимости.

Сам сырой указатель таким свойством не обладает. Запрет копирования
не позволяет получить двух независимых владельцев одного `int`.
Для перемещения, массивов и собственного deleter нужны отдельные правила.

Эта обёртка иллюстрирует RAII, но не повторяет весь контракт `unique_ptr`.
Не передавайте ей адрес локальной переменной или ресурс `new[]`, если удаление
реализовано обычным `delete`. Для прикладного кода используйте готовый
`std::unique_ptr` и `make_unique`.

## Запуск и результат

F5 — запуск с отладчиком; Ctrl+F5 — без отладчика.

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5/Ctrl+F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-130-smart-pointers/main.cpp"
```

На Linux используйте `scripts/build-linux.sh` с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

После Constructor выводятся значение 5 и адрес, а при выходе из `main` — Destructor.

## Что важно понять

Это ограниченный учебный владелец одного объекта: нет полной семантики `std::unique_ptr`, поддержки массивов и перемещения. Основной принцип объясняет бонус 02-raii.
