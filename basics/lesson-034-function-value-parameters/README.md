## Как это работает

`sum(double a, double b, double c)` складывает три параметра. Вызов `sum(2.55, 7.67, 23.81)` передаёт три значения, а `return a + b + c` возвращает результат. Вывод показывает `SUM = 34.03` при обычной точности потока.

Изменение параметра по значению не изменило бы переменную вызывающего кода. Здесь параметры только читаются; отдельный [пример передачи по значению, ссылке и указателю](../lesson-051-reference-parameters/README.md) показывает изменение на практике. Дробные десятичные значения обычно представляются приближённо.

- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.
