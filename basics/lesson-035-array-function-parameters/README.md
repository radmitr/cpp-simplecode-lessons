# 035. Массив как параметр функции

## Версия C++

C++98 — параметры-массивы и явная передача размера. Сборка проекта: **C++17**.

## Что изучаем

При передаче массива в функцию отдельно передаём число элементов.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа.

## Как это работает

`FillArray(arr, size)` заполняет элементы через `rand() % 10`, а `PrintArray(arr, size)` печатает индекс и значение. В `main()` массив `massiv` содержит `10` элементов. Сначала он полностью заполняется, затем читается.

Параметр `int arr[]` в такой записи функции означает указатель на первый элемент. Функция не получает размер массива автоматически, поэтому аргумент `size` должен соответствовать доступной памяти. Изменения `arr[i]` видны вызывающему коду.

- Исправлено нестандартное `void main()` на `int main()`; диапазон случайных чисел в комментарии — `0–9`.
- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

## Типичные ошибки

Вычислять число элементов через `sizeof(arr)` внутри функции, где `arr` уже параметр-указатель; передавать размер больше реального.
