# 067. Макросы с параметрами

## Версия C++

C++98 — функциональные макросы. Сборка проекта: **C++17**.

## Что изучаем

Функциональный макрос подставляет выражение с переданными токенами.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

`#define FOO(x,y) ((x)*(y))` заменяет `FOO(5, 6)` выражением `((5)*(6))`, результат — `30`. Скобки вокруг аргументов и всего выражения защищают группировку при подстановке более сложных выражений.

Это не вызов функции: у макроса нет собственных параметров-переменных и проверки типов. В других определениях повторная подстановка аргумента может несколько раз выполнить побочный эффект. Для обычных вычислений функция или шаблон обычно удобнее.

## Типичные ошибки

Убирать защитные скобки; передавать изменения переменных в макрос, не понимая, сколько раз аргумент подставляется.
