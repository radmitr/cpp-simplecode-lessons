# Урок 64. Конкатенация строк

Предварительно: Массивы char, нулевой символ и std::string.

## Примеры

- [main.cpp](main.cpp): Объединяет C-строки через strcat в заранее выделенном буфере.
- [main2.cpp](main2.cpp): Объединяет std::string через operator+.

Каждый main*.cpp — отдельная программа.

## Механизм и разбор

В main.cpp result сначала содержит нулевой символ. strcat находит этот
нуль и дописывает байты первого, затем второго слова: получается HelloWorld.
Для Hello нужны шесть char, включая завершающий нуль, поэтому str1[6] подходит.

strcat не знает размер назначения. Перед вызовом нужно обеспечить место
для прежнего текста, добавляемого текста и одного '\0'.
Ненуль-терминированный ввод и перекрывающиеся области не поддерживаются.

main2.cpp использует std::string: размер и буфер управляются объектом,
оператор + добавляет запятую, пробел и !!!. Результат — Hello, World!!!.
Два строковых литерала сами по себе не складываются бинарным +;
хотя бы соответствующий операнд должен поддерживать строковую операцию.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-064-string-concat/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Первый пример формирует HelloWorld, второй — Hello, World!!!.

## Что важно понять

strcat не проверяет ёмкость буфера: нужны место под все байты и завершающий нуль, а также корректные исходные C-строки. std::string управляет памятью, но индексы строки всё ещё относятся к её элементам char, а не к символам Unicode.
