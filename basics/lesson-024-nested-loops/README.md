# 024. Вложенные циклы

## Версия C++

C++98 — вложенные циклы. Сборка проекта: **C++17**.

## Что изучаем

Вложенный цикл выполняет внутренний обход для каждой итерации внешнего.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

Внешний `i` принимает `1–4`, внутренний `j` каждый раз начинается с `0` и проходит `0–4`. Поэтому внутреннее тело выполняется `4 × 5 = 20` раз. Перед очередным внутренним обходом программа печатает значение внешнего счётчика.

Счётчики принадлежат разным циклам. Увеличение `j` не меняет `i`. Только когда внутренний цикл заканчивается, внешний делает свой следующий шаг.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Перемножать включённые границы неправильно: `i < 5` при старте с `1` означает четыре итерации; забывать, что `j` начинается заново.
