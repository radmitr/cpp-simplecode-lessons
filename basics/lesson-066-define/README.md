# 066. Препроцессор и define

## Версия C++

C++98 — объектоподобные макросы #define. Сборка проекта: **C++17**.

## Что изучаем

Препроцессор заменяет объектоподобный макрос указанной последовательностью токенов.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа.

## Как это работает

`#define PI 3.14` и `#define tab "\t"` действуют до компиляции. В выражениях вместо `PI` подставляется литерал, вместо `tab` — строка табуляции. Программа сравнивает непосредственно записанное `\t` с использованием макроса.

Макрос не является переменной, не имеет обычной области видимости и не проверяется как отдельный тип. Для обычных констант обычно удобнее `const` или `constexpr`. Закомментированные макросы, заменяющие фигурные скобки, не используются.

- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

Ставить точку с запятой в определении макроса константы или считать макрос обычной переменной с типом.
