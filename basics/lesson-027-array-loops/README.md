# 027. Заполнение и вывод массива циклом

## Версия C++

C++98 — заполнение массива через `rand()` % 100; C++11 — списковая инициализация без =. Сборка проекта: **C++17**.

## Что изучаем

Заполняем массив в одном цикле и выводим в другом.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

В массиве `arr` пять элементов. Изначальный список `{55, 511, 2, 123, 95}` полностью перезаписывается: для каждого индекса выполняется `arr[i] = rand() % 100`. Остаток от деления даёт диапазон `0–99`. Второй цикл только читает уже заполненный массив.

`srand()` здесь не вызывается. Повторный запуск одной реализации обычно повторяет исходную последовательность, но разные стандартные библиотеки могут выдавать разные числа. Конкретные пять значений не являются переносимым ожидаемым результатом. `rand() % 100` также не гарантирует идеально равномерное распределение.

## Типичные ошибки

Ожидать вывода первоначальных значений или последовательности `0, 10, 20…`; считать диапазоном `1–100`; добавлять выход за индекс `4`.
