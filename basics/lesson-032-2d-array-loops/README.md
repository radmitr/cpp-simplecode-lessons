# 032. Заполнение и вывод двумерного массива

## Версия C++

C++98 — обход двумерного массива вложенными циклами; C++11 — списковая инициализация без =. Сборка проекта: **C++17**.

## Что изучаем

Два вложенных цикла позволяют заполнить и вывести матрицу.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

`ROWS = 5` задаёт пять строк, `COLS = 8` — восемь столбцов. При заполнении внешний `i` выбирает строку, внутренний `j` — элемент в ней. `rand() % 10` даёт `0–9`. Для вывода выполняется отдельная пара циклов с табуляцией между числами и переводом строки после каждой строки матрицы.

Всего сохраняются и печатаются `5 × 8 = 40` значений. Начальная нулевая инициализация есть, но затем каждый элемент перезаписывается случайным значением.

## Типичные ошибки

Менять границы местами или ожидать числа `1–10` вместо `0–9`; проверять точные случайные значения разных библиотек.
