# 047. Арифметика указателей

## Версия C++

C++98 — арифметика указателей внутри массива. Сборка проекта: **C++17**.

## Что изучаем

Арифметика указателей позволяет проходить элементы одного массива.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

Массив содержит `{4, 55, 79, 1, 4}`. Сначала значения читаются через `arr[i]`, затем через `pArr[i]` после `int* pArr = arr`. Последующие циклы используют `*(pArr + i)` и `*(arr + i)`. Все четыре обхода читают одни и те же элементы.

Прибавление `1` к `int*` означает переход к следующему `int`, а не к следующему байту. Массив и указатель не один тип: во многих выражениях имя массива преобразуется в адрес первого элемента. Адрес начала `arr` совпадает со значением `pArr`.

Вычислять указатели можно внутри массива и на позицию сразу после конца; разыменовывать позицию после конца нельзя.

## Типичные ошибки

Разыменовывать `arr + SIZE` или выполнять арифметику между несвязанными объектами; путать массив с переменной-указателем.
