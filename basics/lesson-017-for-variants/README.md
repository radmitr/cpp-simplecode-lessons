# 017. Варианты записи for

## Версия C++

C++98 — варианты записи цикла `for`. Сборка проекта: **C++17**.

## Что изучаем

Поля заголовка for могут быть пустыми, а в цикле можно менять несколько переменных.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

Первый цикл использует ранее объявленную `i` и печатает `0–9`. Второй продолжает с оставшегося значения `10` и печатает `10–19`. Третий снова задаёт `i = 0`, но шаг `i++` размещён внутри тела — вывод опять `0–9`.

В четвёртом цикле новая `i` увеличивается от `0`, а `j` уменьшается от `10`. Условие `i < 10 && j != 5` заканчивает работу после пяти пар: `(0,10)`, `(1,9)`, `(2,8)`, `(3,7)`, `(4,6)`. Бесконечный `for (;;)` в исходнике закомментирован и не запускается.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Не замечать сохранения `i` между первыми двумя циклами; печатать `i` под подписью `j`; запускать бесконечный вариант без условия выхода.
