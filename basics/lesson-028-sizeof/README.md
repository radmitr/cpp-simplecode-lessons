# 028. Размер объекта: sizeof

## Версия C++

C++98 — sizeof типов и переменной. Сборка проекта: **C++17**.

## Что изучаем

Оператор sizeof сообщает размер типа или объекта в байтах C++.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

Программа выводит `sizeof(int)`, `sizeof(double)` и `sizeof(a)` для переменной `int a`. Последний результат совпадает с размером `int`. Значение `a` не читается: обычный операнд `sizeof` не вычисляется, поэтому это не чтение неинициализированного числа.

Результат имеет тип `std::size_t`. Размеры зависят от реализации; байт C++ определяется через `sizeof(char) == 1`. Подсчёта элементов массива в этом исходном примере нет.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Считать размеры `int` и `double` одинаковыми на всех реализациях; переносить правило невычисляемого операнда `sizeof` на обычные выражения.
