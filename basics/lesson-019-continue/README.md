# 019. Переход к следующей итерации: continue

## Версия C++

C++98 — переход к следующей итерации через `continue`. Сборка проекта: **C++17**.

## Что изучаем

Инструкция continue пропускает остаток текущей итерации.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

В цикле `i` проходит `0–4`. При `i == 2` выполняется `continue`, поэтому строка вывода в теле пропускается. Затем выполняется шаг цикла `i++` и начинается следующая итерация.

В отличие от `break`, цикл продолжается. В `while` изменение счётчика перед `continue` нужно продумать отдельно: там нет отдельного поля шага.

## Типичные ошибки

Путать `continue` с выходом из цикла; создавать бесконечный `while`, перескакивая через увеличение счётчика.
