# 048. Параметр-указатель

## Версия C++

C++98 — передача указателя в функцию. Сборка проекта: **C++17**.

## Что изучаем

Сравниваем изменение копии аргумента и изменение объекта через указатель.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

`Foo(int aa)` увеличивает свою локальную копию. Поэтому `aa` в `main()` остаётся `0` после `Foo(aa)`. Затем `Foo2(int* pa, int* pb)` получает адреса двух других переменных: `(*pa)++` меняет первую на `1`, `*pb = 555` записывает `555` во вторую.

Сами параметры-указатели передаются по значению, но разыменование обращается к исходным объектам. Скобки в `(*pa)++` важны: `*pa++` увеличивало бы указатель, а не само число.

## Типичные ошибки

Путать изменение указателя и объекта по его адресу; передавать нулевой или недействительный адрес.
