## Версия C++

## Как это работает

После ввода `size` создаётся `new int[size]`. Генератор инициализируется текущим временем; цикл заполняет элементы через `rand() % 100`. Второй цикл выводит адрес каждого элемента и его значение двумя способами: `arr[i]` и `*(arr + i)`.

Оба способа должны давать одно значение. После обхода `delete[] arr` освобождает весь массив. Размер проверяется в пределах `1–100`. При нехватке памяти `new` может выбросить `std::bad_alloc`; в этом примере отдельного обработчика выделения нет.

- Добавлены проверка размера `1–100` и пропущенный `delete[] arr`; сохранены случайное заполнение, адреса и оба способа чтения.
- Добавлена проверка состояния ввода до использования прочитанных значений; ошибка приводит к коду `1`.
- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

## Сборка и запуск

[Запуск в VS Code](../../README.md#сборка-и-запуск-в-vs-code) ·
[Команды Windows/Linux из терминала](../../README.md#сборка-из-терминала).

Откройте `main.cpp` этого урока. Введите размер `1–100`, например `5`. Будет столько же записей с адресом и двумя одинаковыми значениями `0–99`. Неверный размер или текст дают код `1`.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Забывать `delete[]`, применять обычный `delete` к массиву или ожидать одинаковых случайных значений и адресов при каждом запуске.
