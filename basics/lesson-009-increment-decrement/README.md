# 009. Префиксные и постфиксные ++ и --

## Версия C++

## Как это работает

Для `a = 1` выражение `a++` передаёт в поток прежнее значение `1`, а сама переменная становится `2`. Следующий вывод показывает `2`. Для `b = 1` выражение `++b` сначала меняет переменную и сразу даёт `2`. Подписи «до», «после» и «финал» позволяют проследить изменение значений.

В последней части `a` снова получает `1`, затем отдельный `++a` делает его равным `2`, и `b = a * a` даёт `4`. Эти действия разделены: исходное `b = ++a * a` имеет неопределённое поведение из-за несогласованного изменения и чтения `a`.

- Небезопасное `b = ++a * a` разделено на `++a;` и `b = a * a;`. Сохраняется предполагаемый результат `4` без неопределённого поведения.
- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

## Типичные ошибки

Использовать несколько несогласованных чтений и изменений одной переменной в выражении. Префиксная и постфиксная формы дают разные значения выражения.
