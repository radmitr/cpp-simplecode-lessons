# 037. Глобальные и локальные переменные

## Версия C++

C++98 — локальные и глобальные переменные, области видимости. Сборка проекта: **C++17**.

## Что изучаем

Область видимости определяет, где можно обращаться к имени переменной.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа.

## Как это работает

Глобальная `value` объявлена до функций. В `main()` переменная `b` видна и во внутреннем блоке: там ей присваивается `1`. Внутренняя `a = 0` существует только в блоке `if`. После блока объявляется другая `a = 123`, а `b` получает `2`.

Ещё один внутренний блок ограничивает имя `v`. В конце `value = 2` меняет глобальную переменную. Функция `foo()` определена, но не вызывается: её присваивание `value = 1` не выполняется. Неинициализированная `b` получает значение до каждого чтения.

- Исправлены комментарии об области видимости глобальной переменной и о недопустимости чтения локального неинициализированного `int`.
- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

Откройте `main.cpp` этого урока. Ввод не нужен. В блоке `if` выводятся `a = 0` и `b = 1`, в `main()` — `a = 123` и `b = 2`.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Считать, что объявление функции выполняет её тело; обращаться к `v` вне блока; читать локальную переменную без присваивания.
