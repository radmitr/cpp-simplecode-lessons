# Урок 29. Псевдослучайные числа: rand и `srand`

## Версия C++

`std::size_t` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Предварительно: Массивы, циклы, остаток от деления.

## Примеры

- [main.cpp](main.cpp): Заполняет массив из десяти элементов значениями `rand()` % 100.

Каждый `main*.cpp` — отдельная программа.

## Как это работает

rand возвращает псевдослучайное целое, % 100 оставляет остаток 0…99.
`srand(time(nullptr))` выбирает начальное состояние один раз перед циклом.
Программа печатает десять чисел, а не фиксированный заранее набор.

Одинаковое начальное состояние воспроизводит последовательность данной
реализации. Запуски в одну секунду могут получить одинаковый seed.
Переносить `srand` внутрь цикла не надо: генератор будет начинаться заново.

Остаток по модулю может смещать вероятности; rand не предназначен
для секретов. Современные движок и distribution разделены в
[бонусе random](../bonus/28-random/README.md).

## Типичные ошибки

`srand` задаёт начальное состояние, а не делает генератор криптографически стойким. Остаток от деления может давать неравномерное распределение. Продолжение темы — генераторы и распределения из `<random>`.
