# Урок 29. Псевдослучайные числа: rand и srand

Предварительно: Массивы, циклы, остаток от деления.

## Примеры

- [main.cpp](main.cpp): Заполняет массив из десяти элементов значениями rand() % 100.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-029-rand/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Выводятся десять чисел от 0 до 99; конкретные числа зависят от начального состояния генератора.

## Что важно понять

srand задаёт начальное состояние, а не делает генератор криптографически стойким. Остаток от деления может давать неравномерное распределение. Продолжение темы — генераторы и распределения из <random>.
