# 053. Динамическая память: new и delete

## Версия C++

C++98 — выделение и освобождение памяти через `new` и `delete`. Сборка проекта: **C++17**.

## Что изучаем

new создаёт объект в динамической памяти, а delete завершает его жизнь и освобождает память.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа.

## Как это работает

`int* pa = new int` получает указатель на один `int`. Без инициализатора его исходное числовое значение не задано, поэтому перед чтением выполняется `*pa = 10`. Затем программа выводит адрес и сохранённое `10`, после чего делает `delete pa`.

Указатель — отдельная локальная переменная. `delete` не обнуляет её автоматически. После удаления обращаться к прежнему объекту нельзя. Если выделение не удалось, обычный `new` выбрасывает `std::bad_alloc`; обработчика в этом коротком примере нет.

- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Читать `*pa` до присваивания; использовать объект после `delete`; путать `delete` одного объекта и `delete[]` массива.
