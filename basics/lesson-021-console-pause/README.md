# 021. Почему закрывается консоль

## Версия C++

C++98 — ожидание ввода через `std::cin`.`get()`. Сборка проекта: **C++17**.

## Что изучаем

Учебная пауза позволяет оставить программу ждать действия пользователя.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

После вывода пяти названий чисел программа вызывает `cin.get()`. В обычном терминале ввод построчный: нажмите Enter, чтобы передать символ и продолжить выполнение. После этого `main()` возвращает `0`.

В источнике использована Windows-команда `system("pause")`. Здесь сохранена сама пауза, но она реализована средствами C++, доступными на обеих ОС. `cin.get()` читает один символ: после предыдущего `>>` он мог бы сразу получить оставшийся перевод строки. В этом примере предыдущего ввода нет. При завершившемся входном потоке ожидания также не будет.

Откройте `main.cpp` этого урока. Запускайте в терминале. После строк `Один`–`Пять` появляется приглашение нажать Enter; до ввода программа ожидает. В автоматической проверке передаётся `\n`.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Считать `cin.get()` универсальной командой «нажмите любую клавишу»; не учитывать уже находящиеся во входном буфере символы.
