# 056. Двумерный динамический массив

## Версия C++

C++98 — динамический массив указателей на строки. Сборка проекта: **C++17**.

## Что изучаем

Матрицу можно представить массивом указателей на отдельно выделенные строки.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

Сначала читаются `rows` и `cols`, затем `new int*[rows]` создаёт массив указателей. Каждый `arr[i]` получает отдельный `new int[cols]`. Поэтому строки не обязаны располагаться подряд в памяти. Выражение `arr[i][j]` сначала выбирает строку, затем элемент этой строки.

Вложенные циклы записывают `rand() % 20` и выводят матрицу. Очистка выполняется в обратном порядке уровней: `delete[] arr[i]` для каждой строки, затем `delete[] arr` для массива указателей.

До выделения строк указатели обнуляются. Если очередной `new` выбросит исключение, обработчик освободит уже созданные строки и массив указателей. `delete[]` нулевого указателя допустим, поэтому невыделенные строки не мешают очистке.

## Сборка и запуск

[Запуск в VS Code](../../README.md#сборка-и-запуск-в-vs-code) ·
[Команды Windows/Linux из терминала](../../README.md#сборка-из-терминала).

Откройте `main.cpp` этого урока. Введите два размера `1–100`, например `2 3`. Получится две строки по три числа `0–19`. Неверный ввод или отказ выделения очередной строки дают код `1`; отказ самого первого `new` остаётся необработанным исключением.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Удалять только верхний массив указателей и терять строки; считать `int**` одним сплошным прямоугольным блоком; не очищать частично созданную матрицу.
