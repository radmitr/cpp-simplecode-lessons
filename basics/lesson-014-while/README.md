# 014. Цикл while

## Версия C++

C++98 — цикл `while`. Сборка проекта: **C++17**.

## Что изучаем

Цикл while проверяет условие до каждой итерации.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа.

## Как это работает

`a` начинается с `0`. Пока `a < 10`, программа печатает текущее значение и увеличивает его постфиксным `a++`. Получаются `0–9`. После последней итерации `a = 10`, условие ложно и цикл заканчивается.

Если условие ложно при первой проверке, тело не выполняется ни разу. Если убрать изменение `a`, этот конкретный цикл будет бесконечным.

- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

Откройте `main.cpp` этого урока. Ввод не нужен. Десять строк показывают `a` от `0` до `9`; программа завершается самостоятельно.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Забывать менять переменную условия; ожидать, что условие `a < 10` включает значение `10`.
