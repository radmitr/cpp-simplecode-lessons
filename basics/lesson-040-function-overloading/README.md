# 040. Перегрузка функций

## Версия C++

C++98 — перегрузка функций. Сборка проекта: **C++17**.

## Что изучаем

Перегрузки позволяют использовать одно имя функции для разных списков параметров.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа.

## Как это работает

В исходнике есть `Sum(int, int)`, `Sum(double, double)` и `Sum(int, int, int)`. Вызовы `Sum(1, 2)`, `Sum(10.5, 5.1)` и `Sum(2, 3, 7)` выбирают разные определения и дают `3`, `15.6` и `12`.

Выбор происходит при компиляции по аргументам. Одного различия возвращаемого типа недостаточно для создания перегрузки. Если несколько кандидатов подходят одинаково хорошо, вызов может оказаться неоднозначным.

- Три перегрузки `Sum` вызываются с разными аргументами и возвращают `3`, `15.6` и `12`.
- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

## Типичные ошибки

Создавать две функции с одинаковыми параметрами, меняя только тип результата; путать перегрузку и рекурсивный вызов.
