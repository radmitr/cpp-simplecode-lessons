# 022. Переход goto

## Версия C++

C++98 — переход `goto` и метки. Сборка проекта: **C++17**.

## Что изучаем

Переход goto продолжает выполнение с указанной метки.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

Сначала печатается `Один`, затем `goto link` перескакивает через инструкции `Два` и `Три`. Выполнение продолжается у метки `link:` и печатает `Четыре` и `Пять`.

Метка относится к той же функции. Переход не является вызовом функции и не создаёт точки возврата. Для обычных повторений и ветвлений удобнее структурные конструкции `for`, `while` и `if`.

## Типичные ошибки

Ожидать возврата к инструкции после `goto`; перескакивать через обязательную инициализацию локальных объектов.
