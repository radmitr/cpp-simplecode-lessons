# 038. Аргументы по умолчанию

## Версия C++

C++98 — аргументы функций по умолчанию. Сборка проекта: **C++17**.

## Что изучаем

Аргументы по умолчанию подставляются, если соответствующие последние аргументы не указаны.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

Сигнатура `foo(int q, int a = 5, double b = 0.5)` требует `q`, а `a` и `b` могут быть опущены. Тело использует только `a` как число звёздочек. Поэтому `foo(2)` печатает пять, `foo(4, 24)` — двадцать четыре, `foo(4, 10, 1.5)` — десять, `foo(4)` — снова пять.

Наличие параметра ещё не означает, что он влияет на тело: `q` и `b` в этом примере не используются. Аргументы нельзя пропустить посередине, оставив значение следующего параметра.

## Типичные ошибки

Принимать первый аргумент за количество звёздочек; считать, что значения по умолчанию заменяют явно переданный аргумент.
