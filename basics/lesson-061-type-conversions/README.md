# 061. Неявное и явное преобразование типов

## Версия C++

C++98 — преобразование `int` в `char` в стиле C. Сборка проекта: **C++17**.

## Что изучаем

Явное преобразование int в char показано на переборе байтовых кодов.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят фрагмент общего исходника; весь объединённый пример целиком здесь не воспроизводится.

## Как это работает

Программа выводит `sizeof(char)`, затем для каждого `i` от `0` до `255` печатает число и результат `(char)i`. Это исходная запись приведения в стиле C. Цикл включает оба края диапазона — всего `256` записей.

Не все полученные символы видимы: есть нулевой байт, табуляция, переводы строк и другие управляющие коды. Байты `128–255` сами по себе не образуют универсальную таблицу букв UTF-8. Для знакового `char` преобразование больших значений в режиме C++17 зависит от реализации; на используемых Windows/Linux сохраняется младший байт.

Более безопасный для чтения обзор `static_cast` и числовых преобразований есть в [бонусе «Числа, диапазоны и преобразования»](../bonus/05-numeric-conversions/README.md).

## Сборка и запуск

[Запуск в VS Code](../../README.md#сборка-и-запуск-в-vs-code) ·
[Команды Windows/Linux из терминала](../../README.md#сборка-из-терминала).

Откройте `main.cpp` этого урока. Ввод не нужен. Начало: `CHAR = 1 byte`; далее записи `code = ... char = ...` для `0–255`. Вывод содержит управляющие и невалидные для UTF-8 байты. Автоматическая проверка сравнивает байты, а не декодирует их как обычный текст.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Ожидать `256` аккуратных строк терминала: часть выведенных байтов сама меняет расположение текста; считать все `0–255` кодами ASCII или отдельными UTF-8-символами.
