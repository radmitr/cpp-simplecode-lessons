# 026. Инициализация массива

## Версия C++

[main.cpp](main.cpp) — самостоятельная программа.

## Как это работает

Активная строка `int arr[4] = {1, 66, 12, 2}` создаёт четыре значения, затем `arr[3]` выводит `2`. Закомментированные строки показывают другие формы объявления: вывод размера из списка, явный размер и нулевую инициализацию.

Форма со знаком `=` существует в C++98. Прямая списковая инициализация без `=` появилась в C++11. Если значений в списке меньше размера массива, оставшиеся элементы инициализируются нулями; лишние значения — ошибка компиляции.

- Исправлены подписи форм инициализации: со знаком `=` — C++98, без него — C++11.
- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

## Типичные ошибки

Путать последний индекс с размером массива; называть форму со знаком `=` более новой, чем списковую без `=`.
