# 068. Условная компиляция

## Как это работает

При `#define DEBUG 5` директива `#if DEBUG` проверяет ненулевое значение, а `#ifdef DEBUG` — сам факт определения. Поэтому выводятся сообщения начала и конца цикла, наличия отладочного макроса и выбранных сравнений. В цикле печатаются `0–3`.

`#ifndef DEBUG` выбирает противоположную проверку наличия. `#if DEBUG > 4` истинно, а цепочка `#if DEBUG < 4 / #elif DEBUG == 5` выбирает вторую ветвь. Невыбранный текст не становится исполняемой ветвью, как при обычном `if`. Если определить `DEBUG` равным нулю, `#ifdef` и `#if DEBUG` дадут разные ответы.
