# Урок 122. Несколько обработчиков catch

Предварительно: Уроки 120–121 и стандартные исключения.

## Примеры

- [main.cpp](main.cpp): Выбрасывает разные типы в foo; catch(...) обрабатывает всё, что не подошло предыдущим обработчикам.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-122-multiple-catch-blocks/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Текущий вызов foo(1) выбрасывает int и попадает в catch(...). Другие вызовы оставлены в комментариях для сравнения.

## Что важно понять

Обработчики проверяются по порядку. Производный тип нужно ловить до базового, catch(...) ставить последним. В нём нет переменной с описанием ошибки.
