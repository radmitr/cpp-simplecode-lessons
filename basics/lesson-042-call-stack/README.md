# 042. Вызовы функций и стек

## Версия C++

C++98 — стек вызовов рекурсивной функции. Сборка проекта: **C++17**.

## Что изучаем

Стек вызовов помогает понять, какие функции ещё ожидают возврата из вложенных вызовов.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Как это работает

В этом фрагменте исходной `Foo` вызов `Foo(5)` сначала проверяет `a < 1`. При положительном `a` функция уменьшает его, печатает значение и вызывает `Foo(a)` ещё раз. Пока вложенный вызов не вернулся, предыдущий вызов не завершён.

Вывод показывает `4, 3, 2, 1, 0`. После этого вызов `Foo(0)` сразу возвращает `0`. Возвраты завершают вызовы в обратном порядке. У каждого вызова свой параметр `a` — они не являются одной общей переменной.

Этот же вызов разбирается в [уроке «Рекурсивный вызов»](../lesson-043-recursion/README.md). Для обычных вложенных функций и печати до/после возврата есть [бонус «Трассировка стека вызовов»](../bonus/32-call-stack-trace/README.md).

- Вызов `Foo(5)` показывает стек рекурсивных вызовов; трассировка с `outer()` и `inner()` разобрана в бонусе.
- Добавлена проверка состояния ввода до использования прочитанных значений; ошибка приводит к коду `1`.
- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

Самостоятельный вариант, ранее находившийся в этом уроке, перенесён в [«32. Трассировка стека вызовов» — `main.cpp`](../bonus/32-call-stack-trace/README.md).

## Типичные ошибки

Считать разные параметры `a` одной общей переменной; думать, что внешний вызов уже завершился в момент входа во вложенный.
