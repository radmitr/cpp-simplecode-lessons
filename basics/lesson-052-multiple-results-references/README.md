# 052. Несколько результатов через ссылки

## Версия C++

C++98 — возврат нескольких результатов через ссылки. Сборка проекта: **C++17**.

## Что изучаем

Ссылочные параметры позволяют вернуть несколько результатов через переданные объекты.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа.

## Как это работает

Исходные `a = 0`, `b = 4`, `c = 34` передаются в `foo(a, b, c)`. Параметры `int&` связаны с этими же объектами. Внутри выполняются `a = 10`, `b *= 2` и `c -= 100`.

Функция имеет тип результата `void`, но исходные переменные уже изменены к моменту возврата. Это не три значения в `return`, а запись в три объекта вызывающего кода.

- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

Откройте `main.cpp` этого урока. Ввод не нужен. После исходных `0, 4, 34` выводятся `10, 8, -66`.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Менять параметры на обычные `int` и ожидать прежнего результата; передавать одну переменную в несколько параметров, не учитывая взаимное влияние.
