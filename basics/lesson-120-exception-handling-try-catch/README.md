# Урок 120. Обработка исключений: try и catch

Предварительно: Функции, области видимости и открытие файлов из раздела io.

## Примеры

- [main.cpp](main.cpp): Включает исключения потока и ловит ошибку открытия через const std::exception&.
- [main2.cpp](main2.cpp): Ловит std::ifstream::failure и выводит также код ошибки.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-120-exception-handling-try-catch/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

По умолчанию открывается myFile.tx, а не учебный myFile.txt: при отсутствии файла выполняется обработчик. Текст what() зависит от библиотеки и системы.

## Что важно понять

Потоки обычно сообщают об ошибке флагами. exceptions(failbit | badbit) включает выбрасывание для выбранных состояний. Код продолжает работу после catch; перехват сам по себе не меняет код завершения на ненулевой.
