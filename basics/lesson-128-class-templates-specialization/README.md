# Урок 128. Специализация шаблонов

Предварительно: Урок 126 и `std::string`.

## Примеры

- [main.cpp](main.cpp): Сопоставляет общий `Printer<T>` с полной специализацией `Printer<string>`.

Каждый `main*`.cpp — отдельная программа.

## Механизм и разбор

Основной `Printer<T>` печатает произвольный подходящий `T`,
а полная специализация `Printer<string>` задаёт отдельную реализацию
для одного конкретного типа. Поэтому `string` получает оформление с ___.

~~~cpp
template<> class Printer<std::string> { /* собственный интерфейс */ };
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Специализация класса не наследует тело основного шаблона автоматически:
необходимые члены описывают заново. Она должна быть видна до использования,
которое иначе инстанцировало бы общий вариант.

Полная специализация задаёт конкретный тип; частичная — семейство форм,
например `T*`. Для функций обычно удобнее перегрузки, а для отличающейся
ветви внутри общего алгоритма — if `constexpr` или concept.

## Запуск и результат

F5 — запуск с отладчиком; Ctrl+F5 — без отладчика.

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5/Ctrl+F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-128-class-templates-specialization/main.cpp"
```

На Linux используйте `scripts/build-linux.sh` с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Число выводится как 5, строка — как ___Hello, World!!!___.

## Что важно понять

Полная специализация задаёт отдельную реализацию для конкретного типа. Она не является перегрузкой функции и не обязана автоматически повторять интерфейс основного шаблона.
