## Как это работает

`value` начинается с `5`. `foo(value)` присваивает `1` только локальному параметру, поэтому исходное значение остаётся `5`. `foo2(value)` получает ссылку и меняет `value` на `2`. `foo3(&value)` получает адрес и записывает через разыменование `3`.

Передача ссылки не создаёт отдельное число; передача указателя копирует адрес, но позволяет менять число по адресу. Значения после вызовов печатаются в `main()`, когда функция уже вернулась.

- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

## Типичные ошибки

Ожидать изменения исходного числа от присваивания параметру по значению; забывать `&value` в вызове варианта с указателем.
