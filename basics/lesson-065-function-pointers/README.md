# Урок 65. Указатели на функции

Предварительно: Функции, параметры, возвращаемые значения и указатели.

## Примеры

- [main.cpp](main.cpp): Выбирает и вызывает функцию без параметров через указатель.
- [main2.cpp](main2.cpp): Вызывает функцию int(int); текущий выбор foo2(5) даёт 10.
- [main3.cpp](main3.cpp): Передаёт функцию получения строки в showInfo как callback.

Каждый main*.cpp — отдельная программа.

## Механизм и разбор

В объявлении int (*fooPointer)(int) скобки связывают * с именем указателя.
Без них int* fooPointer(int) объявляло бы функцию, возвращающую int*.

main.cpp выбирает функцию без параметров, main2.cpp — функцию int(int).
Вызов fooPointer(5) обращается к выбранной foo2 и даёт 10.
main3.cpp передаёт функцию получения строки в showInfo: выбор источника
отделён от общего алгоритма вывода.

Обычное имя функции часто само преобразуется в указатель, поэтому foo2 и
&foo2 подходят в нужном контексте. Через nullptr вызывать нельзя.
Захватывающая лямбда не превращается в обычный указатель на функцию;
для хранения состояния есть функторы и std::function.
Указатель на нестатический метод — другой тип: ему нужен ещё объект.

```bash
bash scripts/build-windows.sh "basics/lesson-065-function-pointers/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

## Что важно понять

Сигнатура указателя должна соответствовать функции. Имена источников данных в main3.cpp условные: пример возвращает готовые строки и не обращается к сети или базе. Продолжение — уроки 142–144.
