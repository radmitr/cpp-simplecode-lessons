# Урок 129. struct и class

Предварительно: Классы, члены, конструкторы и наследование.

## Примеры

- [main.cpp](main.cpp): Сравнивает объявления class и struct с методами и конструкторами.
- [main2.cpp](main2.cpp): Показывает закрытое наследование class по умолчанию.
- [main3.cpp](main3.cpp): Сравнивает явное public-наследование class и наследование struct по умолчанию.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-129-structures-struct-vs-class/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Варианты печатают доступные значения полей; недоступные обращения оставлены в комментариях.

## Что важно понять

У class доступ к членам и наследование по умолчанию private, у struct — public. Оба могут содержать методы, конструкторы и деструкторы; struct не означает автоматически «только данные».
