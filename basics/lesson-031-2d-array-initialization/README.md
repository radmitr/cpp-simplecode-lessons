# 031. Инициализация двумерного массива

## Версия C++

C++98 — двумерные массивы и вложенные списки инициализации; C++11 — списковая инициализация без =. Сборка проекта: **C++17**.

## Что изучаем

Двумерный массив имеет фиксированное число строк и столбцов.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

В источнике сохранены одномерный `arr_1D`, явно заданный `arr_2D` и нулевой `arr[ROW][COL]` с `ROW = 3` и `COL = 4`. В последней строке списка `arr_2D` пропущен четвёртый элемент: он становится нулём. Программа печатает выбранные элементы другого массива — `arr`.

Сначала `arr[0][0]` и `arr[1][1]` равны `0`. Присваивания меняют их на `111` и `999`, затем вывод показывает эти значения. Первый индекс выбирает строку, второй — столбец.

## Типичные ошибки

Путать `arr_2D` и `arr`; считать, что все объявленные массивы обязательно печатаются; переставлять местами размеры строк и столбцов.
