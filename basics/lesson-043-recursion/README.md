# 043. Рекурсивный вызов

## Версия C++

C++98 — рекурсивные вызовы функций. Сборка проекта: **C++17**.

## Что изучаем

Рекурсия — вызов функции из самой себя с условием остановки.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят фрагмент общего исходника; весь объединённый пример целиком здесь не воспроизводится.

## Как это работает

`Foo(5)` уменьшает положительный параметр на единицу и печатает его, затем делает следующий вызов. Проверка `if (a < 1) return 0` останавливает цепочку. Последний напечатанный `0` относится к вызову, который начинался с `a = 1`; следующий `Foo(0)` уже ничего не печатает.

Без условия остановки или без уменьшения параметра вызовы продолжались бы до исчерпания ресурсов. Реализация может оптимизировать хвостовые вызовы, поэтому конкретное размещение каждого вызова в машинном стеке не гарантируется.

Печать после вложенного вызова и обратный порядок возврата показаны в [бонусе «Трассировка стека вызовов», main2.cpp](../bonus/32-call-stack-trace/README.md).

## Типичные ошибки

Ожидать вывода после возврата там, где его нет в коде; не различать исходный аргумент вызова и значение после `a--`.
