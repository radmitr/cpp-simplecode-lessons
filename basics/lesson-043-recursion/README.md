## Как это работает

`Foo(5)` уменьшает положительный параметр на единицу и печатает его, затем делает следующий вызов. Проверка `if (a < 1) return 0` останавливает цепочку. Последний напечатанный `0` относится к вызову, который начинался с `a = 1`; следующий `Foo(0)` уже ничего не печатает.

Без условия остановки или без уменьшения параметра вызовы продолжались бы до исчерпания ресурсов. Реализация может оптимизировать хвостовые вызовы, поэтому конкретное размещение каждого вызова в машинном стеке не гарантируется.

Печать после вложенного вызова и обратный порядок возврата показаны в [дополнении «Трассировка стека вызовов», main2.cpp](../additions/32-call-stack-trace/README.md).

- `Foo(5)` показывает рекурсивные вызовы. Дополнительная трассировка возвратов разобрана в дополнениеном примере.
- Добавлена проверка состояния ввода до использования прочитанных значений; ошибка приводит к коду `1`.
- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

Самостоятельный вариант, ранее находившийся в этом уроке, перенесён в [«32. Трассировка стека вызовов» — `main2.cpp`](../additions/32-call-stack-trace/README.md).

## Типичные ошибки

Ожидать вывода после возврата там, где его нет в коде; не различать исходный аргумент вызова и значение после `a--`.
