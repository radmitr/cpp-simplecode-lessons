# Урок 58. Копирование динамического массива

Предварительно: Указатели, new[], delete[], циклы.

## Примеры

- [main.cpp](main.cpp): Выделяет два массива, освобождает прежний первый массив и копирует в новый элементы второго.

Каждый main*.cpp — отдельная программа.

## Механизм и разбор

Переменная int* хранит адрес, а не весь массив. firstArray = secondArray
переустановило бы адрес: старый первый буфер потерялся бы, а два указателя
начали бы обозначать один массив. Последующие два delete[] были бы ошибкой.

Текущий цикл присваивает отдельные элементы, поэтому после копирования
значения одинаковы, а владельцы разные. Изменение одного массива не обязано
менять другой. Размер передаётся отдельно: из сырого int* его не восстановить.

Схема delete старого буфера перед new не даёт сильной гарантии при ошибке
выделения. Для устойчивого кода сначала готовят новый ресурс либо используют
vector. new[] должен соответствовать delete[], обычный delete не подходит.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-058-dynamic-array-copy/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

После копирования содержимое массивов совпадает, но память у каждого своя.

## Что важно понять

Присваивание указателей не копирует элементы: оно может потерять прежний адрес и создать двух владельцев одной памяти. Каждому new[] должен соответствовать один delete[].
