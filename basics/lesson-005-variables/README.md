# 005. Переменные и присваивание

## Версия C++

C++98 — объявление и изменение переменных. Сборка проекта: **C++17**.

## Что изучаем

Объявляем переменные разных типов и меняем сохранённые значения.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа.

## Как это работает

Переменная `a` сначала получает `5`, затем присваивание меняет её на `10`. Объявление `int b = 1, c = 2, Age = 10` создаёт три независимые переменные. Далее выводятся `double` со значением `1.551`, символ `'f'` и логические значения `true` и `false`.

`=` при объявлении задаёт начальное значение, а в последующей инструкции меняет уже существующую переменную. По умолчанию поток печатает логические значения как `1` и `0`.

- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Читать локальную переменную до инициализации. Имена `Age` и `age` различаются; символ записывается в одинарных кавычках.
