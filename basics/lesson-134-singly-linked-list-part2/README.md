# Урок 134. Односвязный список: удаление

Предварительно: Урок 133 и освобождение динамической памяти.

## Примеры

- [main.cpp](main.cpp): Сохраняет исходный пример с ошибочным list[1000].
- [main2.cpp](main2.cpp): Добавляет pop_front и ввод количества элементов.
- [main3.cpp](main3.cpp): Показывает pop_front на списке 55, 11, 2; также содержит clear.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-134-singly-linked-list-part2/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

main.cpp завершается на неперехваченном out_of_range. В main3.cpp после удаления остаются 11 и 2, размер уменьшается с 3 до 2.

## Что важно понять

Сначала сохраните адрес следующего узла, затем удаляйте текущий. Владеющие сырыми указателями варианты не следует копировать; более полный интерфейс и операции копирования/перемещения находятся в уроке 135.
