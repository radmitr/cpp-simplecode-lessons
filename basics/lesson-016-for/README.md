# 016. Цикл for

## Версия C++

C++98 — цикл `for`. Сборка проекта: **C++17**.

## Что изучаем

Цикл for объединяет начальное значение, условие и шаг.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

`int i = 2` выполняется один раз. Перед каждой итерацией проверяется `i < 13`, тело печатает `i`, затем `i++` увеличивает значение. Получаются числа `2–12` включительно.

При `i = 13` тело уже не выполняется. Объявленная в заголовке цикла `i` доступна внутри самого цикла; после него эта переменная выходит из области видимости.

## Типичные ошибки

Считать правую границу `13` включённой в условие `i < 13`; изменять счётчик одновременно в теле и в шаге без необходимости.
