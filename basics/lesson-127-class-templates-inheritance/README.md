# Урок 127. Наследование шаблонных классов

Предварительно: Урок 126, наследование и обращение к членам базового класса.

## Примеры

- [main.cpp](main.cpp): Наследует TypeInfo<T> от TypeSize<T> и показывает размер и имя типа.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-127-class-templates-inheritance/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Для double, int и Point выводятся размер и результат typeid(...).name().

## Что важно понять

this->value указывает на член зависимого базового класса. Строка typeid(...).name() зависит от реализации и может быть закодированным именем; это не стандартная статическая рефлексия полей.
