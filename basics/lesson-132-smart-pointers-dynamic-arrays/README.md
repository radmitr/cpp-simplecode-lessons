# Урок 132. Умные указатели на динамические массивы

Предварительно: Урок 131, массивы и new[].

## Примеры

- [main.cpp](main.cpp): Хранит пять заданных чисел в shared_ptr<int[]> и выводит их по индексам.
- [main2.cpp](main2.cpp): Читает размер с клавиатуры и заполняет массив значениями rand() % 100.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-132-smart-pointers-dynamic-arrays/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Первый вариант выводит 54, 3, 74, 5, 11; второй ожидает положительный небольшой размер.

## Что важно понять

Поддержка shared_ptr<T[]> относится к C++17. В main2.cpp нет полноценной проверки размера и ввода: не используйте отрицательные и чрезмерно большие размеры. Если совместное владение не требуется, рассмотрите vector или unique_ptr<T[]>.
