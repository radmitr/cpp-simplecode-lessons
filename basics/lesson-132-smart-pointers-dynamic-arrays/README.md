# Урок 132. Умные указатели на динамические массивы

## Версия C++

`std::shared_ptr`, лямбды — **C++11**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Предварительно: Урок [«131. Виды умных указателей»](../lesson-131-smart-pointers-types/README.md), массивы и `new[]`.

## Примеры

- [main.cpp](main.cpp): Хранит пять заданных чисел в `shared_ptr<int[]>` и выводит их по индексам.
- [main2.cpp](main2.cpp): Читает размер с клавиатуры и заполняет массив значениями `rand()` % 100.

Каждый `main*.cpp` — отдельная программа.

## Как это работает

Специализация `shared_ptr` для массива использует `delete[]` и индексирование.
В `main.cpp` пять значений 54, 3, 74, 5, 11 сохраняются до уничтожения
последнего владельца массива.

`main2.cpp` читает размер, выделяет массив и заполняет `rand()` % 100.
Передавайте небольшой корректный неотрицательный размер: код не реализует
полную проверку недоверенного ввода и лимитов памяти.

Указатель-владелец сам не предоставляет безопасного at с проверкой границ;
число элементов нужно учитывать отдельно. Массивная поддержка `shared_ptr`
в этом виде — возможность C++17; `make_shared` для массивов добавлена позже.
Если совместного владения не нужно, чаще подходят `vector` или `unique_ptr<T[]>`.
Смена владельца не продлевает жизнь отдельно сохранённой ссылки после удаления массива.

## Сборка и запуск

[Запуск в VS Code](../../README.md#сборка-и-запуск-в-vs-code).

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5/Ctrl+F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-132-smart-pointers-dynamic-arrays/main.cpp"
```

На Linux используйте `scripts/build-linux.sh` с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Первый вариант выводит 54, 3, 74, 5, 11; второй ожидает положительный небольшой размер.

## Типичные ошибки

Поддержка `shared_ptr<T[]>` относится к C++17. В `main2.cpp` нет полноценной проверки размера и ввода: не используйте отрицательные и чрезмерно большие размеры. Если совместное владение не требуется, рассмотрите `vector` или `unique_ptr<T[]>`.
