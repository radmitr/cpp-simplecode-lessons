# 008. Арифметические операторы

## Версия C++

C++98 — арифметические операторы и приоритет операций. Сборка проекта: **C++17**.

## Что изучаем

Изучаем арифметические операторы и порядок вычисления выражения.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

В исходнике показан унарный минус: `x = -x` меняет знак `5`. Затем для `a = 5` и `b = 2` вычисляются сумма `7` и произведение `10`. Выражение `2 + 2 * 2` даёт `6`, а `(2 + 2) * 2` — `8`: скобки изменяют группировку операций.

Первый вывод показывает `5`, второй — `-5` после унарного минуса. Затем последовательно печатаются результаты сложения, умножения и выражений со скобками.
