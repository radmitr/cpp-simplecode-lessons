# Урок 144. Захваты и возвращаемый тип лямбды

Предварительно: Урок 143, ссылки, классы и this.

## Примеры

- [main.cpp](main.cpp): Сравнивает [a], [&a, b], [=], [&] и mutable.
- [main2.cpp](main2.cpp): Вызывает метод через захваченный this.
- [main3.cpp](main3.cpp): Сравнивает вывод возвращаемого типа и явный -> int.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-144-lambda-capture-context/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

main.cpp показывает значения и адреса оригиналов и копий, main2.cpp печатает msg. main3.cpp ничего не печатает: результаты вызовов не выводятся.

## Что важно понять

mutable разрешает менять копию захвата, но не исходную переменную. Захват по ссылке и захват this не продлевают жизнь объекта. В main3.cpp возврат 1.45 как int отбрасывает дробную часть, даже если результат позже преобразуется во float.
