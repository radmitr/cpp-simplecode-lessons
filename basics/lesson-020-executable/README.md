# 020. Исходник и исполняемый файл

## Версия C++

C++98 — `main()` и вывод последовательности сообщений. Сборка проекта: **C++17**.

## Что изучаем

Исходный текст и собранная программа — разные файлы.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

После компиляции `main.cpp` получается отдельный исполняемый файл: на Windows с расширением `.exe`, на Linux обычно без него. В исходном примере пять последовательных инструкций вывода печатают названия чисел.

Компилятор не нужен для каждого последующего запуска уже собранного файла. После изменения исходника его нужно собрать заново, иначе запускается прежняя версия программы.

## Сборка и запуск

[Запуск в VS Code](../../README.md#сборка-и-запуск-в-vs-code) ·
[Команды Windows/Linux из терминала](../../README.md#сборка-из-терминала).

Откройте `main.cpp` этого урока. Ввод не нужен. Печатаются `Один`, `Два`, `Три`, `Четыре`, `Пять`.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Открывать `.cpp` как исполняемый файл или ожидать, что изменение текста автоматически меняет старый бинарный файл.
