# Урок 124. Перечисления `enum`

## Версия C++

Основные средства языка и классической библиотеки — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Предварительно: Целые числа, `switch` и основы классов.

## Примеры

- [main.cpp](main.cpp): Хранит состояние компьютера во вложенном `enum` и обрабатывает его через `switch`.
- [main2.cpp](main2.cpp): Задаёт явные значения перечисления `Speed`: 150, 600, 800.

Каждый `main*.cpp` — отдельная программа.

## Как это работает

`enum` даёт именованные значения состояния. В `PC` они используются в `setState`
и `switch`, чтобы вместо непонятных целых писать OFF, ON, SLEEP.
break завершает соответствующую ветку; без него выполнение могло бы перейти
в следующую ветвь.

У `Speed` явно заданы числа 150, 600, 800, поэтому перечисление не обязано
состоять из последовательных 0, 1, 2. Вывод в этом варианте показывает числа.

Обычный `enum` разрешает некоторые неявные преобразования к целому и имеет
менее строгую область имён. `enum class` из [`enum class` и битовые флаги](../additions/07-enum-class/README.md) делает эти границы явнее.
Приведение внешнего числа не заменяет проверку известного состояния.
Для набора одновременных флагов нужен отдельно спроектированный битовый формат.

## Типичные ошибки

Рабочий код использует обычный `enum`. Закомментированная строка `enum class` — лишь направление продолжения: для `enum class` нужен явный вывод числового значения или собственное форматирование.
