# Урок 136. Вывод типа через auto

Предварительно: Типы переменных, инициализация, vector и итераторы.

## Примеры

- [main.cpp](main.cpp): Выводит тип из инициализатора и печатает значения и sizeof.
- [main2.cpp](main2.cpp): Сравнивает явное имя итератора vector с auto.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-136-auto-keyword/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

В main.cpp видны значения разных типов и их размеры. main2.cpp дважды выводит 11, 46, 9.

## Что важно понять

auto требует инициализатора и означает статически выведенный тип. sizeof не всегда однозначно определяет тип: например, auto c = "string" выводит указатель, а sizeof(c) показывает размер указателя, не длину строки.
