# Урок 136. Вывод типа через `auto`

## Версия C++

`auto` — **C++11**.
`std::vector` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Предварительно: Типы переменных, инициализация, `vector` и итераторы.

## Примеры

- [main.cpp](main.cpp): Выводит тип из инициализатора и печатает значения и sizeof.
- [main2.cpp](main2.cpp): Сравнивает явное имя итератора `vector` с `auto`.

Каждый `main*.cpp` — отдельная программа.

## Как это работает

`auto` выводит статический тип из инициализатора. В примере это `int` для 10,
`double` для 1.44, `const char*` для `"string"` и `bool` для `true`.
Поэтому `sizeof(c)` измеряет указатель, а не длину слова.

`auto` без инициализатора здесь вывести нельзя.
Присваивание нового значения позже не меняет уже выведенный тип.
`auto it = vector.begin()` получает конкретный тип итератора, не теряя проверок.

Обычный `auto` может сделать копию там, где выражение возвращает ссылку.
Для изменения исходного элемента используют `auto&`, для чтения — `const auto&`.
Подробное различие `auto`, `decltype` и `decltype(auto)` показано
в [`auto`, ссылки и `decltype(auto)`](../bonus/05-auto-and-decltype/README.md).

## Типичные ошибки

`auto` требует инициализатора и означает статически выведенный тип. sizeof не всегда однозначно определяет тип: например, `auto c = "string"` выводит указатель, а `sizeof(c)` показывает размер указателя, не длину строки.
