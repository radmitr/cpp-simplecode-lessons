# 004. Основные типы данных

## Версия C++

C++98 — основные типы языка (обзор в комментариях). Сборка проекта: **C++17**.

## Что изучаем

Обзор числовых, символьного и логического типов в комментариях исходного примера.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

В комментарии перечислены `short`, `int`, `long`, `float`, `double`, `char` и `bool`. Исполняемая часть этого урока выводит только `Привет!`: она не создаёт по переменной каждого типа и не измеряет их размеры.

`sizeof(char)` всегда равен одному байту C++, но число битов в таком байте определяется реализацией. Размеры остальных типов нельзя считать универсальными. Например, `long` в обычных 64-битных Windows и Linux часто имеет разные размеры. Реальное создание и вывод переменных сохранены в [бонусе «Основные типы и sizeof на практике»](../bonus/31-fundamental-types/README.md).
