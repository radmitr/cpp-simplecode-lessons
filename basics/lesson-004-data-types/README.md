## Как это работает

В комментарии перечислены `short`, `int`, `long`, `float`, `double`, `char` и `bool`. Исполняемая часть этого урока выводит только `Привет!`: она не создаёт по переменной каждого типа и не измеряет их размеры.

`sizeof(char)` всегда равен одному байту C++, но число битов в таком байте определяется реализацией. Размеры остальных типов нельзя считать универсальными. Например, `long` в обычных 64-битных Windows и Linux часто имеет разные размеры. Реальное создание и вывод переменных сохранены в [бонусе «Основные типы и sizeof на практике»](../bonus/01-fundamental-types/README.md).

- В комментариях исправлены фиксированные размеры типов и утверждение о неиспользуемом `long`. Исполняемый пример выводит приветствие.
- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

Самостоятельный вариант, ранее находившийся в этом уроке, перенесён в [«01. Основные типы и sizeof на практике» — `main.cpp`](../bonus/01-fundamental-types/README.md).

Заучивать размеры типов как одинаковые для любой платформы; считать `long` неиспользуемым типом.
