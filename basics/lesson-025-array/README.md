# 025. Одномерный массив

## Версия C++

C++98 — массивы; C++11 — инициализация пустым списком. Сборка проекта: **C++17**.

## Что изучаем

Массив хранит несколько элементов одного типа под одним именем.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

`int arr[4]{}` создаёт четыре нулевых элемента. Затем `arr[0] = 5` меняет только первый. Индексы начинаются с нуля, поэтому допустимый диапазон здесь `0–3`.

Квадратные скобки при объявлении задают размер, а в выражении `arr[0]` выбирают элемент. Проверка границ при таком доступе автоматически не выполняется.

## Типичные ошибки

Обращаться к `arr[4]` в массиве из четырёх элементов; считать пустой список `{}` отсутствием инициализации.
