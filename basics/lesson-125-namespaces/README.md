# Урок 125. Пространства имён

## Версия C++

Основные средства языка и классической библиотеки — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Предварительно: Функции, глобальные переменные и оператор ::.

## Примеры

- [main.cpp](main.cpp): Размещает одноимённые `foo` в разных, в том числе вложенных, пространствах имён.

Каждый `main*.cpp` — отдельная программа.

## Как это работает

`firstNS::foo` и `secondNS::foo` — разные функции, хотя короткое имя совпадает.
:: указывает область поиска. Вложенный путь `thirdNS::secondNS::foo`
проходит через два пространства имён.

`using namespace firstNS` расширяет поиск неуточнённых имён в своей области;
он не копирует функции и не меняет их принадлежность.
Подключение сразу двух пространств с `foo` может сделать `foo()` неоднозначным.

Дополнительные полезные формы:
`using std::cout` вводит одно имя; `namespace chrono = std::chrono` создаёт
псевдоним пространства; ::name начинает поиск с глобальной области.
В заголовках избегают глобального `using namespace std`, чтобы не менять
поиск имён у каждого подключившего код файла.

## Типичные ошибки

Несколько `using namespace` с одинаковыми именами могут сделать вызов неоднозначным. В заголовках лучше использовать квалифицированные имена и не навязывать `using namespace` пользователю заголовка.
