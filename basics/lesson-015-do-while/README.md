# 015. Цикл do-while

## Версия C++

C++98 — цикл `do` / `while`. Сборка проекта: **C++17**.

## Что изучаем

Цикл do / while проверяет условие после выполнения тела.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

В источнике `a = 19`. Тело сначала печатает `19` и увеличивает `a` до `20`, затем проверка `a < 20` завершает цикл. В комментарии оставлен вариант `while` для сравнения.

Тело `do / while` выполняется хотя бы один раз даже при изначально ложном условии. После закрывающего условия требуется точка с запятой.

## Типичные ошибки

Путать момент проверки условия с обычным `while` или пропускать завершающую точку с запятой.
