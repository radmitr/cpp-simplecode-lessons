# Урок 145. Измерение времени выполнения

Предварительно: Деструкторы, chrono; для main.cpp также потоки и join.

## Примеры

- [main.cpp](main.cpp): Измеряет область видимости RAII-таймером и запускает sum в отдельном потоке.
- [main2.cpp](main2.cpp): Измеряет Foo, которая печатает 5000 чисел.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-145-measure-execution-time/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Появляются строки DURATION с секундами. main.cpp работает примерно семь секунд из-за явных sleep_for; точные времена и порядок строк зависят от системы.

## Что важно понять

Измеряется и стоимость вывода, и ожидания. high_resolution_clock не обязан быть монотонным; для измерения длительностей обычно выбирают steady_clock. Это демонстрация механизма, не точный сравнительный бенчмарк.
