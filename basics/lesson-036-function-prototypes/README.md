# 036. Предварительное объявление функции

## Версия C++

C++98 — прототипы функций. Сборка проекта: **C++17**.

## Что изучаем

Прототип функции позволяет вызвать её до определения тела.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа.

## Как это работает

Перед `main()` объявлены `foo(int, int)` и `foo2()`. Вызов `foo(1, 2)` передаёт два аргумента. Внутри `foo` вычисляется `3`, печатается сообщение и вызывается `foo2()`, затем результат возвращается в `main()` и печатается как `RES`.

Объявление описывает интерфейс, определение содержит тело. Имя, тип результата и типы параметров должны согласовываться. Одного объявления достаточно для компиляции вызова, но при сборке нужна реализация.

- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

Откройте `main.cpp` этого урока. Ввод не нужен. Сначала сообщения из `foo` и `foo2`, после возврата в `main()` — результат `3`.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Путать объявление с определением или менять сигнатуру только в одном из них; забывать, что вложенный вызов `foo2()` выполняется до возврата из `foo`.
