# 063. Строки, указатели и функции

## Версия C++

C++98 — `strlen()` и `strcat()`; C++11 — пустой список инициализации. Сборка проекта: **C++17**.

## Что изучаем

Функции C-строк работают с завершающим нулём и заранее выделенным буфером.

Сначала изучите [устройство программы](../lesson-002-program-structure/README.md) и [функции](../lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят фрагмент общего исходника; весь объединённый пример целиком здесь не воспроизводится.

## Как это работает

`result[255]{}` изначально содержит нули и представляет пустую строку. `strlen(str1)` и `strlen(str2)` возвращают `6`. Первый `strcat(result, str1)` добавляет `"Hello "`, второй — `"World!"`. Результат `"Hello World!"` содержит `12` символов и ещё завершающий ноль.

Стандартная `strcat()` не знает размер буфера. Здесь два фиксированных литерала требуют `13` байт, а выделено `255`, поэтому запись помещается. Нестандартная двухаргументная `strcat_s` из Visual Studio заменена именно для этого известного случая. Произвольный длинный ввод требует отдельной проверки размера или использования `std::string`.

Сравнение содержимого C-строк через `std::strcmp` уже выполняется в [классе String](../../examples/String/README.md): реализация находится в `String.cpp`, проверки сравнений — в `main2.cpp`. Отдельная копия этого механизма здесь не добавляется.

## Типичные ошибки

Добавлять текст в неинициализированный буфер; забывать место под ноль; считать, что `strcat()` сама проверяет ёмкость или допускает перекрывающиеся строки.
