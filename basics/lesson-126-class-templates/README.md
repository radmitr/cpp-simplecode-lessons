# Урок 126. Шаблоны классов

Предварительно: Классы, конструкторы, поля и типы.

## Примеры

- [main.cpp](main.cpp): Создаёт MyClass<T> для int, double и Point; использует sizeof(T) и getValue().
- [main 2.cpp](main%202.cpp): Добавляет два независимых параметра типа T1 и T2.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-126-class-templates/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Печатаются размеры типов и сохранённые значения; размеры зависят от платформы. Во втором варианте возвращаются 5 и Point(11, 22, 33).

## Что важно понять

template<class T> и template<typename T> в таком объявлении равнозначны. Имя второго файла содержит пробел: при запуске скрипта заключайте весь путь в кавычки. Определения используемых шаблонов обычно должны быть доступны в месте инстанцирования.
