# Урок 121. Выбрасывание исключений: `throw`

Предварительно: Урок 120, функции и условия.

## Примеры

- [main.cpp](main.cpp): Повторяет обработку файлового исключения с `what()` и `code()`.
- [main2.cpp](main2.cpp): Выбрасывает и перехватывает отрицательное значение `int`.
- [main3.cpp](main3.cpp): Выбрасывает строковый литерал и ловит `const char*`.
- [main4.cpp](main4.cpp): Выбрасывает `std::invalid_argument` и ловит `const std::exception&`.

Каждый `main*`.cpp — отдельная программа.

## Механизм и разбор

`throw` создаёт объект исключения и передаёт управление наружу до подходящего
обработчика. При этом локальные RAII-объекты покидаемых областей уничтожаются.

`main.cpp` продолжает тему ошибок файла. Варианты main2/main3/main4 бросают
соответственно `int`, строковый литерал и стандартное исключение.
Обработчик должен соответствовать типу: `catch(int)` не является обработчиком
для `runtime_error`, а `catch(const char*)` не ловит `std::string`.

В прикладном интерфейсе собственные/стандартные классы ошибок позволяют
сохранить контекст и единый базовый тип. `throw`; внутри `catch` повторно бросает
текущее исключение; `throw` e создаёт новый `throw` выражения и может срезать тип.
Перенос через границу обычного рабочего `std::thread` требует отдельной обработки.

## Что важно понять

`int` и `const char*` показывают механику сопоставления типов. Для прикладных ошибок предпочтительнее типы с понятным назначением, например `std::invalid_argument`. У стандартного `std::exception` нет переносимого конструктора с текстом сообщения.
