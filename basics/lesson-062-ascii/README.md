# Урок 62. Коды символов и ASCII

Предварительно: Циклы, `char` и преобразование типов.

## Примеры

- [main.cpp](main.cpp): Печатает коды 0–255 и соответствующие значения `char`.

Каждый `main*`.cpp — отдельная программа.

## Механизм и разбор

Цикл перебирает 256 кодов одного байта на обычной платформе, но ASCII —
только диапазон 0…127. В нём есть управляющие коды: например, перевод строки
или табуляция могут менять оформление вывода вместо изображения символа.

Значения 128…255 зависят от интерпретации кодировки. В UTF-8 русский символ
обычно занимает несколько байтов; отдельный байт 200 не является готовой
Unicode-буквой. Настройка UTF-8 консоли не превращает каждый код в корректный символ.

`char` может быть знаковым или беззнаковым. Для работы с кодом байта обычно
явно используют `unsigned char`. Для Unicode нужны кодовые точки и выбранная
кодировка, а не предположение «один `char` — одна буква».

## Что важно понять

ASCII определяет только коды 0–127. Значения 128–255 не являются универсальным продолжением ASCII. В UTF-8 один символ может занимать несколько байтов; этот цикл не строит таблицу символов Unicode.
