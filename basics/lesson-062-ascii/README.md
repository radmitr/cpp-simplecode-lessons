# Урок 62. Коды символов и ASCII

Предварительно: Циклы, char и преобразование типов.

## Примеры

- [main.cpp](main.cpp): Печатает коды 0–255 и соответствующие значения char.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-062-ascii/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Часть строк содержит управляющие или непечатаемые значения; вид вывода зависит от терминала.

## Что важно понять

ASCII определяет только коды 0–127. Значения 128–255 не являются универсальным продолжением ASCII. В UTF-8 один символ может занимать несколько байтов; этот цикл не строит таблицу символов Unicode.
