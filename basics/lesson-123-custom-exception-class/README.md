# Урок 123. Собственные классы исключений

Предварительно: Уроки 120–122, классы и наследование.

## Примеры

- [main.cpp](main.cpp): Выбрасывает самостоятельный тип MyException без наследования от std::exception.
- [main2.cpp](main2.cpp): Наследует MyException от std::invalid_argument и добавляет состояние ошибки.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "basics/lesson-123-custom-exception-class/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

При foo(1) выбирается обработчик MyException; второй вариант выводит сообщение и дополнительное состояние.

## Что важно понять

Первый MyException не перехватывается через std::exception. Во втором примере специфический catch стоит раньше базового. В общем случае ловите объекты исключений по const-ссылке; для этого наблюдающие методы класса также должны быть const.
