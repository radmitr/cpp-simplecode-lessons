# Общая настройка кодировки консоли

[console.hpp](console.hpp) предоставляет `console::setupConsoleEncoding()`.
Одинаковую функцию используют все уроки, которым нужна эта настройка.

`console` — пространство имён, в котором объявлена функция.
В записи `console::setupConsoleEncoding()` оператор `::` указывает, где искать
её имя. Так вспомогательная функция отделена от глобальных имён урока.
Само помещение в пространство имён не меняет действий функции.

На Windows она вызывает `SetConsoleCP(CP_UTF8)` для ввода и
`SetConsoleOutputCP(CP_UTF8)` для вывода. На Linux тело функции пустое:
используйте терминал с UTF-8. Исходники и строковые литералы проекта хранятся
в UTF-8. Функция не перекодирует файлы и не меняет язык системных сообщений.

Подключите заголовок относительным путём из папки своего исходника и вызовите
`console::setupConsoleEncoding();` в начале `main()`. Для обычной папки урока путь —
`../../common/console.hpp`, для бонуса на три уровня глубже корня —
`../../../common/console.hpp`.

Пример подключения и вызова есть в [первой программе](../basics/lesson-001-hello-world/main.cpp).
Используйте полное имя `console::setupConsoleEncoding()`; директива
`using namespace console;` здесь не нужна.

Функция определена как `inline`, поэтому её одинаковое определение из заголовка
допустимо в нескольких отдельно компилируемых `.cpp` одной программы.
Защита `#ifndef` предотвращает повторное включение внутри одного такого файла.
`inline` здесь не гарантирует оптимизацию вызова.

В уроках с отдельной темой широких потоков и `_setmode` сохраняется
их собственная демонстрация. Для чисто ASCII-вывода перенастройка не требуется.
