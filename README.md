# cpp-simplecode-lessons

Мои упражнения и эксперименты по C++ на основе материалов канала [#SimpleCode](https://www.youtube.com/@SimpleCodeIT), в первую очередь плейлиста [«Основы C++. Программирование для начинающих»](https://www.youtube.com/playlist?list=PLQOaTSbfxUtCrKs0nicOg2npJQYSPGO9r). Это личный учебный репозиторий, а не официальный проект автора курса.

## Структура

- `basics/` — основы языка и небольшие программы.
- `oop/` — объектно ориентированное программирование.
- `stl/` — контейнеры, алгоритмы и другие темы стандартной библиотеки.
- `multithreading/` — многопоточность.
- `examples/` — дополнительные примеры.
- `_template/` — заготовка для новых уроков.

Каждый урок находится в отдельной папке. У разных уроков могут быть собственные `main.cpp` и настройки VS Code в `.vscode/`.

## Сборка и запуск в VS Code

Текущие конфигурации рассчитаны на **Windows и MSYS2 MinGW-w64**. Для них нужны `g++` и `gdb` из `C:/msys64/mingw64/bin/`, Bash из `C:/msys64/usr/bin/bash.exe`, а также расширение VS Code **C/C++** от Microsoft. Пути к инструментам прописаны в файлах уроков; при другой установке MSYS2 их потребуется изменить. CMake в этом репозитории пока не настроен.

1. Откройте в VS Code **папку нужного урока** как отдельную рабочую папку. Тогда VS Code увидит именно её `.vscode/tasks.json` и `.vscode/launch.json`.
2. Для обычного урока откройте нужный исходный файл `.cpp` перед сборкой: задачи с `${file}` используют активную вкладку. Если активен, например, `tasks.json`, компилятор попытается собрать этот JSON-файл.
3. В верхнем меню VS Code выберите **Terminal (Терминал) → Run Task… → C/C++: Build and Run**, чтобы собрать и сразу запустить программу.

Другие доступные действия:

- **Ctrl+Shift+B** — выполнить задачу сборки по умолчанию (`C/C++: g++.exe build active file`); она создаёт `.exe`, но не запускает его.
- **F5** — выполнить конфигурацию `C++: Run and Debug` из `launch.json`: сначала задачу сборки `preLaunchTask`, затем запуск под GDB.
- **Terminal → Run Task… → C/C++: Run (No Build)** — запустить уже собранный `.exe` без повторной компиляции. Если исходник изменился, эта задача всё равно запустит старую версию программы.

В большинстве уроков `.exe` создаётся рядом с исходным `.cpp`. В многофайловых уроках `basics/lesson-139-multi-file-project` и `basics/lesson-140-multi-file-project-include-guard` программа собирается из нескольких файлов в `build/app.exe`; их задачи настроены отдельно.

При желании можно назначить сочетания **Ctrl+F5** для `C/C++: Build and Run` и **Ctrl+Alt+F5** для `C/C++: Run (No Build)`. В VS Code откройте **File → Preferences → Keyboard Shortcuts**, затем **Open Keyboard Shortcuts (JSON)** и добавьте эти правила в пользовательский `keybindings.json`:

```jsonc
[
    {
        "key": "ctrl+f5",
        "command": "workbench.action.tasks.runTask",
        "args": "C/C++: Build and Run"
    },
    {
        "key": "ctrl+alt+f5",
        "command": "workbench.action.tasks.runTask",
        "args": "C/C++: Run (No Build)"
    }
]
```

Если в `keybindings.json` уже есть другие правила, добавьте эти два объекта в существующий массив. Сочетания хранятся в настройках пользователя, поэтому из репозитория автоматически не применяются. **Ctrl+F5** заменит стандартный запуск VS Code без отладки через `launch.json`.

## Что хранится в репозитории

Исходные файлы и настройки задач/отладки в `.vscode/tasks.json` и `.vscode/launch.json` полезны для воспроизведения учебных примеров. Созданные при сборке `.exe` и каталоги `build/` исключены через `.gitignore`. Также исключены данные, создаваемые уроками `117` и `118` при запуске. Локальные `.vscode/settings.json` исключены: они содержат в основном привязки файлов к языку C++ и не нужны для сборки.
