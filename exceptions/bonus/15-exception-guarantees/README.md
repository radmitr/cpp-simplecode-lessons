# 15. Гарантии безопасности исключений

## Версия C++

`auto` — **C++11**.
`std::vector`, `std::exception`, `std::invalid_argument` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Базовая гарантия сохраняет корректность и отсутствие утечек, сильная
оставляет исходное состояние неизменным при ошибке, no-`throw` запрещает выход
исключения. Пример готовит копию, проверяет её и фиксирует результат через `swap`
для `vector` с обычным allocator. Внешние эффекты (уже записанные данные, отправленные
запросы) копией в памяти не отменяются. Для произвольных allocator/типов отдельно
проверьте условия `noexcept` у операции фиксации.

## Примеры

- [main.cpp](main.cpp).

Выбирайте один исходник с `main()`; варианты запускаются отдельно.

## Как это работает

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Каждый исходник здесь — самостоятельный исполняемый пример.

`append_checked` сначала копирует `vector` в `candidate`, меняет копию,
проверяет значение и лишь затем фиксирует новый `vector` через `swap`.

~~~cpp
auto candidate = data;
candidate.push_back(value);
// Проверка candidate...
data.swap(candidate);
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Попытка добавить -1 выбрасывает исключение, но исходные {1, 2} сохраняются.
Добавление 3 заканчивается {1, 2, 3}. Это сильная гарантия для данной операции:
при неудаче наблюдаемое исходное состояние не изменилось.

Базовая гарантия могла бы допустить частичное изменение, сохранив корректность
и отсутствие утечек. No-`throw` означает отсутствие выхода исключения.
Сам `try`/`catch` не создаёт сильную гарантию: её обеспечивает порядок
подготовки и фиксации. Внешний запрос или уже записанный файл нельзя
откатить одним `swap` памяти; для них нужен отдельный протокол.

### Результат и проверка

После показанных в коде значений последняя строка — `OK 15-exception-guarantees`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section exceptions/bonus`
(на Linux команда Python обычно называется python3).

### Самостоятельно
