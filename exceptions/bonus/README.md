# Бонусы по исключениям

Нужны [`try`, `throw`, `catch` и собственные исключения из курса](../README.md). Сначала изучите семейства ошибок, затем перенос причины, `noexcept` и гарантии состояния после исключения.

Номера папок задают порядок изучения внутри раздела. Уроки SimpleCode сохраняют исходную нумерацию.

## Уроки

- [01. Стандартные и собственные типы исключений](01-exception-types/README.md) — `c++17`.
- [02. Повторное выбрасывание и вложенные исключения](02-rethrow-and-nested/README.md) — `c++17`.
- [03. `noexcept`, деструкторы и перемещение](03-noexcept/README.md) — `c++17`.
- [04. Гарантии безопасности исключений](04-exception-guarantees/README.md) — `c++17`.
