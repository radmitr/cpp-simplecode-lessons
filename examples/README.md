# Дополнительные примеры классов строк

Примеры связывают [копирование и перегрузки](../oop/README.md),
[владение памятью](../basics/bonus/README.md) и потоковый ввод-вывод.

- [String](String/README.md) — собственный буфер, копирование/перемещение,
  строковые операции и два независимых main.
- [CowString](CowString/README.md) — общий буфер и отделение копии при записи.

Это учебные реализации. Их ограничения по исключениям, границам, UTF-8
и потокам перечислены рядом с кодом, чтобы успешная демонстрация не
воспринималась как гарантия готовности контейнера для любых входных данных.

Откройте соответствующий .cpp с main() в VS Code и нажмите F5.
[Сборка Windows/Linux](../scripts/README.md) · [Все разделы](../README.md).
