## Как это работает

### Как работает COW

Copy-on-write откладывает дорогое копирование общего буфера до изменения.

1. `s1("Hello")` создаёт `Data` с `refCount = 1`.
2. `s2(s1)` копирует указатель `Data` и увеличивает `refCount` до 2.
3. `s2.get(0)` читает H без отделения буфера.
4. `s2.set(0, 'J')` вызывает `detach`: при нескольких владельцах создаётся
   собственный `Data`. `s1` остаётся Hello, `s2` становится Jello.
5. `s3 = s2` снова разделяет буфер; изменение `s3.set(1, 'a')`
   отделяет его и даёт Jallo. `s2` остаётся Jello.

`release` уменьшает число владельцев и удаляет `Data`, когда их больше нет.
Удаление `Data` освобождает массив. Проверка `this` != &other защищает
копирующее присваивание от самоприсваивания.

### Нюансы ссылки на символ

Нестатический `operator[]` возвращает `char&` и вызывает `detach` даже при чтении
из неконстантного объекта: он не знает, будет ли вызывающий писать через ссылку.
`const`-перегрузка и `get` читают без отделения.

Сохранённая `char&` может нарушить задуманные свойства COW, если затем
скопировать строку и изменить символ через старую ссылку: `detach` обходится.
Поэтому такой пример не обладает всеми гарантиями современного `std::string`.
`std::string` не следует считать реализацией этой учебной схемы.

### Границы применения

В коде нет проверки индекса и `nullptr`, счётчик ссылок не атомарный.
Выход за буфер, повреждение завершающего нуля и конкурентные изменения
не поддерживаются. Даже один атомарный `refCount` не сделал бы безопасными
все операции с изменяемым общим буфером.

## Сборка и запуск

[Запуск в VS Code](../../README.md#сборка-и-запуск-в-vs-code).

Откройте `CowString.cpp` и нажмите F5/Ctrl+F5, либо из корня на Linux:

~~~bash
bash scripts/build-linux.sh examples/CowString/CowString.cpp
./build/examples/CowString/CowString
~~~

Windows: `build-windows.sh` и `CowString.exe`. Ввод не нужен, порядок шагов
последовательный. Счётчики/сообщения показывают момент фактического копирования.
[Подготовка Windows/Linux](../../README.md#требования) · [Другие примеры](../README.md).
