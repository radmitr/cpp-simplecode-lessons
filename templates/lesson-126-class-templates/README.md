# Урок 126. Шаблоны классов

## Версия C++

Основные средства языка и классической библиотеки — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Предварительно: Классы, конструкторы, поля и типы.

## Примеры

- [main.cpp](main.cpp): Создаёт `MyClass<T>` для `int`, `double` и `Point`; использует `sizeof(T)` и `getValue()`.
- [main 2.cpp](main%202.cpp): Добавляет два независимых параметра типа T1 и T2.

Каждый `main*.cpp` — отдельная программа.

## Как это работает

`MyClass<int>` и `MyClass<double>` — разные типы, созданные по одной схеме.
`T` подставляется в поля, параметры и возвращаемые значения.
Вариант с T1/T2 хранит два независимо выбранных типа: `int` и `Point`.

`sizeof(T)` показывает объём хранения для реализации, а не «число полей».
В `main 2.cpp` значения 5 и `Point(11, 22, 33)` извлекаются из разных полей.
Методы, реально используемые для `T`, должны поддерживать нужные операции.

template задаёт семейство типов, а не runtime-переключатель.
Обычно определения шаблонов доступны в заголовке в месте использования.
Имена с пробелом, как `main 2.cpp`, передавайте скрипту сборки в кавычках.
Вывод параметров класса (CTAD) и ограничения шаблонов рассмотрены в дополнениях.

## Сборка и запуск

[Запуск в VS Code](../../README.md#сборка-и-запуск-в-vs-code).

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5/Ctrl+F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "templates/lesson-126-class-templates/main.cpp"
```

На Linux используйте `scripts/build-linux.sh` с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Печатаются размеры типов и сохранённые значения; размеры зависят от платформы. Во втором варианте возвращаются 5 и `Point(11, 22, 33)`.

## Типичные ошибки

`template<class T>` и `template<typename T>` в таком объявлении равнозначны. Имя второго файла содержит пробел: при запуске скрипта заключайте весь путь в кавычки. Определения используемых шаблонов обычно должны быть доступны в месте инстанцирования.
