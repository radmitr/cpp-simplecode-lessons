# 041. Шаблоны функций

## Версия C++

C++98 — шаблоны функций. Сборка проекта: **C++17**.

## Что изучаем

Шаблон функции позволяет описать один алгоритм для нескольких типов.

Сначала изучите [устройство программы](../../basics/lesson-002-program-structure/README.md) и [функции](../../basics/lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят фрагмент общего исходника; весь объединённый пример целиком здесь не воспроизводится.

## Как это работает

`SumT(T a, T b)` выводит один `T` из обоих аргументов: `SumT(1, 2)` даёт `3`, `SumT(10.2, 5.05)` — `15.25`. Функция `SumT_t(T1 a, T2 b)` допускает два типа, но возвращает именно `T1`. Поэтому `SumT_t(5, 10.4)` возвращает `int` со значением `15`, а `SumT_t(10.5, 7)` — `double` со значением `17.5`.

`Ft` выводит оба аргумента, сохраняя все четыре исходных вызова с разными типами. `Ft_t(10)` показывает, что для объявления параметра типа в этом контексте можно использовать `class` вместо `typename`. Это не делает аргумент обязательно классом.

Вычисление `a + b` должно быть допустимо для выбранных типов. Разные типы аргументов у `SumT` автоматически в один `T` не объединяются.

## Типичные ошибки

Считать тип возвращаемого результата автоматически наиболее широким; не учитывать усечение `double` при возврате `int`.
