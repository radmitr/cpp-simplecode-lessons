# 04. Пакеты параметров и fold expressions

## Версия C++

свёртка пакета — **C++17**.
`std::forward`, `auto`, `constexpr`, лямбды, пакеты параметров — **C++11**.
`std::exception` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Пакет описывает несколько аргументов, fold expression разворачивает
оператор над ними. Начальное значение определяет поведение пустой суммы.
Сложение разнородных типов зависит от обычных преобразований и допустимости
оператора. Свёртка по запятой выполняет вызовы по порядку, логическая свёртка
сохраняет короткое замыкание. Не путайте число аргументов sizeof...(T) с размером данных.

## Как это работает

Нужны шаблоны функций, пакеты параметров и лямбды.

`class... T` и `values...` описывают переменное число параметров.
Сумма использует начальный 0, поэтому `sum()` допустима и равна нулю,
а `sum(1, 2, 3)` даёт 6.

~~~cpp
return (0 + ... + values);
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Это левая бинарная свёртка: ((0 + v1) + v2) + v3.
Тип результата выводится из выражения; 0 участвует в обычных преобразованиях.
Логическая свёртка `all_positive` сохраняет короткое замыкание &&;
для пустого пакета её нейтральное значение `true`.

`call_all` сворачивает запятую: сначала счётчик увеличивается на 1,
затем на 2. Это последовательность вызовов, а не создание потоков.
Для других операторов порядок вычисления операндов нельзя автоматически
выводить из вида записи свёртки. sizeof...(T) даёт число аргументов.

### Результат и проверка

После показанных в коде значений последняя строка — `OK 04-parameter-packs`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;

Проверка всего раздела: `python scripts/check-additions.py --section templates/additions`
(на Linux команда Python обычно называется python3).

## Типичные ошибки

Пустая свёртка допустима не для каждого оператора; здесь сумма имеет начальный `0`. Группировка выражения и порядок вычисления операндов — разные правила. Запятая в показанном вызове задаёт последовательность действий.
