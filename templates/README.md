# Шаблоны C++

Шаблон описывает семейство функций или классов для разных типов и значений.
Начните после [функций и ссылок](../basics/README.md) и
[основ классов](../oop/README.md). Для правил выбора перегрузки полезен
[урок о перегрузке функций](../basics/lesson-040-function-overloading/README.md).

## Уроки курса

1. [041. Шаблоны функций](lesson-041-function-templates/README.md).
2. [126. Шаблоны классов](lesson-126-class-templates/README.md).
3. [127. Наследование шаблонных классов](lesson-127-class-templates-inheritance/README.md).
4. [128. Специализация шаблонов](lesson-128-class-templates-specialization/README.md).

Номера, имена папок и исходные варианты сохранены. Новые сценарии находятся
в [bonus](bonus/README.md), отдельно от курса.
`_template/` в корне — заготовка урока, а не раздел шаблонов языка.

## Продолжение

[Вывод параметров и специализация](bonus/README.md) → пакеты и forwarding →
`if constexpr` → concepts. Темы бонусов можно изучать по порядку их списка.
Шаблоны появились в C++98; отдельные возможности — в C++11/14/17/20.
Сборка большинства примеров проекта — C++17, concepts — C++20.

## Сборка и запуск

[Общий запуск в VS Code](../README.md#сборка-и-запуск-в-vs-code) ·
[Команды терминала](../README.md#сборка-из-терминала).
Каждый `main*.cpp` — отдельная программа; указанный в уроках `main 2.cpp`
с пробелом тоже запускается отдельно. Поддерживающие исходники не объединяют
с несколькими функциями `main`.

Из корня: `python scripts/check-bonuses.py --section templates/bonus`
(Linux: `python3`). Новые папки учитывает генератор IntelliSense.
[Версии C++](../docs/cpp-versions.md) · [Каталог](../LESSONS.md).
