# 22. Индексирование пакета параметров

## Версия C++

Режим сборки — **C++26**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках. Для C++26 реализация ещё может быть неполной.

## Что изучаем

Выбираем тип или значение по индексу, известному при компиляции. Нужны пакеты параметров и `sizeof...`.

## Примеры

- [main.cpp](main.cpp) — выбор типа и чисел; вывод `20`.

## Как это работает

Запись `T...[I]` выбирает тип с номером `I`, а `values...[I]` — выражение из пакета параметров функции. Индексация начинается с нуля. Ограничение `requires` отклоняет пустой пакет и выход за границы до входа в функцию. Пример также проверяет крайние допустимые индексы.

## Сборка и запуск

[Настройка компилятора и запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).
Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh templates/bonus/22-pack-indexing/main.cpp
./build/templates/bonus/22-pack-indexing/main
```

Для остальных вариантов замените `main.cpp` и имя исполняемого файла. На Windows вызовите `scripts/build-windows.sh` через MSYS2 Bash, затем соответствующий файл `build/templates/bonus/22-pack-indexing/main.exe`. Готовые `tasks.json` и `launch.json` содержат оба варианта системы.

Ввода, сетевых служб и постоянных файлов не требуется, если ниже не указано другое. Каждый пример проверяет результаты; успех — строка `OK modern-example` и код `0`, ошибка проверки — код `1`.

## Типичные ошибки

Индекс не может быть произвольной переменной, известной только при запуске. Пакет не является массивом, у него нет обычного `operator[]`. Вариант со ссылками требует отдельно сохранить категории значений и время жизни; пример принимает числа по значению.
