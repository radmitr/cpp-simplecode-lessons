# 18. type_traits, `if constexpr` и enable_if

## Версия C++

`std::string_view`, `if constexpr` — **C++17**.
`constexpr` — **C++11**.
`std::exception` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Traits представляют свойства и преобразования типов. `if constexpr`
в шаблоне отбрасывает неподходящую зависимую ветвь при инстанцировании; это не
способ скрыть любую синтаксическую ошибку. enable_if показывает распространённый
старый способ исключить перегрузку. Для нового C++20-кода часто понятнее concepts.
Проверка заранее названной операции не перечисляет поля — это отдельная задача
раздела bonus/reflection.

## Как это работает

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Каждый исходник здесь — самостоятельный исполняемый пример.

`describe(7)` выбирает integer, `describe(2.5)` — other ещё при инстанцировании
нужной специализации. Поэтому строка вывода: integer other.

~~~cpp
if constexpr (std::is_integral_v<T>) {
    // Только для подходящих T.
}
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

В отличие от обычного if неподходящая зависимая ветвь шаблона не обязана
быть исполняемым кодом для данного `T`. Но синтаксис и независящие от `T`
ошибки всё равно проверяются.

enable_if у `twice` оставляет перегрузку только для целочисленных типов.
Если условие не выполнено, подходящего кандидата может не остаться:
это ограничение интерфейса, а не runtime-ветка возврата ошибки.
remove_reference_t преобразует тип, не меняя существующий объект.
Для сложных интерфейсов C++20 concepts обычно дают более явные требования.

### Результат и проверка

После показанных в коде значений последняя строка — `OK 18-traits-if-constexpr`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section templates/bonus`
(на Linux команда Python обычно называется python3).
