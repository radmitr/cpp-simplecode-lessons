# 23. Перенос квалификаторов через forward_like

## Версия C++

Режим сборки — **C++23**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках.

## Что изучаем

Передаём поле с той же константностью и категорией значения, что у другого объекта. Нужны `std::forward` и ссылочные типы.

## Примеры

- [main.cpp](main.cpp) — четыре типа результата; вывод `8`.

## Как это работает

`std::forward_like<Model>(value)` использует `Model` как образец: lvalue-модель даёт lvalue, rvalue-модель — rvalue, константная модель добавляет `const`. Это преобразование ссылки; само по себе оно не перемещает данные. Пример проверяет четыре комбинации и изменяет исходное число через неконстантную lvalue-ссылку.

## Типичные ошибки

В отличие от `std::forward<T>`, модель здесь может описывать другой объект, а не выводимый тип самого аргумента. Не сохраняйте ссылку на поле временного объекта после его уничтожения.
