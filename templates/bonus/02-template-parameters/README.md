# 02. Параметры шаблонов, специализация и CTAD

## Версия C++

Шаблоны переменных, `std::integer_sequence` и `std::index_sequence` — **C++14**.

`CTAD`, `deduction guide` — **C++17**.
`std::array`, `decltype`, псевдонимы using — **C++11**.
`std::vector`, `std::exception`, `std::size_t` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Шаблон может принимать типы и значения. Частичная специализация
класса задаёт реализацию для формы `T*`, а не конкретного одного типа. CTAD
выводит аргументы шаблона класса; явная deduction guide сохраняет пример
на C++17. Псевдоним `using` не создаёт новый класс. Функциональные шаблоны не имеют
частичной специализации — для них используют перегрузки или ограничения.

## Примеры

- [main.cpp](main.cpp).
- [main2.cpp](main2.cpp): шаблоны переменных и пакет индексов C++14; вывод `4 0 3`.

## Как это работает

В `main2.cpp` `pi<T>` обозначает отдельную типизированную константу для каждого `T`,
а `pointer_v<T>` — булево свойство. Это шаблоны **переменных**, появившиеся в C++14.
`make_index_sequence<4>` создаёт тип с пакетом индексов `0,1,2,3`; функция `indices`
разворачивает пакет в `array`. Сам пакет не является массивом во время выполнения.
Успех этого варианта — `OK reference-example` и код `0`; ввода и файлов нет.

Нужны шаблоны функций, типы и константные выражения.

`Buffer<int, 3>` передаёт тип `int` и значение 3; N задаёт размер `array`.
Значение по умолчанию 4 используется, если второй аргумент пропущен.

~~~cpp
template<class T> struct Pointer<T*> : std::true_type {};
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Это частичная специализация для всех указателей формы `T*`, например `int*`.
Общий вариант для `int` наследует false_type.
`Pair pair`{7, 2.5} использует deduction guide и получает `Pair<int, double>`.
`Values<int>` — другое имя `vector<int>`, нового несовместимого типа не создаёт.

CTAD относится к шаблонам классов; вывод аргументов вызова функции —
другой процесс. Значение N должно быть допустимым константным аргументом,
его нельзя заменить произвольным введённым во время выполнения числом.
Частичную специализацию функций не пишут: выбирают перегрузку или ограничение.

## Типичные ошибки

Параметр типа и параметр-значение задают разные свойства специализации. CTAD выводит аргументы, но не превращает класс в динамически типизированный. Шаблоны функций нельзя частично специализировать как классы; для них используют перегрузки.
