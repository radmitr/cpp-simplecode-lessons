## Как это работает

Полный исходник: [main.cpp](main.cpp).

~~~cpp
const auto total = std::accumulate(values.begin(), values.end(), 0LL);
~~~

`values` содержит три числа по миллиарду. Суффикс `LL` у `0LL` выбирает
`long long` для аккумулятора: именно в этом типе хранятся промежуточные суммы.
Результат равен `3000000000`. Присваивание в широкий тип только после накопления
в `int` не исправило бы переполнение, случившееся внутри алгоритма.

Вторая часть складывает `1.5` и `2.5` с разным начальным значением:

- При `init = 0` аккумулятор имеет тип `int`. После первого шага получается
  `1`, после второго — `3`: дробная часть теряется на каждом присваивании.
- При `init = 0.0` аккумулятор имеет тип `double`. Промежуточное значение
  равно `1.5`, итоговое — `4.0`.

~~~text
Long long total: 3000000000
Int init: 3
Double init: 4
~~~

`static_assert` в программе проверяет тип целочисленного результата.
Широкий тип тоже имеет пределы: начальное значение выбирают с учётом
возможного результата всего диапазона.
