# 22. Многомерное представление mdspan

## Версия C++

Режим сборки — **C++23**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках.

## Что изучаем

Работаем с матрицей поверх уже выделенной памяти. Нужны массивы, индексы и время жизни объектов.

## Примеры

- [main.cpp](main.cpp) — постоянные размеры и два порядка хранения; вывод `7`.
- [main2.cpp](main2.cpp) — динамические размеры и строки с промежутками.

## Как это работает

`mdspan` хранит указатель, размеры и правило преобразования индексов в смещение. `layout_right` размещает соседние столбцы рядом, `layout_left` — соседние строки. У одного массива два представления могут показывать разные логические матрицы. `extents` задаёт постоянные размеры, `dextents` — размеры при запуске. `layout_stride` описывает строки с промежутками; во втором примере в каждой строке используются три числа из четырёх ячеек. Проверяются размерность `rank()`, размер по оси `extent()` и общий `size()`.

## Типичные ошибки

Представление не владеет памятью и не продлевает её жизнь. Индексы и размер буфера проверяет вызывающий код: обычный `operator[]` не является `at()`. Число элементов и требуемый размер памяти при нестандартном шаге могут различаться.
