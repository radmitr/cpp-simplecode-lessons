# 19. Владение с копированием значения

## Версия C++

Режим сборки — **C++26**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках. Для C++26 реализация ещё может быть неполной.

## Что изучаем

Копируем динамический объект независимо от оригинала, в том числе через базовый тип. Нужны RAII, умные указатели и наследование.

## Примеры

- [main.cpp](main.cpp) — indirect: независимая копия строки.
- [main2.cpp](main2.cpp) — polymorphic: копирование производного объекта через базовый интерфейс.

## Как это работает

Копирование `indirect<string>` создаёт отдельную строку. Поэтому изменение копии не меняет исходник. `polymorphic<Base>` дополнительно сохраняет фактический производный тип: при копировании круга через базовый интерфейс копируется круг. `in_place_type<Circle>` выбирает создаваемый тип явно. Хранилище управляется автоматически. Пример проверяет независимость данных и вызов виртуального метода после копирования.

Ввода, сетевых служб и постоянных файлов не требуется, если ниже не указано другое. Каждый пример проверяет результаты; успех — строка `OK modern-example` и код `0`, ошибка проверки — код `1`.

## Типичные ошибки

Это не разделяемое владение `shared_ptr` и не уникальное владение `unique_ptr`: копирование может выделять память и бросать исключения. Объекты должны поддерживать нужные операции копирования. После перемещения исходная обёртка может быть без значения; её нельзя разыменовывать. Не путать сохранение динамического типа с копированием самого `Base`, которое может срезать производную часть.
