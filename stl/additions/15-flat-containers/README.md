# 15. flat_map и flat_set

## Версия C++

Режим сборки — **C++23**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках.

## Что изучаем

Храним упорядоченные данные в последовательностях. Нужны обычные `map`, `set` и сравнение ключей.

## Примеры

- [main.cpp](main.cpp) — словарь и перенос его хранилища; вывод `a=5 c=3`.
- [main2.cpp](main2.cpp) — множество, повторения и sorted_unique.

## Как это работает

`flat_map` по умолчанию хранит ключи и значения в двух векторах, `flat_set` — ключи в одном. Поиск использует порядок ключей и занимает логарифмическое число сравнений; вставка в середину обычно сдвигает элементы. Пример проверяет `try_emplace`, `insert_or_assign`, поиск, удаление, а затем `extract` и восстановление через `replace`. Множество хранит один экземпляр каждого ключа; `flat_multiset` допускает повторения. `sorted_unique` позволяет пропустить сортировку только для уже проверенных данных.

## Типичные ошибки

После вставки и удаления прежние ссылки/итераторы могут стать недействительными. Не изменяйте ключ через обход. Для `replace` размеры ключей и значений должны совпадать, а ключи — быть отсортированы и уникальны. Нарушать эти предусловия ради демонстрации нельзя.
