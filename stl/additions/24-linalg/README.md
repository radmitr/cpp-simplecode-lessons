# 24. Линейная алгебра поверх mdspan

## Версия C++

Режим сборки — **C++26**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках. Для C++26 реализация ещё может быть неполной.

## Что изучаем

Умножаем матрицу на вектор и получаем скалярное произведение. Сначала изучите `mdspan`.

## Примеры

- [main.cpp](main.cpp) — matrix_vector_product и dot; ожидаются `50 110 500`.

## Как это работает

Алгоритмы `std::linalg` получают представления `mdspan`, а память принадлежит обычным массивам. В примере матрица из двух строк `[1,2]` и `[3,4]` умножается на вектор `[10,20]`: результат `[50,110]`. `dot` для входного вектора даёт `500`. Вызов без execution policy использует стандартную последовательную форму; интерфейс также предусматривает политики выполнения. Конкретное подключение оптимизированного BLAS — свойство реализации, не самого `mdspan`.

## Сборка и запуск

[Настройка компилятора и запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).
Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh stl/additions/24-linalg/main.cpp
./build/stl/additions/24-linalg/main
```

Для остальных вариантов замените `main.cpp` и имя исполняемого файла. На Windows вызовите `scripts/build-windows.sh` через MSYS2 Bash, затем соответствующий файл `build/stl/additions/24-linalg/main.exe`. Готовые `tasks.json` и `launch.json` содержат оба варианта системы.

Если возможности нет, программа печатает `UNAVAILABLE` и возвращает `77`: это пропуск, а не успешная демонстрация. Включённая ветка примера требует совместимой реализации; один флаг стандарта не добавляет отсутствующую библиотеку.

Ввода, сетевых служб и постоянных файлов не требуется, если ниже не указано другое. Каждый пример проверяет результаты; успех — строка `OK modern-example` и код `0`, ошибка проверки — код `1`.


Явный внешний профиль использует **stdBLAS и Kokkos mdspan**, а не нативную реализацию
стандартной библиотеки. Подготовьте зависимости из корня:

```bash
python3 scripts/prepare-reference-libraries.py
REFERENCE_LIBRARIES=1 bash scripts/build-linux.sh stl/additions/24-linalg/main.cpp
./build/stl/additions/24-linalg/main
```

Для остальных вариантов замените имя исходника/бинарного файла.
[Закреплённые версии, различия и возврат к стандартному профилю](../../../additions/execution/reference-libraries.md).

## Типичные ошибки

Размеры должны согласовываться, память результата должна быть записываемой. Не предполагать допустимость любого перекрытия входа и выхода. Не выдавать ручной цикл за выполнение стандартного API. В локальной libstdc++ заголовка `<linalg>` нет: включённая ветка этого примера здесь не проверена.
