# 05. Представление массива: `std::span`

## Версия C++

`std::span` — **C++20**. `std::array` — C++11.
Сборка урока: **C++20**, задана через `cxx-standard.txt`.

## Что изучаем

Функции часто нужны адрес и число элементов, но не владение массивом.
`span` объединяет эти два свойства в одном объекте.
Предварительно: [указатели и массивы](../../../basics/lesson-047-pointer-arithmetic/README.md),
[std::array](../02-array-initialization/README.md).

## Примеры

[main.cpp](main.cpp) — одно представление всего массива, другое его хвоста
и константный доступ к тем же элементам.

## Как это работает

`values` владеет тремя числами. `all` ссылается на них; `3` в его типе
означает статическую длину. `all.subspan(1)` создаёт представление от индекса
`1` до конца, без выделения памяти и копирования элементов.

После `tail[0] = 99` изменяется `values[1]`: массив общий.
`span<const int>` позволяет только читать элементы через этот доступ.
Само `const span<int>` запрещает менять объект представления,
но не делает элементы `int` константными.

`span<int>` с динамической длиной может описывать разные размеры.
`data()` возвращает адрес начала, `size()` — число элементов.
У `span` нет `push_back` и изменения размера массива: его задача —
описывать существующий диапазон. `subspan` тоже не меняет владельца.


Ввода и файлов нет. Успех — `0`, неверный результат — `1`.

~~~text
Original: 10 99 30

~~~

## Типичные ошибки

`span` не продлевает жизнь элементов. Возвращать представление локального
массива из функции нельзя. Перераспределение памяти `vector` может
сделать прежний `span` висячим. В этом C++20-примере `operator[]`
не гарантирует проверку границ; соблюдайте индексы и требования `subspan`.
