# 14. Перенос узлов контейнера

## Версия C++

`extract`, узлы и `merge` — C++17. Режим сборки — **C++17**. Достаточно GCC 11+.

## Что изучаем

Переносим элемент `map` без копирования его значения, меняем ключ и обрабатываем совпадения. Нужны `map`, `set`, перемещение и владение.

## Примеры

- [main.cpp](main.cpp) — ключ меняется с `1` на занятый `2`, затем на свободный `3`; вывод `3=7`.
- [main2.cpp](main2.cpp) — слияние `map` и перенос из `multiset` в `set`; вывод `10 20 11`.

## Как это работает

`extract` отделяет узел от дерева. Контейнер больше не владеет элементом, теперь им
владеет `node_type`; его деструктор освободит не вставленный обратно элемент.
Отсутствующий ключ даёт пустой узел. Пока узел непустой, `key()` позволяет менять
ключ, а `mapped()` — значение; обычный итератор `map` менять ключ не позволяет.

Для `map::insert(node)` без подсказки результат содержит три поля:
`inserted` — успех, `position` — вставленный или уже существующий элемент,
`node` — возвращённое владение при конфликте. В первом примере попытка вставить
ключ `2` не затирает `9`; возвращённый узел переименовывается в `3` и вставляется.
Значение `unique_ptr<int>` при этом не копируется.

`merge` переносит все допустимые узлы. В контейнере с уникальными ключами
совпавшие элементы остаются в источнике. Узлы совместимы не у любых контейнеров:
например, подходят `set`/`multiset` одного типа ключа и аллокатора,
а `map` и `unordered_map` между собой не подходят.

## Сборка и запуск

[Настройка и запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).
Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh stl/additions/14-node-handles/main.cpp
```

последняя строка `OK reference-example`, код завершения `0`;
нарушение проверки или необработанная ошибка — код `1`.

## Типичные ошибки

Аллокаторы непустого узла и получателя должны сравниваться равными.
Итератор извлечённого элемента недействителен; сохранённые ссылки/указатели на элемент
нельзя использовать, пока узел отделён, хотя после успешной вставки они снова пригодны.
`get_allocator`, `key` и `mapped` требуют непустой узел. Не путать эти узлы с
`flat_map::extract`, который отдаёт целые последовательности: [плоские контейнеры](../15-flat-containers/README.md).
