# 19. `std::accumulate` и тип аккумулятора

C++17. Нужны итераторы, диапазоны и основы вызываемых объектов.

`accumulate` последовательно сворачивает диапазон в одно значение.
Начальный init участвует в вычислении и определяет тип аккумулятора.

Для `vector` {2, 3, 4} результат с init = 0 равен 9, с init = 10 — 19.
Для массива {2, 3, 4, 5, 7, 10} сумма — 31, произведение с началом 1 — 8400.
Лямбда с b % 2 == 0 складывает **чётные** числа: 2 + 4 + 10 = 16,
хотя подпись результата в исходнике называется sum_odd.

0LL выбирает `long long`; обычный 0 выбирает `int` даже для элементов другого
числового типа. Это может приводить к сужению, потере дробной части или
переполнению. Диапазон результата всё равно нужно учитывать.

## Нечисловой результат

Обе строковые свёртки в `main` дают 2-3-4-5-7-10.
Одна начинает с arr[0] и обрабатывает хвост через `next(begin)`,
вторая начинает с пустой строки и отдельно обрабатывает первый разделитель.
Для пустого диапазона `accumulate` возвращает init; вариант с arr[0]
предполагает, что исходный массив непустой.

Алгоритм объявлен в numeric. reduce допускает другое группирование операций;
он не является полной заменой `accumulate` для неассоциативных операций.
