## Как это работает

`forward_list` хранит только движение вперёд, поэтому у итератора есть ++,
но нет --. Вставка/удаление работает относительно **предыдущего узла**.

После `push_front` и `pop_front` в примере остаются 15, 10, 5, 1, 33.
it передвигается с 15 на 10. `insert_after(it, 999)` вставляет 999 после 10,
`erase_after(it)` удаляет именно этот новый узел.
`before_begin()` позволяет вставить 1111 перед первым элементом.

~~~cpp
auto before = values.before_begin();
values.insert_after(before, 1111);
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

`before_begin()` — специальная позиция перед началом; её нельзя разыменовывать.
У `forward_list` нет `size()`, `push_back()` или произвольного доступа по индексу.
Число элементов при необходимости находят обходом, например distance.

Вставка не разрушает итераторы на другие узлы. После `erase_after` нельзя
использовать позицию удалённого узла, но итератор на предшественника остаётся.
Для цикла удаления важно хранить именно предшествующую позицию.
