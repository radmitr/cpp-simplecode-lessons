# 21. Сравнение диапазонов с предикатом

C++17. Нужны итераторы, диапазоны и основы вызываемых объектов.

У Point нет operator==. Лямбда передаёт equal правило сравнения:

~~~cpp
[](const Point& a, const Point& b) {
    return a.getX() == b.getX() && a.getY() == b.getY();
}
~~~

Оба vector содержат (2, 7), (10, 11), (3, 8), поэтому вывод equal: 1.
Сравнение получает const-ссылки: не копирует точки и не меняет их.
Переданы обе пары границ, поэтому различие размеров тоже обнаружится.

Предикат определяет, что именно считается равенством в этой операции.
Если сравнить только x, точки с разным y будут считаться совпавшими.
Это удобно для проверки отдельных свойств, но не меняет универсально
семантику всего типа Point.

Сравнение последовательное по позициям: одинаковые точки в другом порядке
могут дать false. Для равенства без учёта порядка есть is_permutation
либо отдельно выбранная стратегия сортировки.
