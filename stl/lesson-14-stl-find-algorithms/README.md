# 14. Поиск: `find`, `find_if` и `find_if_not`

C++17. Нужны итераторы, диапазоны и основы вызываемых объектов.

`find` ищет первое значение, равное заданному. `find_if` ищет первый элемент,
для которого предикат истинен, `find_if_not` — первый, для которого он ложен.
Все возвращают итератор, а при отсутствии — конец заданного диапазона.

~~~cpp
auto it = std::find_if(v.begin(), v.end(), [](int x) { return x % 2 == 0; });
if (it != v.end()) std::cout << *it;
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

`main.cpp` находит 33, затем первое чётное 12. В наборе v2 нет нечётных
и отрицательных чисел. `find_if_not` с условием x < 0 находит первое
неотрицательное — снова 12.

`main2.cpp` ищет `Person` по имени, баллам и сочетаниям условий.
Первая Маша имеет 179 баллов; первый с 50 баллами — Сергей.
По имени Иван возвращается **первый** Иван (150), а не оба совпадения.
Для всех результатов подходит `copy_if` из следующего урока.

Поиск линейный и не меняет порядок. Перед разыменованием обязательно
проверять конец; пустой диапазон также возвращает конец.
Для `set`/`map` их `find` использует структуру контейнера и обычно выгоднее
общего линейного `std::find`. Для отсортированного диапазона есть lower_bound,
но ему нужно согласованное с сортировкой сравнение.
