# 24. Перемешивание и владение объектами

C++17. Нужны итераторы, диапазоны и основы вызываемых объектов.

main.cpp сравнивает исторический random_shuffle и современный shuffle.
Первый удалён из стандарта в C++17, хотя libstdc++ может ещё предоставлять
его как расширение. Для переносимого C++17 используйте std::shuffle.

~~~cpp
std::mt19937 engine(std::random_device{}());
std::shuffle(values.begin(), values.end(), engine);
~~~

shuffle переставляет элементы, не меняя их набор. Новый порядок может
случайно совпасть с прежним; это не ошибка. Фиксированный seed удобен
для воспроизводимых опытов, но конкретная перестановка не обязана совпадать
между разными стандартными библиотеками. mt19937 не криптографический генератор.

## main2.cpp: что именно перемешивается

Через IAction вызываются действия кота, чая, собаки и сна.
Сначала показаны указатели на локальные объекты: они не владеют объектами,
удалять их нельзя. Затем массив указателей на new-объекты освобождается вручную.
Варианты с массивом и vector из unique_ptr освобождают объекты автоматически.

shuffle переставляет указатели/unique_ptr, а не внутренние данные действий.
Виртуальный деструктор IAction обеспечивает корректное полиморфное удаление.
Закрытые override в конкретных классах допустимо вызывать через публичный
базовый интерфейс. Ручной new-вариант не защищён от исключения между
выделениями; для прикладного кода предпочтительнее владение через RAII.
