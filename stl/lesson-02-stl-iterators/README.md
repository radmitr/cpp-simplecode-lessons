# 02. Итераторы и полуоткрытый диапазон

C++17. Нужны циклы, ссылки и базовые шаблоны типов.

Итератор обозначает позицию элемента. *it читает или изменяет элемент,
++it переходит к следующему. begin() обозначает начало, end() — позицию
после последнего элемента, которую разыменовывать нельзя.

В main сначала меняется первый элемент vector на 1000, затем каждый
увеличивается на один: получаются 1001, 455, 577, 621, 46, 4.
const_iterator позволяет обход без изменения через *it.
rbegin/rend дают обратный обход.

## Изменение контейнера

insert вставляет **перед** заданной позицией, erase удаляет её элемент.
erase(first, last) удаляет диапазон [first, last), не включая last.
После показанных вставки и удалений остаются 46, 999, 4.

~~~cpp
auto it = values.begin();
std::advance(it, 3);
~~~

Для vector допустимо it + 3, потому что итератор имеет произвольный доступ.
У list переход на три позиции требует последовательных шагов.
Нельзя переходить за допустимые границы диапазона.

Сохранённые итераторы не обновляются автоматически после insert/erase.
У vector перераспределение инвалидирует все позиции, а сдвиг при erase —
позиции начиная с удалённой. Для цикла удаления используйте возвращённый
erase итератор на следующий элемент.
