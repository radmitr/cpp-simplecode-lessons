## Как это работает

`list` хранит отдельные связанные узлы. Вставка перед известным итератором
и удаление известного узла не требуют сдвига остальных элементов.
Поиск самой позиции всё равно может занимать линейное время.

`main` начинает с 15, 64, 985, добавляет значения с обоих концов,
сортирует, удаляет крайние элементы, убирает соседние повторы, разворачивает,
вставляет/удаляет узлы и заменяет содержимое через `assign`.

### Особенности операций

- `list.sort()` сортирует узлы. `std::sort` требует произвольного доступа,
  которого у итераторов `list` нет.
- `unique()` удаляет только **соседние** одинаковые элементы.
  Две группы 99 с разных концов могут обе сохраниться.
- `remove(99)` удаляет все узлы со значением 99 и сразу меняет размер.
- `insert(it, value)` не меняет сам `it`: он продолжает обозначать прежний узел.
- `assign(3, 173745)` заменяет содержимое тремя одинаковыми числами.

У `list` нет [] и `it += 3`. `std::advance` делает нужное число переходов;
отрицательный шаг допустим для двунаправленного итератора внутри границ.
Вставка сохраняет итераторы на существующие узлы. Удаление инвалидирует
итераторы/ссылки только на удалённые элементы; после `assign`/`clear` старые
позиции использовать нельзя. Узлы не образуют непрерывный массив.
