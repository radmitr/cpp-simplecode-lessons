# 16. remove и физическое удаление

C++17. Нужны итераторы, диапазоны и основы вызываемых объектов.

std::remove не уменьшает контейнер: он сдвигает сохраняемые значения
к началу и возвращает **новый логический конец**.

~~~cpp
auto newEnd = std::remove(v.begin(), v.end(), 9);
v.erase(newEnd, v.end());
~~~

В main.cpp исходный размер 9 остаётся 9 после remove. После erase он равен 7,
значения: 12, 43, 4, 33, 7, 2, 4. Хвост между newEnd и прежним end
содержит допустимые, но не определённые для цели алгоритма значения;
не следует трактовать его как отдельный набор удалённых элементов.

## Варианты

main2.cpp удаляет Person по условию баллы < 150 **или** возраст > 25.
Остаются 5 записей; следующий фильтр баллы < 160 оставляет 3.
main3.cpp удаляет все обычные пробелы из строки, а не только лишние соседние.

Этот приём называется erase–remove. Для vector/string в C++20 удобны
std::erase и std::erase_if. У list есть собственные remove/remove_if,
которые действительно удаляют узлы; общий алгоритм и метод — разные операции.
После физического erase учитывайте инвалидирование итераторов.

## Запуск

Откройте main.cpp или main2.cpp или main3.cpp и нажмите F5 в VS Code.
Каждый main*.cpp собирается отдельно. [Команды Windows/Linux и карта STL](../README.md).
