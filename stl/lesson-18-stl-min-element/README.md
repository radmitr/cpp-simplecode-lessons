## Как это работает

`min_element` возвращает итератор первого минимального элемента.
В `main` минимумы `vector`, `list` и массива равны соответственно 2, -7 и 2.

`minmax_element` делает один проход и возвращает пару позиций:

~~~cpp
auto bounds = std::minmax_element(v.begin(), v.end());
if (bounds.first != v.end()) {
    std::cout << *bounds.first << ' ' << *bounds.second;
}
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Для последнего `vector` результат 2 и 43. При пустом диапазоне обе позиции
равны `end`. Перед разыменованием их проверяют.

### Редкий, но полезный нюанс равных значений

Отдельные `min_element` и `max_element` выбирают первое подходящее значение.
У `minmax_element` минимум — первый, максимум — **последний** среди равных.
Это может быть важно, когда возвращают запись с максимальным полем,
а остальные её поля различаются.

Подписи про «максимальный» в ветках отсутствия результата исходника — текст
диагностики, не изменение смысла `min_element`. Поиск минимумов не сортирует
и не удаляет элементы.
