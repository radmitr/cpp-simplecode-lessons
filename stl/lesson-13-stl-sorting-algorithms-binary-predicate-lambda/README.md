## Как это работает

`std::sort` меняет порядок элементов диапазона [`first`, last).
В `main.cpp` сортируются `vector` и обычный массив: по возрастанию, убыванию,
через именованные функции, стандартные функторы и лямбды.

~~~cpp
std::sort(v.begin(), v.end(), [](int a, int b) { return a > b; });
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Компаратор отвечает: «должен ли `a` стоять раньше b?». Он **бинарный**,
несмотря на подписи «унарный» у `greater`/`less` в исходнике.
`a` > b задаёт убывание, `a` < b — возрастание. Итоговый `vector`:
0, 2, 9, 12, 14, 23, 33, 43, 84.

### Требования и ошибки

Нужен итератор произвольного доступа: `vector`/`array` подходят, `list` — нет.
Сравнение должно задавать строгий слабый порядок. Нельзя использовать <=,
возвращать `true` для `a` с самим собой или менять сравниваемые элементы.
`std::sort` не сохраняет порядок эквивалентных элементов; для этого есть stable_sort.

`main2.cpp` сортирует `Person` сначала по имени, затем по убыванию баллов.
После второй сортировки прежний порядок имён для одинаковых баллов
не гарантируется. Для устойчивого правила укажите второй ключ в компараторе.
Строковое сравнение имён здесь не реализует языковую сортировку.

Не полагайтесь на неуточнённый `sort` и ADL: связь итераторов с `namespace std`
может зависеть от реализации. Переносимая явная запись — `std::sort`.
Сложность обычного `sort` — `O(n log n)` сравнений.
