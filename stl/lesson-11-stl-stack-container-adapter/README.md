# 11. std::stack: адаптер LIFO

C++17. Нужны циклы, ссылки и базовые шаблоны типов.

stack ограничивает интерфейс последовательного контейнера:
последним положили — первым извлекли. По умолчанию внутри deque;
в примере также показаны варианты на list и vector.

После push 10, 23, 35, 47 и emplace(51) вершина — 51, размер — 5.
pop() удаляет 51, после чего вершина становится 47.
Все три варианта выполняют один стековый алгоритм.

~~~cpp
while (!values.empty()) {
    std::cout << values.top();
    values.pop();
}
~~~

top читает верхний элемент, pop удаляет его и возвращает void.
Их не вызывают на пустом стеке. emplace передаёт аргументы конструктору
элемента; это не универсальная гарантия отсутствия любых временных объектов.

У stack нет публичного обхода begin/end. Функция printStack получает
адаптер **по значению** и опустошает копию, поэтому исходный стек не меняется.
Для тяжёлых элементов такое диагностическое копирование может быть дорого.
