# 12. Блочный контейнер hive

## Версия C++

Режим сборки — **C++26**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках. Для C++26 реализация ещё может быть неполной.

## Что изучаем

Добавляем и удаляем элементы, сохраняя адреса остальных. Нужны итераторы и правила их инвалидирования.

## Примеры

- [main.cpp](main.cpp) — вставка, удаление, адрес живого элемента, сортировка и уникальность.

## Как это работает

`hive` выделяет память блоками и может использовать освобождённые ячейки повторно. `insert` возвращает итератор нового элемента. Удаление инвалидирует итератор удалённого элемента, но не ссылки на остальные живые элементы. Порядок вставки не задаёт порядок обхода после повторного использования ячеек. Пример сохраняет адрес первого элемента, удаляет другой, вставляет ещё один и сравнивает адрес. `sort` и `unique` показаны отдельно в том же небольшом сценарии.

## Сборка и запуск

[Настройка компилятора и запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).
Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh stl/bonus/12-hive/main.cpp
./build/stl/bonus/12-hive/main
```

Для остальных вариантов замените `main.cpp` и имя исполняемого файла. На Windows вызовите `scripts/build-windows.sh` через MSYS2 Bash, затем соответствующий файл `build/stl/bonus/12-hive/main.exe`. Готовые `tasks.json` и `launch.json` содержат оба варианта системы.

Если возможности нет, программа печатает `UNAVAILABLE` и возвращает `77`: это пропуск, а не успешная демонстрация. Включённая ветка примера требует совместимой реализации; один флаг стандарта не добавляет отсутствующую библиотеку.

Ввода, сетевых служб и постоянных файлов не требуется, если ниже не указано другое. Каждый пример проверяет результаты; успех — строка `OK modern-example` и код `0`, ошибка проверки — код `1`.

## Типичные ошибки

Нет произвольного индексирования `operator[]`; итераторы не random access. Не читать удалённую ячейку. Стабильность адресов при обычных вставках не означает сохранение ссылок при любой операции, например сортировке или переупаковке. Заголовка `<hive>` в текущей локальной libstdc++ нет: рабочая ветка подготовлена по интерфейсу стандарта, но здесь не выполнялась.
