# Бонусы по STL

Дополнительные примеры вне курса SimpleCode. Исходные уроки сохраняют свои номера.

1. [Инициализация и копирование array](01-array-initialization/README.md) —
   после урока [«06. `std::array`: фиксированный размер»](../lesson-06-stl-array/README.md); нулевые элементы, самостоятельная копия, массив размера 0.
2. [Тип аккумулятора accumulate](02-accumulator-type/README.md) —
   после урока [«19. `std::accumulate` и тип аккумулятора»](../lesson-19-stl-accumulate/README.md); широкая сумма и потеря дробной части при целочисленном `init`.
3. [Конструкторы vector: круглые и фигурные скобки](03-vector-initialization/README.md) —
   после урока [«01. `std::vector`: размер, ёмкость и элементы»](../lesson-01-stl-vector/README.md); количество элементов и список значений.

4. [Результат или ошибка: `std::expected`](04-expected/README.md) — C++23;
   после функций, шаблонов, строк и исключений.

5. [Представление массива: `std::span`](05-span/README.md) — C++20;
   длина, поддиапазон, константный доступ и время жизни.

Бонус можно изучать сразу после указанного урока; номер здесь обозначает
порядок добавления. Первые три примера собираются как C++17; `expected` — как C++23. В каждой папке есть
`main.cpp`, README и настройки VS Code для Windows/Linux.
**F5** запускает с отладчиком, **Ctrl+F5** — без отладчика.
Команды терминала, результат и код завершения описаны в README бонуса.
