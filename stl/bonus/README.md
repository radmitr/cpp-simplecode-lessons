# Бонусы по STL

Начните с [контейнеров, итераторов и алгоритмов курса](../README.md). Порядок бонусов: создание контейнеров → представления → результаты операций → диапазоны → хранение и вызываемые объекты → память и вычисления. Для политик выполнения нужны основы многопоточности; для `mdspan`, SIMD и линейной алгебры — массивы и численные операции.

Номера папок задают порядок изучения внутри раздела. Уроки SimpleCode сохраняют исходную нумерацию.

## Как работать

Откройте корень проекта или папку урока и выберите нужный исходник.
[F5, Ctrl+F5 и команды терминала](../../README.md#сборка-и-запуск-в-vs-code).
