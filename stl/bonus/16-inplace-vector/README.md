# 16. Вектор с фиксированной вместимостью

## Версия C++

Режим сборки — **C++26**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках. Для C++26 реализация ещё может быть неполной.

## Что изучаем

Храним переменное число объектов внутри самого контейнера. Нужны `vector`, конструкторы и исключения.

## Примеры

- [main.cpp](main.cpp) — проверяемое и непроверяемое добавление, переполнение, нулевая вместимость.
- [main2.cpp](main2.cpp) — конструирование и уничтожение только занятых ячеек.

## Как это работает

`inplace_vector<T,N>` резервирует место для `N` объектов внутри себя, но создаёт только `size()` из них. `push_back` при переполнении бросает `bad_alloc`, `try_push_back` возвращает пустой результат без добавления. В актуальной реализации GCC 16 это `optional<T&>`; ранняя редакция API возвращала указатель. Проверка через `bool` подходит для обеих форм. `unchecked_push_back` вызывается только после проверки свободного места. Удаление уничтожает элемент; пример со счётчиком показывает, что неиспользованная вместимость не содержит живых объектов. Нулевая вместимость допустима. В отличие от `vector`, увеличить максимальную вместимость нельзя.

## Сборка и запуск

[Настройка компилятора и запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).
Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh stl/bonus/16-inplace-vector/main.cpp
./build/stl/bonus/16-inplace-vector/main
```

Для остальных вариантов замените `main.cpp` и имя исполняемого файла. На Windows вызовите `scripts/build-windows.sh` через MSYS2 Bash, затем соответствующий файл `build/stl/bonus/16-inplace-vector/main.exe`. Готовые `tasks.json` и `launch.json` содержат оба варианта системы.

Если возможности нет, программа печатает `UNAVAILABLE` и возвращает `77`: это пропуск, а не успешная демонстрация. Включённая ветка примера требует совместимой реализации; один флаг стандарта не добавляет отсутствующую библиотеку.

Ввода, сетевых служб и постоянных файлов не требуется, если ниже не указано другое. Каждый пример проверяет результаты; успех — строка `OK modern-example` и код `0`, ошибка проверки — код `1`.

## Типичные ошибки

Не путайте размер с вместимостью. Перемещение контейнера может перемещать его элементы: внутреннее хранилище нельзя просто отдать новому объекту. Ссылки на удалённые элементы недействительны. Исключения конструктора элемента возможны даже при наличии места.
