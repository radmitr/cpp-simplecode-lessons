# 23. Поэлементные вычисления SIMD

## Версия C++

Режим сборки — **C++26**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках. Для C++26 реализация ещё может быть неполной.

## Что изучаем

Выполняем одинаковую арифметику над несколькими числами. Нужны массивы и обычные циклы.

## Примеры

- [main.cpp](main.cpp) — загрузка, арифметика, маска, свёртка и сохранение; сумма `20`.

- [main2.cpp](main2.cpp) — неполный входной блок, нулевой хвост, частичное сохранение и маски; вывод `5 7 0`.

## Как это работает

Актуальный интерфейс `<simd>` использует пространство `std::simd`, тип `vec<T,N>` и функции загрузки/сохранения. Пример загружает четыре числа, умножает каждое на два и сохраняет результат. Сравнение создаёт маску; `all_of` проверяет все её позиции, `reduce` складывает элементы. Это параллельные по данным операции внутри потока, а не создание нескольких `std::thread`. `main2.cpp` читает два числа в блок из четырёх позиций; незаполненные позиции становятся нулями, а сохранение в массив длиной три записывает только его три позиции.

В GCC 16.2 заголовок предоставляет реализацию, но публичный макрос `__cpp_lib_simd` ещё не определён. Поэтому проверка доступности дополнительно учитывает внутренний маркер libstdc++ `__glibcxx_simd`; это явно зависимая от GCC временная мера, а не переносимый контракт макроса.

Стандарт не обещает конкретного ускорения или конкретной инструкции процессора.

## Сборка и запуск

[Настройка компилятора и запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).
Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh stl/bonus/23-simd/main.cpp
./build/stl/bonus/23-simd/main
```

Для остальных вариантов замените `main.cpp` и имя исполняемого файла. На Windows вызовите `scripts/build-windows.sh` через MSYS2 Bash, затем соответствующий файл `build/stl/bonus/23-simd/main.exe`. Готовые `tasks.json` и `launch.json` содержат оба варианта системы.

Если возможности нет, программа печатает `UNAVAILABLE` и возвращает `77`: это пропуск, а не успешная демонстрация. Включённая ветка примера требует совместимой реализации; один флаг стандарта не добавляет отсутствующую библиотеку.

Ввода, сетевых служб и постоянных файлов не требуется, если ниже не указано другое. Каждый пример проверяет результаты; успех — строка `OK modern-example` и код `0`, ошибка проверки — код `1`.

## Типичные ошибки

Не смешивайте старые примеры `std::experimental::simd` с текущим интерфейсом. `unchecked_load/store` требуют достаточно элементов; для неполного хвоста существуют `partial_load/store`. Специальный флаг выравнивания допустим только для действительно выровненной памяти. Порядок суммирования вещественных чисел может менять округление.
