# 15. optional со ссылкой и обход optional

## Версия C++

Режим сборки — **C++26**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках. Для C++26 реализация ещё может быть неполной.

## Что изучаем

Представляем необязательную ссылку без копирования объекта и обходим optional как диапазон из нуля или одного элемента. Нужен обычный `optional`.

## Примеры

- [main.cpp](main.cpp) — запись через ссылку, перепривязка, reset и диапазон.

## Как это работает

`optional<int&>` хранит связь с существующим числом. Запись через `value()` изменяет это число. `emplace(other)` меняет объект, на который ссылается обёртка; `reset()` убирает связь, но не уничтожает число. Обычный `optional<int>` в C++26 можно обходить циклом и использовать в конвейере ranges. Для отсутствующего значения цикл не выполняется. Пример сравнивает оба случая.

## Типичные ошибки

Обёртка со ссылкой не владеет объектом и не продлевает его жизнь. Различайте переназначение ссылки и запись через неё. Не разыменовывайте пустой optional: проверяйте состояние или используйте проверяемый `value()`.
