# 12. Адаптеры и алгоритмы диапазонов

## Версия C++

Режим сборки — **C++23**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках.

## Что изучаем

Объединяем последовательности, строим окна и группы, сохраняем результат в контейнер. Сначала изучите предыдущий бонус о представлениях.

## Примеры

- [main.cpp](main.cpp) — zip, enumerate и ranges::to; изменение элемента через ссылку.
- [main2.cpp](main2.cpp) — окна, группы, декартово произведение и разделители.
- [main3.cpp](main3.cpp) — свёртки, последний элемент, поиск и перемещение unique_ptr.

## Как это работает

В [main2.cpp](main2.cpp) один и тот же диапазон `[1,2,3,4,5]` даёт разные результаты:

| Адаптер | Что получается |
|---|---|
| `chunk(2)` | `[1,2]`, `[3,4]`, `[5]` |
| `slide(2)` | `[1,2]`, `[2,3]`, `[3,4]`, `[4,5]` |
| `stride(2)` | `1,3,5` |
| `adjacent<2>` | Пары `(1,2)`, `(2,3)`, `(3,4)`, `(4,5)` |
| `chunk_by` с условием `a / 3 == b / 3` | Группы `[1,2]` и `[3,4,5]` |

У `chunk`, `slide` и `stride` размер/шаг должен быть положительным.
`chunk_by` проверяет соседние элементы, а не сравнивает каждый с первым в группе.

`zip` объединяет элементы с одинаковым индексом и останавливается на самом коротком диапазоне. `enumerate` добавляет индекс, а изменение ссылочного элемента меняет исходник. `chunk(2)` даёт неперекрывающиеся группы, `slide(2)` — перекрывающиеся окна, `stride(2)` — каждый второй элемент. `adjacent<2>` выдаёт пары, а `chunk_by` группирует соседей по предикату. `join_with` вставляет разделитель, `cartesian_product` строит все сочетания. `ranges::to` материализует представление, то есть сохраняет результаты в новый контейнер. `fold_left` и `fold_right` различаются направлением и порядком аргументов. `find_last` возвращает поддиапазон от последнего совпадения; перед чтением проверяется пустота.

## Сборка и запуск

[Настройка компилятора и запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).
Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh stl/bonus/12-ranges-adaptors/main.cpp
./build/stl/bonus/12-ranges-adaptors/main
```

Для остальных вариантов замените `main.cpp` и имя исполняемого файла. На Windows вызовите `scripts/build-windows.sh` через MSYS2 Bash, затем соответствующий файл `build/stl/bonus/12-ranges-adaptors/main.exe`. Готовые `tasks.json` и `launch.json` содержат оба варианта системы.

Ввода, сетевых служб и постоянных файлов не требуется, если ниже не указано другое. Каждый пример проверяет результаты; успех — строка `OK modern-example` и код `0`, ошибка проверки — код `1`.

## Типичные ошибки

Не путать окно с копией данных. Большинство представлений ссылается на исходник. Бесконечный `repeat` ограничивайте `take` до материализации. Не обращаться к пустому результату поиска. `as_rvalue` разрешает перемещение при последующем чтении; само представление ничего не перемещает.
