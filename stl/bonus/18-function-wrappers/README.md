# 18. Ссылка на функцию и копируемая обёртка

## Версия C++

Режим сборки — **C++26**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках. Для C++26 реализация ещё может быть неполной.

## Что изучаем

Выбираем невладеющую ссылку на вызываемый объект или владеющую копируемую обёртку. Нужны лямбды и `std::function`.

## Примеры

- [main.cpp](main.cpp) — невладеющая ссылка, два вызова; затем копируемая noexcept-обёртка.

## Как это работает

`function_ref` ссылается на уже живой вызываемый объект и не продлевает его жизнь. В примере лямбда меняет внешнюю переменную, и вызов через ссылку видит новое значение. `copyable_function` владеет своей копией цели; сигнатура может задавать `const`, ссылочные квалификаторы и `noexcept`. Вторая обёртка копируется независимо. Пустота владеющей обёртки проверяется перед вызовом.

## Сборка и запуск

[Настройка компилятора и запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).
Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh stl/bonus/18-function-wrappers/main.cpp
./build/stl/bonus/18-function-wrappers/main
```

Для остальных вариантов замените `main.cpp` и имя исполняемого файла. На Windows вызовите `scripts/build-windows.sh` через MSYS2 Bash, затем соответствующий файл `build/stl/bonus/18-function-wrappers/main.exe`. Готовые `tasks.json` и `launch.json` содержат оба варианта системы.

Если возможности нет, программа печатает `UNAVAILABLE` и возвращает `77`: это пропуск, а не успешная демонстрация. Включённая ветка примера требует совместимой реализации; один флаг стандарта не добавляет отсутствующую библиотеку.

Ввода, сетевых служб и постоянных файлов не требуется, если ниже не указано другое. Каждый пример проверяет результаты; успех — строка `OK modern-example` и код `0`, ошибка проверки — код `1`.

## Типичные ошибки

Не возвращать `function_ref` на локальную лямбду и не хранить ссылку на уничтоженную временную цель. Копия лямбды с захватом по ссылке всё равно ссылается на тот же внешний объект. Для цели без копирования используйте изученную `move_only_function`. Нельзя вызывать пустую обёртку.
