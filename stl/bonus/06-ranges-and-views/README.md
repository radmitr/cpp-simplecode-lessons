# 06. Диапазоны, представления и время жизни

## Версия C++

Режим сборки — **C++20**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках.

## Что изучаем

Строим последовательность обработки без промежуточных контейнеров. Нужны итераторы, лямбды и `vector`.

## Примеры

- [main.cpp](main.cpp) — конвейер filter/transform/take и проверка результата `20 40`.
- [main2.cpp](main2.cpp) — ссылка на исходник, владение временным контейнером, borrowed_range.

## Как это работает

В `main.cpp` исходные числа проходят `filter`, затем `transform`, затем `take`. Вычисления происходят при обходе, а не при создании конвейера: результат — `20 40`. Представление обычно не хранит результаты. В `main2.cpp` представление над lvalue-вектором ссылается на его элементы; изменение элемента видно при следующем обходе. Представление над временным вектором владеет перенесённым контейнером. `borrowed_range` означает, что уничтожение самого объекта диапазона не обязательно делает его итераторы недействительными; это не отменяет время жизни исходной памяти. Вектору данные принадлежат, `span` — нет.

## Сборка и запуск

[Настройка компилятора и запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).
Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh stl/bonus/06-ranges-and-views/main.cpp
./build/stl/bonus/06-ranges-and-views/main
```

Для остальных вариантов замените `main.cpp` и имя исполняемого файла. На Windows вызовите `scripts/build-windows.sh` через MSYS2 Bash, затем соответствующий файл `build/stl/bonus/06-ranges-and-views/main.exe`. Готовые `tasks.json` и `launch.json` содержат оба варианта системы.

Ввода, сетевых служб и постоянных файлов не требуется, если ниже не указано другое. Каждый пример проверяет результаты; успех — строка `OK modern-example` и код `0`, ошибка проверки — код `1`.

## Типичные ошибки

Не возвращать представление на локальный контейнер. Не считать ленивый `transform` однократным вычислением. Изменение размера вектора может инвалидировать итераторы. У `filter` возможен кэш начала; не перестраивайте его предикат изменением данных во время обхода.
