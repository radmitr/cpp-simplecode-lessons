# 10. Вызываемые объекты без копирования

## Версия C++

Режим сборки — **C++23**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках.

## Что изучаем

Храним лямбду, владеющую `unique_ptr`, и фиксируем аргументы функции. Нужны перемещение и `std::function`.

## Примеры

- [main.cpp](main.cpp) — владение и перенос; вывод `12`.
- [main2.cpp](main2.cpp) — bind_front, bind_back, invoke_r и явная ссылка.

## Как это работает

Лямбду с `unique_ptr` нельзя копировать. `move_only_function` принимает такую цель и перемещает владение в новую обёртку. Пример проверяет пустоту старой обёртки после переноса и сигнатуру `noexcept`. Квалификаторы `const`, `&`, `&&`, `noexcept` в сигнатуре ограничивают допустимую цель и способы вызова. `bind_back` фиксирует последние аргументы, `bind_front` — первые. Значения обычно сохраняются внутри; `std::ref` явно сохраняет ссылку. `invoke_r<R>` вызывает цель и приводит результат к `R`.

## Типичные ошибки

Вызов пустой `move_only_function` нарушает предусловие — проверяйте её через `if`. Она не копируется и не предоставляет `target()`. Ссылка через `std::ref` требует живого объекта. Обёртка не делает захваты потокобезопасными.
