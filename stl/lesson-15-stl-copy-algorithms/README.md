## Как это работает

`std::copy` переписывает исходный диапазон в выходной, `copy_if` — только
элементы с истинным предикатом. Исходный people в `main` не изменяется.

~~~cpp
std::vector<Person> selected;
std::copy_if(people.begin(), people.end(), std::back_inserter(selected),
             [](const Person& p) { return p.getName() == "Иван"; });
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

back_inserter преобразует запись через выходной итератор в `push_back`.
Поэтому selected можно оставить пустым: он будет расти по мере копирования.

### Что отбирает программа

Полная копия содержит 13 записей. Выборка по имени Иван — 2,
по баллам меньше 100 — 4, возрасту больше 25 — 5.
Сочетание возраста больше 25 и баллов больше 140 оставляет 4 записи;
добавление имени Андрей — 2. Выборка по возрасту отдельно сортируется
по убыванию возраста.

### Границы назначения

`copy(..., emptyVector.begin())` не создаёт элементов. Без inserter в выходном
диапазоне уже должно быть достаточно живых объектов. `reserve` даёт память,
но не делает такой вызов допустимым: нужен `resize` либо back_inserter.

`copy_if` сохраняет относительный порядок выбранных элементов.
При перекрывающихся диапазонах действуют ограничения направления копирования;
для сдвига вправо часто нужен copy_backward. Для передачи владения ресурсами
из элементов существует алгоритм `std::move`; обычное копирование `unique_ptr`
не допускается.
