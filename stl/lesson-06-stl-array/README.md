# 06. std::array: фиксированный размер

C++17. Нужны циклы, ссылки и базовые шаблоны типов.

`std::array<int, 5>` хранит ровно пять int внутри самого объекта.
Размер — часть типа и не меняется при выполнении. Копирование array копирует
элементы, в отличие от обычного массива, который нельзя присвоить целиком.

main выводит 4, 33, 96, 11, 73 разными способами, проверяет at(111),
показывает front = 4 и back = 73, затем fill(-1) заменяет все пять значений.

~~~cpp
std::array<int, 5> a{}; // Все элементы равны нулю.
a.at(0) = 42;          // Проверяемый доступ.
~~~

at выбрасывает out_of_range при неверном индексе; [] требует корректного индекса.
Подписи об Assertion в комментариях относятся к конкретному режиму библиотеки,
а не к гарантии обычного operator[].

У array нет reserve/resize/push_back. Итераторы имеют произвольный доступ,
data() даёт начало непрерывного диапазона. Даже `array<T, 0>` допустим,
но front/back/разыменование begin у пустого массива недопустимы.
В данном примере printArray принимает const-ссылку, поэтому копии массива нет.
