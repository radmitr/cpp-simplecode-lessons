## Как это работает

`queue` извлекает элементы в порядке добавления. Для 45, 23, 81, 10
`front = 45`, `back = 10`; после `pop` `front` становится 23.
По умолчанию используется `deque`, также показан `list`. `vector` не имеет `pop_front`
и не подходит для этого обычного интерфейса `queue`.

`priority_queue` выбирает элемент по приоритету. При `std::less` вершина —
наибольшее число 81, затем 45, 23, 10. При `std::greater` — наименьшее:
10, 23, 45, 81.

### Доступ и извлечение

У `queue` есть `front`/`back`, у `priority_queue` — `top`.
`pop` удаляет элемент, но не возвращает его; сначала читают значение.
Пустоту проверяют до доступа. Печатные функции копируют адаптер и разбирают
копию, поэтому их вывод не удаляет элементы исходного контейнера.

В `minPriorityQueue` после первого `pop` в исходнике один раз вызывается
`printPriorityQueue(priorityQueue)` — печать уже опустевшей другой очереди.
Пустой вывод в этом месте не означает, что `minPriorityQueue` пуста:
её следующие `top`/`size` и цикл относятся к правильному объекту.

`priority_queue` не обещает порядок среди одинаковых приоритетов.
Для неё нужен контейнер с произвольным доступом (обычно `vector`/`deque`), а не `list`.
Смена компаратора меняет смысл «самого приоритетного» элемента.
