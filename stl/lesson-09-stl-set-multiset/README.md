# 09. `std::set` и `std::multiset`

C++17. Нужны циклы, ссылки и базовые шаблоны типов.

`set` хранит уникальные ключи в порядке сравнения. `main.cpp` начинает с
5, 23, 76, 11; повторная вставка 2 не создаёт дополнительные элементы.

~~~cpp
auto result = values.insert(6);
// result.first — позиция; result.second — был ли создан новый элемент.
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Вставка существующего 76 возвращает `false` и позицию уже имеющегося ключа.
`find` возвращает `end` при отсутствии. `erase(5)` даёт 1, `erase(4444)` — 0:
возвращается число удалённых элементов.

## Ввод и `multiset`

`main.cpp` ждёт целое число в терминале: например 76. При неверном вводе
проверки состояния `cin` в учебном коде нет; используйте корректное целое.
`main2.cpp` показывает `multiset`, который разрешает повторяющиеся ключи.
`lower_bound(1)` даёт первую единицу, `upper_bound(1)` — первую позицию после
всех единиц (здесь 16). `equal_range` даёт обе границы.

Диапазон границ полуоткрытый; `upper_bound` может быть `end`, его нельзя
без проверки разыменовывать для произвольных данных.
Ключи `set` не изменяют через итератор: это нарушило бы порядок.
Уникальность определяется сравнением, а не обязательно `operator==`.
Поиск/вставка/удаление по ключу обычно оцениваются `O(log n)`.
