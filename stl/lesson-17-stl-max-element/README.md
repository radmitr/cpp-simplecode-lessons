## Как это работает

`max_element` возвращает позицию максимума, а не отдельную копию значения.
Если максимумов несколько, выбирается первый. Для пустого диапазона
возвращается last, поэтому перед *`it` нужна проверка.

`main.cpp` находит 43 в `vector`, 55 в `list` и 77 в обычном массиве.

~~~cpp
auto it = std::max_element(values.begin(), values.end());
if (it != values.end()) std::cout << *it;
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Алгоритм не требует сортировки и не меняет контейнер. Для n непустых элементов
достаточно n - 1 сравнений; предварительная сортировка ради одного максимума
дала бы лишнюю работу.

Дополнительный бинарный компаратор определяет отношение «меньше».
Для объектов можно сравнивать нужное поле; при `std::greater` смысл выбранного
«максимума» меняется на минимум по обычному числовому порядку.
Итератор остаётся пригодным только пока контейнер и соответствующий элемент
живут и не произошло его инвалидирование.
