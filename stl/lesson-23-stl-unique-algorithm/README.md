## Как это работает

`unique` объединяет **соседние** эквивалентные элементы и возвращает
новый логический конец, не изменяя размер `vector` самостоятельно.

В `main` {1, 2, 2, 2, 5, 4, 4} превращается в префикс {1, 2, 5, 4}.
После `erase(result, end)` размер действительно становится 4.
Напечатанный до `erase` хвост не является определённым результатом дедупликации.

~~~cpp
v.erase(std::unique(v.begin(), v.end()), v.end());
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

`unique_copy` не меняет источник: в примере он записывает
0, 1, 2, 3, 5, 4, 7 в новый `list` через back_inserter.

### Все повторы или только соседние

Для 1, 2, 1 обычный `unique` сохранит обе единицы. Если порядок не важен,
можно сначала `sort`, затем `unique`/`erase`. Если порядок важен, нужен другой
алгоритм с запоминанием уже встреченных значений.

Пользовательский предикат должен задавать эквивалентность:
рефлексивность, симметричность и транзитивность. Несогласованное условие
делает ожидаемый результат алгоритма ненадёжным.
