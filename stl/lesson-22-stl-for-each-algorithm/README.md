# 22. `std::for_each` и ссылки на элементы

C++17. Нужны итераторы, диапазоны и основы вызываемых объектов.

В `main` три обхода одного `vector` {3, 65, 17, 1}:
именованная `foo`, лямбда и range-based `for`. Каждый выводит те же четыре числа.

~~~cpp
std::for_each(v.begin(), v.end(), [](int& value) {
    std::cout << value << '\n';
});
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Параметр `int&` обозначает существующий элемент; присваивание `value` изменило бы
`vector`. Параметр `int` копировал бы значение, `const int&` разрешил бы только чтение.
Текущие функции ничего не меняют.

Обычный `for_each` без execution policy идёт в порядке итераторов.
Функциональный объект может копироваться; для накопленного в нём состояния
можно использовать возвращённый объект или явно спроектированный захват.
Для построения другого диапазона часто лучше transform, а для простого
обхода с break/continue — обычный цикл.

Во время обхода не меняйте контейнер так, чтобы инвалидировались используемые
итераторы. Удаление элементов требует отдельного корректного алгоритма.
