## Как это работает

`map` связывает уникальный ключ с изменяемым значением. Элемент выглядит
как `pair<const Key, Value>`: ключ сохраняет порядок, значение можно менять.

`main.cpp` добавляет товары с числовыми ключами и записи с именами.
Повторный `emplace` с ключом 22 не заменяет прежнее «гаджет» и возвращает `false`.
`find(222)` даёт `end`; at для отсутствующего «Билли» бросает `out_of_range`.

### Важное различие [] и `at()` и `find()`

~~~cpp
std::cout << map1[999]; // Вставит отсутствующий ключ с пустой строкой.
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

`operator[]` — не чистая проверка наличия. Для существующего ключа он возвращает
ссылку, для отсутствующего создаёт значение по умолчанию. at проверяет наличие
без вставки; `find` позволяет обработать отсутствие без исключения.
В C++17 insert_or_assign обновляет значение, а try_emplace может создавать
его только при отсутствии ключа.

`main2.cpp` хранит несколько записей «Петя» в `multimap`. У него нет []/at,
потому что одному ключу соответствует не единственное значение;
для группы используют equal_range.

Обход `map` упорядочен по ключу, а не времени вставки. Сравнение строк здесь
не является языковой сортировкой русских имён по правилам словаря.
