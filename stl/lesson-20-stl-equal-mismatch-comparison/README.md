# 20. equal и mismatch: границы двух диапазонов

C++17. Нужны итераторы, диапазоны и основы вызываемых объектов.

Трёхитераторная equal(first1, last1, first2) проверяет только столько
элементов второго диапазона, сколько есть в первом.
В main первая проверка даёт true: шестичленный arr совпадает с префиксом arr2,
у которого есть ещё седьмой элемент.

~~~cpp
std::equal(a.begin(), a.end(), b.begin(), b.end());
~~~

Версия с четырьмя границами сравнивает также длины и для этих массивов даёт false.
Её удобно предпочитать, когда известны оба диапазона.
Контейнеры могут быть разными: vector и list сравниваются по значениям.

## Поиск различия

mismatch возвращает пару итераторов на первую несовпавшую позицию.
Для v3/v4 в main это 2 и 3. При одинаковом содержимом возвращаются концы.
При разных длинах один диапазон может закончиться раньше другого:
нельзя разыменовывать оба итератора только потому, что не закончились оба.
В текущем примере длины одинаковы.

Сортировка перед equal меняет смысл проверки: она сравнит наборы
с учётом повторов, а не исходный порядок. Сам equal порядок не меняет.
У трёхитераторной перегрузки вызывающий обязан обеспечить достаточную
длину второго диапазона; иначе возможен выход за границы.
