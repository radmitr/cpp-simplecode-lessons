# 104. Абстрактный класс

C++17. Нужны классы, конструкторы, ссылки и области видимости.

Weapon описывает обязательную операцию:

~~~cpp
virtual void shoot() = 0;
~~~

= 0 делает функцию чисто виртуальной. Сам Weapon создать нельзя,
но Weapon* и Weapon& могут обращаться к объектам Gun, RPG или Knife.
Класс остаётся абстрактным, пока не реализованы все необходимые чисто
виртуальные функции.

## Выполнение примера

Gun, SubmachineGun, RPG и Knife выводят свои варианты shoot().
knife.foo() показывает, что абстрактный класс может иметь обычные готовые методы.
Через Gun* pGun и Player::shoot(Weapon*) выбирается версия SubmachineGun.

Абстрактность не означает отсутствие данных, конструктора или реализации
других методов. Она ограничивает непосредственное создание объектов этого типа.
Указатель в Player должен обозначать живой объект; nullptr здесь не проверяется.

В этом файле Weapon не имеет виртуального деструктора: локальные объекты
уничтожаются корректно, но добавлять delete через Weapon* без изменения
интерфейса нельзя. Безопасный базовый деструктор показан в 105 и 113.
