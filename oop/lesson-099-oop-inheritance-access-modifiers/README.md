## Как это работает

В текущем коде `B` наследует `A` **приватно**:

~~~cpp
class B : private A { /* ... */ };
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Метод `B::printMsg()` может читать `A::msgOne` (`public`) и `A::msgThree` (`protected`).
`A::msgTwo` остаётся закрытым для `B`. Поэтому программа печатает первое и третье
сообщения; второе обращение закомментировано.

### Три формы наследования

- `public`: `public` базы остаётся `public`, `protected` остаётся `protected`.
- `protected`: `public` и `protected` базы становятся `protected` в производном классе.
- `private`: `public` и `protected` базы становятся `private` в производном классе.

Private-члены базы существуют в базовом подобъекте, но производный класс
не получает прямого доступа к ним. Управлять ими можно через доступный интерфейс `A`.

Важное уточнение к комментариям исходника: при фактическом `private A`
обращение из `main` к `b.msgOne` **не разрешено**, несмотря на комментарий OK
рядом с закомментированной строкой. Внутри `printMsg` доступ есть, снаружи — нет.
Также внешнее преобразование `B*` в `A*` при `private`-наследовании недоступно.
У `class` наследование по умолчанию `private`, у `struct` — `public`.
