# 084. Сравнение объектов: == и !=

C++17. Перед изучением нужны классы, конструкторы, ссылки и области видимости.

Point сравнивается по координатам, а не по адресу объекта.
a(5, 1) отличается от b(9, 4), а b и c(9, 4) имеют одинаковые значения.

~~~cpp
return this->x == other.x && this->y == other.y;
~~~

&& требует совпадения обеих координат. Поэтому вывод сравнений:
a == b → 0, a != b → 1, b == c → 1, b != c → 0.
По умолчанию cout печатает bool как 0/1; boolalpha выбирает false/true.

## Как обычно оформляют сравнение

Параметр const Point& избегает копии и запрещает изменение правого аргумента.
Сам метод здесь не const, поэтому сравнить через const левый объект нельзя.
Для сравнения без изменения состояния обычно добавляют const после скобок.
operator!= удобно определять через отрицание ==, чтобы правила не разошлись.

В C++20 можно использовать сравнения = default для подходящих классов.
Это отдельная возможность; текущий C++17-пример реализует оба оператора вручную.
Равенство значений не означает, что объекты занимают одну область памяти.
