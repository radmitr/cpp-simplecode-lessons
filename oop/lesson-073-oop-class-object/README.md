# 073. Класс и объект

## Версия C++

C++98 — классы, объекты и поля. Сборка проекта: **C++17**.

## Что изучаем

Класс описывает тип объекта, а каждый объект содержит собственные поля.

Сначала изучите [устройство программы](../../basics/lesson-002-program-structure/README.md) и [функции](../../basics/lesson-033-functions/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа.

## Как это работает

`Human` имеет публичные `age`, `weight` и `name`. В `main()` создаются два независимых человека. Первый получает `30`, `100` и `Ivanov Ivan Ivanovich`; второй — `19`, `60` и `Noname`. Поля заполняются и выводятся через оператор `.`.

Другой класс `Point` хранит `x`, `y` и `z`. Его объект `a` получает координаты `1, 3, 5`, но они не печатаются. Неинициализированные числовые поля нужно присвоить до чтения, как и обычным локальным переменным.

- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

## Сборка и запуск

[Запуск в VS Code](../../README.md#сборка-и-запуск-в-vs-code) ·
[Команды Windows/Linux из терминала](../../README.md#сборка-из-терминала).

Откройте `main.cpp` этого урока. Ввод не нужен. Выводятся возраст, вес и имя обоих `Human`: `30/100` и `19/60`. Объект `Point` заполняется без вывода.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Считать поля всех объектов общими; ожидать вывода координат, для которых нет инструкции вывода.
