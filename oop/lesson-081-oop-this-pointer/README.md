# 081. Указатель this

## Версия C++

C++98 — указатель this. Сборка проекта: **C++17**.

## Что изучаем

Указатель this обозначает объект, для которого сейчас выполняется метод или конструктор.

Перед примером изучите [классы и объекты](../lesson-073-oop-class-object/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа.

## Как это работает

`Point p1` вызывает конструктор без аргументов и печатает свой адрес с `constructor 1`. `Point p2(11, 22)` записывает координаты и печатает другой адрес с `constructor 2`. В `this->x = x` слева находится поле объекта, справа — одноимённый параметр.

Для каждого объекта значение `this` своё. Конструктор `p1` инициализирует координаты нулями через список `: x(0), y(0)` до входа в своё тело. Так объект сразу содержит определённые значения. Адрес печатается отдельно от координат. Сеттеры и `Print()` определены, но здесь не вызываются.

- Исправлены комментарии о конструкторах и `private`. Конструктор без аргументов инициализирует координаты нулями: это предотвращает чтение неинициализированных полей.
- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

## Типичные ошибки

Считать `this` адресом самого класса как типа; оставлять числовые поля без инициализации в своём конструкторе; ожидать вызова всех методов, которые определены в классе.
