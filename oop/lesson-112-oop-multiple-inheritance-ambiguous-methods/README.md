## Как это работает

И `Car`, и `Airplane` имеют метод `use()`. Вызов `fc.use()` неоднозначен:
компилятор не выбирает случайную базу.

В `main` показаны два разных способа:

~~~cpp
((Car)fc).use();   // Копирует базовую часть в временный Car.
fc.Car::use();     // Вызывает метод на базовой части самого fc.
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Аналогично обрабатывается `Airplane`. Обе пары печатают «Я еду!» и «Я лечу!»,
но при приведении к значению дополнительно появляются деструкторы временных
объектов. Это наблюдаемая цена копирования/срезки.

### Доступ без копии

Явная квалификация `fc.Car::use()` наиболее прямо выражает выбор базы.
Дополнительный вариант — `static_cast<Car&>`(`fc`).`use()`: ссылка тоже не копирует.
C-style cast из текущего примера смешивает несколько видов преобразований,
поэтому для нового кода предпочтительнее именованные приведения.

`using Car::use` внутри `FlyingCar` мог бы выбрать базовое имя для обычного
поиска, а собственный `FlyingCar::use` — определить единое поведение интерфейса.
Квалифицированный вызов виртуального метода также подавляет виртуальный выбор.
