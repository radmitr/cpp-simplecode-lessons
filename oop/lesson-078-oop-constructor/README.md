## Как это работает

`Point(int x, int y)` записывает переданные координаты в поля через `this`. Объекты `a(5, 44)`, `b(77, 9)` и `c(10, 20)` печатают эти пары. `Point d` вызывает пустой конструктор по умолчанию, затем сеттеры записывают `111` и `222` до вызова `Print()`.

Конструктор называется как класс и не имеет указанного возвращаемого типа. Пустой конструктор источника не обнуляет `int`-поля. Поэтому до присваивания обоих полей объект `d` нельзя читать через геттеры или `Print()`.

- Исправлены комментарии о конструкторах и закрытых полях. Пустой конструктор сохранён: оба поля `d` заполняются сеттерами до чтения.
- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

## Типичные ошибки

Считать пустое тело конструктора автоматическим обнулением; вызывать вывод `d` до сеттеров; записывать возвращаемый тип у конструктора.
