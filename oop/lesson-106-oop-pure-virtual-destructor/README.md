## Как это работает

`A` абстрактен благодаря объявлению:

~~~cpp
virtual ~A() = 0;
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

При этом ниже обязательно дано определение `A::~A()`.
Чистота запрещает создание самого `A`, но при разрушении любого `B`
базовая часть `A` всё равно уничтожается, и телу её деструктора нужно существовать.

`main` создаёт `B` через `A*`, затем `delete` даёт последовательность:
конструктор `A` → конструктор `B` → деструктор `B` → деструктор `A`.
Закомментированное `A` a недопустимо из-за абстрактности.

### Отличие от обычной чисто виртуальной функции

Для многих чисто виртуальных операций тело базы необязательно.
У деструктора другая роль: он участвует в обязательной цепочке уничтожения.
Отсутствие определения `A::~A()` обычно проявится ошибкой линковки.

Это способ сделать базу абстрактной без дополнительной искусственной операции.
Если достаточно обычного интерфейса, часто понятнее виртуальный деструктор
= default и содержательные чисто виртуальные методы, как в уроке [«113. Интерфейс через абстрактный класс»](../lesson-113-oop-interfaces/README.md).
