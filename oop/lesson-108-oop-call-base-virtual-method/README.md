## Как это работает

`BracketsMsg` расширяет готовое поведение `Msg::getMsg()`:

~~~cpp
return "[" + Msg::getMsg() + "]";
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

`Printer` получает `Msg*`, виртуальный вызов выбирает `BracketsMsg::getMsg`,
а тот явно обращается к базовой реализации. Итог `main` — [Привет!].

### Почему указан `Msg::`

Вызов просто `getMsg()` внутри `BracketsMsg::getMsg` снова обратился бы
к этой же реализации и вызвал рекурсию. Квалифицированный `Msg::getMsg()`
выбирает именно функцию базы, подавляя виртуальный выбор для этого вызова.
Конструктор `BracketsMsg` также явно передаёт строку базовой части через `Msg(msg)`.

Так можно дополнить проверку, логирование или оформление, сохранив базовую
реализацию. Передача объекта в `Printer` не копирует строку целого объекта:
передаётся указатель. Он должен указывать на живой `Msg`.
Объект в `main` локальный; для владеющего удаления через `Msg*` нужен виртуальный деструктор `~Msg()`.
