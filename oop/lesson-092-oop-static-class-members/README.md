# 092. Статическое поле класса

C++17. Перед изучением нужны классы, конструкторы, ссылки и области видимости.

У каждого `Apple` свои `weight`/color, но `count` — одна переменная на класс.

## Два способа определения

`main.cpp` содержит объявление `static int count` внутри `Apple` и определение
`int Apple::count = 0` снаружи. После создания одного яблока выводится 1.

`main2.cpp` использует C++17:

~~~cpp
inline static int count = 0;
~~~

Сокращённый фрагмент; полный пример: [main2.cpp](main2.cpp).

Определение можно разместить прямо в классе, в том числе в заголовке.
Создаются три яблока, `Apple::count` печатает 3. Обращение `apple.count` тоже
разрешено, но запись через имя класса яснее показывает общее состояние.

## Что именно считает пример

Счётчик увеличивается только в показанном конструкторе и не уменьшается
в деструкторе. Поэтому это не число живых объектов. Неявная копия также
не выполнит этот конструктор. Статическое поле не становится потокобезопасным:
при параллельных изменениях нужны атомик или блокировка.
`inline` здесь решает правило определений, а не обещает оптимизацию доступа.

## Запуск

F5 — запуск с отладчиком; Ctrl+F5 — без отладчика.

Откройте `main.cpp` или `main2.cpp` в VS Code и нажмите F5/Ctrl+F5.
Каждый файл с `main` — самостоятельная программа.
