# 080. Деструктор и выход из блока

## Версия C++

C++98 — деструкторы и освобождение ресурсов. Сборка проекта: **C++17**.

## Что изучаем

Деструктор освобождает ресурс, которым владеет объект.

Перед примером изучите [классы и объекты](../lesson-073-oop-class-object/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа. Взят полный учебный пример указанного исходника.

## Как это работает

Вызов `Foo()` печатает начало, создаёт `MyClass a(10)` и затем печатает конец тела функции. Конструктор выделяет массив через `new int[size]`, заполняет `0–9` и выводит адрес и элементы.

При выходе из `Foo()` локальный `a` уничтожается: выполняется `~MyClass()`. Он печатает адрес и освобождает массив через `delete[]`. Поэтому сообщение деструктора идёт после надписи «КОНЕЦ ВЫПОЛНЕНИЯ», хотя оно всё ещё относится к завершению вызова `Foo()`.

Этот класс вручную владеет указателем. Неявное копирование создало бы два объекта с одним адресом и привело бы к повторному удалению. В текущем примере копий нет; продолжение — [«Конструктор копирования»](../lesson-082-oop-copy-constructor/README.md). При отказе `new` исключение здесь не перехватывается.

## Типичные ошибки

Думать, что ресурс освобождается при последнем использовании объекта, а не в конце области; копировать этот владеющий объект без корректных специальных методов.
