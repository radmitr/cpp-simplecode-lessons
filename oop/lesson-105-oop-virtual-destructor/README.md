## Как это работает

`main` создаёт `B` динамически, но хранит его адрес как `A*`:

~~~cpp
A* bptr = new B();
delete bptr;
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

`virtual` ~`A()` позволяет `delete` выбрать полное уничтожение `B`.
Сначала печатаются конструкторы `A`, `B`; при `delete` — деструкторы `B`, `A`.
Словесные сообщения о памяти иллюстрируют этапы: дополнительных буферов
внутри `A` и `B` этот пример не выделяет.

### Что будет без `virtual`

Удаление `B` через `A*` без подходящего виртуального деструктора здесь было бы
неопределённым поведением. Нельзя описывать его как гарантированный вызов
только ~`A`: стандарт не обещает корректного результата вообще.

~`B() override` подтверждает переопределение виртуального деструктора.
Для базового интерфейса обычная форма — `virtual` ~`A()` = default.
В практическом коде владеющий указатель часто заменяют `unique_ptr<A>`,
но ему также нужен корректный механизм удаления через базовый тип.
