## Как это работает

`TestClass` содержит пять `int`: 5, 44, 4, 987, 69.
`operator[]` возвращает **ссылку на элемент**, поэтому доступ работает
и для чтения, и для присваивания.

~~~cpp
int& operator[](size_t index) {
    return arr[index];
}
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Сначала `a[1]` печатает 44. Запись `a[1] = 100` изменяет сам arr[1],
а следующий вывод даёт 100. При возврате `int` по значению такое присваивание
элементу через обычный возвращённый `int` было бы невозможно.

### Границы и `const`

Допустимые индексы — 0…4. Проверки в этой реализации нет: выход за границы
даёт неопределённое поведение, а не гарантированное исключение.
Для безопасного интерфейса добавляют отдельную проверяемую операцию
или используют `std::array::at()`.

Для чтения `const` объекта нужна также `const`-перегрузка, обычно возвращающая
`const int&`. Полученная ссылка действительна только пока живёт содержащий массив
объект. `size_t` — беззнаковый тип размера; переносимое имя `std::size_t`
объявлено в `cstddef`.
