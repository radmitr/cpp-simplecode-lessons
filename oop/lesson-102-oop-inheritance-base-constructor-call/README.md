# 102. Выбор конструктора базового класса

C++17. Нужны классы, конструкторы, ссылки и области видимости.

B выбирает конкретную перегрузку конструктора A через список инициализации:

~~~cpp
B() : A("Конструктор класса A", 100) {}
~~~

До входа в пустое тело B() базовая часть A уже получила сообщение и число.
Первый объект a в main выводит «Класс A наше сообщение», второй b —
«Конструктор класса A» через унаследованный printMsg().

Запись A(...) внутри тела B() создала бы отдельный временный объект,
а не переинициализировала базовую часть. Поэтому аргументы базы указывают
после двоеточия.

## Поля и порядок

У A есть перегрузки без числа, где int value не инициализирован.
Текущий main его не читает, но добавлять такое чтение до присваивания нельзя.
Обычный способ избежать этого — начальное значение поля или его инициализатор.

Базы и поля создаются в порядке, заданном определением класса, а не порядком
перечисления в списке инициализации. Сам список выбирает значения, но не
переставляет этапы создания.
