# 111. Порядок деструкторов нескольких баз

C++17. Нужны классы, конструкторы, ссылки и области видимости.

После создания `Car` → `Airplane` → `FlyingCar` локальный `fc` выходит
из области видимости. Сообщения разрушения идут в порядке:

~~~text
FlyingCar
Airplane
Car
~~~

Сначала выполняется тело деструктора самого производного класса,
потом уничтожаются его поля и базы. Для обычных прямых баз это обратный
порядок их создания.

## Что здесь не проверяется

`main` не вызывает `driveAndFly` и не удаляет объект через указатель на базу.
Поэтому пример показывает именно порядок локального уничтожения.
Виртуальность деструктора требуется отдельно при полиморфном `delete`;
множественное наследование само по себе её не добавляет.

Не следует вручную вызывать деструкторы `Car` и `Airplane` из ~`FlyingCar`:
цепочка выполняется автоматически, повторное уничтожение было бы ошибкой.
