# 03. Явный параметр объекта

## Версия C++

Режим сборки — **C++23**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках.

## Что изучаем

Один метод обслуживает изменяемые, константные и временные объекты. Нужны ссылки, шаблоны и категории значений.

## Примеры

- [main.cpp](main.cpp) — типы результата для трёх категорий объекта; вывод `9`.
- [main2.cpp](main2.cpp) — рекурсивная лямбда; вывод `120`.

## Как это работает

Параметр `this Self&& self` обозначает объект вызова явно. Компилятор выводит `Self`, включая `const` и ссылочность. `std::forward` сохраняет категорию объекта, а скобки в `decltype(auto)` сохраняют ссылку на поле. Метод вызывается привычно через точку. В отдельном примере лямбда получает собственный объект и рекурсивно вызывает себя без `std::function`.

## Типичные ошибки

У такого метода нет неявного `this`: используйте `self`. Метод нельзя одновременно сделать `static` или `virtual`; после списка параметров не добавляются обычные квалификаторы метода `const`/`&`. Ссылка на поле временного объекта не продлевает жизнь этого объекта.
