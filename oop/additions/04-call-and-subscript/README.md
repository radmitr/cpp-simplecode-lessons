# 04. Многомерный индекс и статические операторы

## Версия C++

Режим сборки — **C++23**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках.

## Что изучаем

Задаём доступ к матрице через два индекса и вызываемый объект без состояния. Нужны классы и перегрузка операторов.

## Примеры

- [main.cpp](main.cpp) — запись, чтение и проверяемый неверный индекс; вывод `7`.

## Как это работает

`matrix[row, column]` передаёт два аргумента одной перегрузке `operator[]`. Неконстантная перегрузка возвращает изменяемую ссылку, константная — `const int&` для чтения. В примере проверка границ предшествует вычислению адреса. Статические `operator()` и `operator[]` не получают объект через `this` и подходят для операций без состояния. Статическая лямбда тоже не имеет захватов. Она не даёт доступа к внешней локальной переменной.

## Типичные ошибки

Многомерный индекс не равен цепочке `matrix[row][column]`: у неё два отдельных вызова. Сырые массивы не приобретают многомерную перегрузку. Проверяйте границы; не объявляйте статический оператор для доступа к нестатическому полю.
