## Как это работает

`Apple::getCount()` читает общий `count` без конкретного яблока.
У `static`-метода нет указателя `this`, поэтому он не может выбрать, чей color
изменять, пока объект не передан явно.

~~~cpp
Apple::changeColor(apple, "Black");
apple.changeColorNonStatic("Yellow-Red");
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Первый метод получает `Apple&` отдельным параметром. Второй вызывается
на объекте и обращается к нему через `this`. Оба меняют одно исходное яблоко.

### Результат и выбор интерфейса

Сначала печатаются `id` 1, 2, 3 и общий `count` 3. Затем данные первого яблока
с цветом Black и после второго изменения — Yellow-Red.
Вес остаётся 125.

`static`-метод остаётся членом класса и имеет доступ к его `private`-полям.
`static` не означает «один вызов за программу» и не даёт синхронизации.
Для обычного изменения конкретного объекта нестатический метод часто проще;
`static` подходит для общей операции, фабрики или данных уровня класса.
