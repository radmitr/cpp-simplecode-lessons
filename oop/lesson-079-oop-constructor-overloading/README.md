# 079. Перегрузка конструкторов

Перегрузки конструктора выбираются по списку аргументов создания объекта.

Перед примером изучите [классы и объекты](../lesson-073-oop-class-object/README.md).

## Как это работает

`Point()` задаёт `x = 0` и `y = 0`. `Point(int, int)` принимает обе координаты напрямую. `Point(int, bool)` задаёт `x` аргументом и выбирает `y = 1` либо `-1` по логическому значению.

Поэтому `Point a` даёт `0/0`, `Point b(77, 9)` — `77/9`, а `Point c(22, false)` — `22/-1`. Для второго аргумента `9` точнее подходит `int`, для `false` — `bool`; выбираются разные перегрузки.

## Типичные ошибки

Путать `false` с целым аргументом `0` при выборе перегрузки; считать, что все конструкторы вызываются подряд для одного объекта.
