# 086. Префиксный и постфиксный ++

C++17. Перед изучением нужны классы, конструкторы, ссылки и области видимости.

В `Point` увеличение означает прибавление единицы к обеим координатам.

~~~cpp
Point& operator++();    // ++a
Point operator++(int);  // a++
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Пустая версия сначала меняет объект и возвращает ссылку на него.
Фиктивный параметр `int` отличает постфиксную перегрузку: явно передавать его
при записи `a`++ не надо. Постфиксная версия запоминает старую копию,
увеличивает исходный объект и возвращает прежнее значение.

## Ход `main.cpp`

Начальное `a` равно (5, 1). После `Point b` = ++`a` оба имеют (6, 2).
После `b = a`++ значение `a` — (7, 3), а `b` получает прежнее (6, 2).
`b` остаётся самостоятельным объектом, несмотря на ссылочный результат ++`a`:
его объявление `Point b` создаёт значение, не ссылку.

Если прежнее значение не требуется, обычно пишут ++`a`. Для сложных типов
постфиксный вариант может потребовать копию; для `int` выбор редко заметен.
Пример с `operator--` находится в [бонусе о декременте](../bonus/01-decrement-operators/README.md).
Не смешивайте
несколько изменений одной переменной в выражении без ясного порядка вычисления.
