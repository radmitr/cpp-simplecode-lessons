## Как это работает

`Pixel` arr[5] создаёт пять объектов с конструктором по умолчанию.
Он обнуляет RGB. Затем arr[0] = `Pixel(111, 11, 17)` присваивает значение
уже существующему первому элементу.

Динамический `new Pixel[5]` также создаёт пять `Pixel`, а `delete[] arr2`
вызывает их деструкторы и освобождает память.
Печатаются первый статический пиксель 111/11/17 и динамический 222/22/27.

### Инициализация и присваивание

~~~cpp
Pixel arr[5];                   // Конструирование элементов.
arr[0] = Pixel(111, 11, 17);     // Присваивание существующему элементу.
Pixel p3 = {25, 127, 229};       // Инициализация через конструктор.
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Если нет подходящего конструктора по умолчанию, пустая инициализация массива
таким способом не сработает. Форма `new[]` должна соответствовать `delete[]`.
После удаления обращаться к `arr2` нельзя.

Для фиксированного размера обычно удобен `std::array`, для динамического —
`std::vector`: они связывают время жизни элементов со временем жизни контейнера.
Сырой указатель сам размер выделенного массива не хранит.
