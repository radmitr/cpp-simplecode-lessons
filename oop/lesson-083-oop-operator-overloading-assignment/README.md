## Как это работает

`MyClass` хранит динамический массив. Все три объекта уже созданы, когда
выполняется `c = a = b`. Здесь работает `operator=`, а не конструктор копирования.

~~~cpp
MyClass& operator=(const MyClass& other);
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Правая операция `a = b` выполняется первой: сначала выделяется и заполняется
копия массива `b`, затем прежний массив `a` заменяется новой копией.
`return *this` возвращает ссылку на `a`,
поэтому `c = a` копирует тот же набор значений. После цепочки размеры `a` и `c`
равны размеру `b`, то есть 2. Деструкторы освобождают каждый свой массив.

### Почему возвращается ссылка

`*this` — сам объект, на котором вызван метод; `this` — указатель на него.
Возврат `MyClass&` поддерживает цепочки и не создаёт лишний объект.
`const MyClass& other` даёт доступ к источнику без его копирования.

### Самоприсваивание и ошибка выделения памяти

Проверка `this == &other` распознаёт `a = a`: источник и получатель —
один объект. Метод сразу возвращает его, сохраняя массив.
Для разных объектов сначала создаётся `newData`. Если `new[]` выбросит
исключение, старый массив ещё существует и объект остаётся прежним.
Копирование элементов `int` не выбрасывает исключений; после него можно
удалить старый массив и записать новые указатель и размер.
Эти исправления добавлены к исходной учебной реализации.

Другой способ — `copy-and-swap`. Для класса с `std::vector` ресурсами управляют
его специальные функции: это правило нуля.
[Гарантии исключений](../../exceptions/bonus/15-exception-guarantees/README.md).
