# 083. Копирующее присваивание

C++17. Перед изучением нужны классы, конструкторы, ссылки и области видимости.

MyClass хранит динамический массив. Все три объекта уже созданы, когда
выполняется c = a = b. Здесь работает operator=, а не конструктор копирования.

~~~cpp
MyClass& operator=(const MyClass& other);
~~~

Правая операция a = b выполняется первой: прежний массив a удаляется,
затем выделяется копия массива b. return *this возвращает ссылку на a,
поэтому c = a копирует тот же набор значений. После цепочки размеры a и c
равны размеру b, то есть 2. Деструкторы освобождают каждый свой массив.

## Почему возвращается ссылка

*this — сам объект, на котором вызван метод; this — указатель на него.
Возврат MyClass& поддерживает цепочки и не создаёт лишний объект.
const MyClass& other даёт доступ к источнику без его копирования.

## Важные ограничения текущей реализации

Здесь нет защиты от a = a: после удаления и нового выделения источник
совпадает с получателем, и читаются ещё неинициализированные элементы.
Также старый массив удаляется до успешного new: исключение при выделении
памяти может оставить висячий указатель для деструктора. Это учебная схема,
а не готовый безопасный контейнер.

Обычные решения — сначала подготовить новый ресурс и только затем заменить
старый либо применить copy-and-swap. Для класса с vector ресурсами управляют
его специальные функции: это правило нуля.
