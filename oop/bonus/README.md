# Бонусы по ООП

Нужны [классы, конструкторы, связи объектов и перегрузка операторов](../README.md). Сначала разберите владение компонентом, затем операторы и современные способы описания интерфейса.

Номера папок задают порядок изучения внутри раздела. Уроки SimpleCode сохраняют исходную нумерацию.

## Уроки

- [01. Композиция и невладеющая связь](01-composition-aggregation/README.md) — `c++17`.
- [02. Префиксный и постфиксный `operator--`](02-decrement-operators/README.md) — `c++17`.
- [03. Явный параметр объекта](03-explicit-object/README.md) — `c++23`.
- [04. Многомерный индекс и статические операторы](04-call-and-subscript/README.md) — `c++23`.

## Как работать

Откройте корень проекта или папку урока и выберите нужный исходник.
[F5, Ctrl+F5 и команды терминала](../../README.md#сборка-и-запуск-в-vs-code).
В каждом README указаны ввод, результат, ошибки, зависимости и ограничения.
В списке выше дан **режим сборки**; даты появления отдельных возможностей объясняются в уроках.
