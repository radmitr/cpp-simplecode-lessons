# Бонусы по ООП

Дополнительные примеры вне курса SimpleCode. Номера исходных уроков не меняются.

1. [Декремент: префикс и постфикс](01-decrement-operators/README.md) —
   после урока [«086. Префиксный и постфиксный ++»](../lesson-086-oop-operator-overloading-increment-decrement/README.md); ссылка на изменённый объект и копия старого значения.
2. [Композиция и агрегация](02-composition-aggregation/README.md) —
   после урока [«097. Композиция и агрегация»](../lesson-097-oop-aggregation-composition/README.md); собственный компонент и ссылка на внешний объект.

Первые два бонуса используют C++17; новые операторы и явный объект — C++23. В каждой папке есть `main.cpp`, README и
настройки VS Code для Windows/Linux. Откройте корень проекта или папку бонуса:
**F5** запускает с отладчиком, **Ctrl+F5** — без отладчика.
Команды терминала и ожидаемый вывод приведены в README каждого бонуса.
