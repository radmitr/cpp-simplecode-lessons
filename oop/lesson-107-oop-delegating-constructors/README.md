## Как это работает

Перегрузки `Human` вызывают друг друга, чтобы не повторять общую инициализацию.

~~~cpp
Human(string Name, int Age) : Human(Name)
{
    this->Age = Age;
    cout << "Обновлён возраст: " << Age << endl;
}
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

При трёх аргументах сначала выполняется версия с одним аргументом,
потом тело двухаргументной, затем тело трёхаргументной.
Всё это создаёт один объект, а не три отдельных человека.

### Результаты `main.cpp`

Первый человек получает имя «Аристарх!» и возраст/вес 0.
Второй — то же имя, возраст 33 и вес 0. Третий — возраст 41 и вес 65.
Промежуточные сообщения показывают, когда меняется каждое поле.

В строках конструктора имя параметра Name скрывает поле; `this->Name`
обращается к полю, которому добавляется !. Поэтому диагностическая печать
параметра и последующий `printInfo` могут показывать немного разный текст.

Делегирование указывают в списке инициализации. Вызов `Human(...)` в теле
создал бы временный объект. Циклическая цепочка делегирования недопустима;
делегирующий список инициализации не дополняют инициализацией других полей.
