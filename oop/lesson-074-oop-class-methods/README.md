# 074. Методы класса

## Версия C++

C++98 — методы класса. Сборка проекта: **C++17**.

## Что изучаем

Метод класса выполняет действие с полями конкретного объекта.

Перед примером изучите [классы и объекты](../lesson-073-oop-class-object/README.md).

## Примеры

[main.cpp](main.cpp) — самостоятельная программа.

## Как это работает

`Human::Print()` выводит `name`, `weight` и `age`. Первый объект хранит `Иванов Иван`, `100` и `30`, второй — `Петр Петров`, `60` и `19`. Вызов `firstHuman.Print()` работает с первым объектом, `secondHuman.Print()` — со вторым.

Внутри нестатического метода обращения к полям без имени объекта относятся к текущему объекту. Сам метод определяется один раз, а наборы данных у экземпляров разные.

- `console::setupConsoleEncoding()` настраивает UTF-8 в Windows-консоли и не выполняет дополнительных действий на Linux.

## Сборка и запуск

[Запуск в VS Code](../../README.md#сборка-и-запуск-в-vs-code) ·
[Команды Windows/Linux из терминала](../../README.md#сборка-из-терминала).

Откройте `main.cpp` этого урока. Ввод не нужен. Две записи с именем, весом и возрастом; сначала Иванов, затем Петров.

При успешном завершении код возврата `0`. Внешние файлы и службы не нужны; программа не создаёт пользовательских файлов.

## Типичные ошибки

Вызывать метод до заполнения читаемых полей; считать, что метод без параметров не может использовать данные объекта.
