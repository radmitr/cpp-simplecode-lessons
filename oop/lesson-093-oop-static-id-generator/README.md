## Как это работает

Общий `count` увеличивается при обычном создании `Apple`, а полученное значение
копируется в нестатическое поле `id` конкретного объекта.

~~~cpp
++count;
id = count;
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Три создаваемых яблока получают `id` 1, 2, 3. Изменение общего счётчика
не меняет `id` уже созданного яблока: у него хранится собственный `int`.

### Границы примера

Это идентификаторы в пределах одного запуска и показанного пути создания.
При перезапуске `count` снова начинается с нуля.
Неявный конструктор копирования скопирует `id`, поэтому гарантии уникальности
для всех возможных объектов здесь нет.

В многопоточном приложении `++count` без синхронизации даёт гонку.
Для длительно работающего генератора учитывают также диапазон и переполнение.
Идентификатор объекта, число созданий и число живых объектов — разные величины;
не стоит использовать один счётчик сразу для всех этих задач.
