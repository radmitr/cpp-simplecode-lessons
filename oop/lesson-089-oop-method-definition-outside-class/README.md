# 089. Определение метода вне класса

C++17. Перед изучением нужны классы, конструкторы, ссылки и области видимости.

Внутри `MyClass` объявлены конструктор, деструктор и `printMessages`.
Их определения расположены ниже класса:

~~~cpp
void MyClass::printMessages() {
    std::cout << "Hello!" << std::endl;
}
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

`MyClass`:: показывает принадлежность функции классу. При определении снаружи
метод сохраняет доступ к `private`-членам и указатель `this`.
В `main` создаётся `a`, затем `a.printMessages()` печатает Hello!.

Объявление описывает интерфейс, определение содержит тело. Оба должны совпадать
по типам параметров и квалификаторам, например `const`.
У конструкторов/деструкторов нет возвращаемого типа.
Если объявить метод, вызвать его и не дать определения, обычно возникает
ошибка линковки.

В многофайловом проекте объявление класса часто помещают в заголовок, а тела
обычных методов — в .cpp. Простое вынесение определения ниже в том же файле
само по себе не меняет время выполнения или число объектов.

## Запуск

F5 — запуск с отладчиком; Ctrl+F5 — без отладчика.

Откройте `main.cpp` в VS Code и нажмите F5/Ctrl+F5.
Каждый файл с `main` — самостоятельная программа.
