# 088. Дружественная свободная функция

C++17. Перед изучением нужны классы, конструкторы, ссылки и области видимости.

changeX получает Point& и Test& и изменяет private-поля обоих классов.
Каждый класс отдельно объявляет эту функцию другом:

~~~cpp
friend void changeX(Point& value, Test& testValue);
~~~

friend не превращает функцию в метод. Вызов — changeX(a, b), у функции нет this.
Доступ разрешён именно потому, что оба владельца закрытых полей его предоставили.
Предварительное class Test позволяет упомянуть тип до его полного определения.

## Результат

До вызова у a координаты (5, 12), у b data = 0.
После вызова x становится -1, y остаётся 12, data становится -10.
Ссылочные параметры изменяют исходные объекты; копии здесь не создаются.

Дружба не симметрична, не транзитивна и автоматически не наследуется.
friend удобно использовать для тесно связанных операций, включая потоковые
операторы, но открывать доступ всем функциям для обычного изменения одного
свойства часто менее понятно, чем явно назвать публичный метод.
