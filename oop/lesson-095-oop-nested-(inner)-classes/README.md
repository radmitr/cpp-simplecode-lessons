# 095. Вложенный класс

## Версия C++

`std::to_string`, lambda — **C++11**.
`std::string`, `std::size_t` — **C++98**.

Сборка примеров: **C++17**. Режим сборки и дата появления возможностей различаются.

## Что изучаем

Перед изучением нужны классы, конструкторы, ссылки и области видимости.

## Примеры

Полные исходники дополнительных вариантов:

- [main2.cpp](main2.cpp).

- `main.cpp`: `Pixel` объявлен в `private`. `Image` хранит пять пикселей по значению
  и `getImageInfo()` выводит строки #0…#4 с их компонентами RGB.
- `main2.cpp`: `Pixel` объявлен в `public`. В `main` можно создать
  `Image::Pixel pixel(25, 127, 229)`; вывод показывает эти три значения.

`Image::Pixel` обозначает тип, а `img` — конкретный экземпляр `Image`.
Для создания `public Pixel` экземпляр `Image` не требуется.
Сами RGB-поля `Pixel` закрыты; `Image` пользуется его публичным `getInfo()`.

## Как это работает

`Image::Pixel` — тип, объявленный внутри `Image`.
Вложенность задаёт область имени, но не создаёт автоматически ссылку
на окружающий объект `Image`.

## Типичные ошибки

Private-вложенный тип позволяет скрыть детали реализации. Public-вложенный
тип выражает связь имён в интерфейсе. Вложенный класс имеет права доступа
к членам внешнего класса, но для его нестатических полей всё равно нужен
конкретный внешний объект. Внешний класс не получает автоматически доступа
ко всем `private`-полям вложенного.
