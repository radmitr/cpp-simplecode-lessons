## Как это работает

`Student` и `Professor` публично наследуют `Human`. У них есть базовая часть
с name и публичные `getName`/`setName`, а также собственные group или subject.
`ExtramuralStudent` наследует `Student` и получает ту же цепочку `Human`.

### Выполнение

`main` создаёт отдельные `Human`, `Student`, `Professor` и `ExtramuralStudent`,
задаёт имена через `setName` и выводит их. У `Student` вызывается `learn()`,
у `ExtramuralStudent` — его собственный `learn()` с другим сообщением.
Закрытое поле `Human::name` недоступно напрямую, но методы `Human` им управляют.

~~~cpp
class Student : public Human { /* дополнительные члены */ };
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

`public`-наследование разрешает использовать `Student` через `Human&` или `Human*`.
При передаче `Student` в `Human` **по значению** производная часть будет срезана.

### Наследование ещё не означает виртуальный вызов

`learn()` здесь не `virtual`. Совпадающее имя в `ExtramuralStudent` скрывает метод
`Student`, но выбор при обращении через `Student&` определяется статическим типом.
Для динамического выбора нужен `virtual`, показанный в уроке [«103. Виртуальные методы и `override`»](../lesson-103-oop-virtual-methods-virtual-override-keywords/README.md).
При полиморфном удалении через базовый указатель нужен виртуальный деструктор.
