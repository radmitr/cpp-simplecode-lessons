## Как это работает

`operator+` создаёт `Point` из суммы соответствующих координат:

~~~cpp
Point c = a + b;
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Вызов соответствует `a.operator`+(`b`). Из `a(5, 1)` и `b(9, 4)` получается `c(14, 5)`.
Внутри создаётся `temp`, вычисляются его `x`/`y` и возвращается значение.
Исходные `a` и `b` не изменяются; `temp` не возвращается по ссылке.

### Почему результат возвращается по значению

Локальный `temp` уничтожается после выхода из функции. Возвращённая ссылка
на него стала бы висячей. Возврат значения позволяет получить самостоятельный `c`;
компилятор может исключить промежуточное копирование.

Метод здесь не `const`, хотя не меняет `a`; в обычном интерфейсе такой `operator+`
делают `const`. Оператор += имеет другой смысл: меняет левый объект и обычно
возвращает ссылку на него. Перегрузка не меняет приоритет или число операндов +.
Сообщения с адресами конструкторов могут различаться из-за оптимизации копий.
