## Как это работает

`C` создаётся по цепочке `A` → `B` → `C`. При выходе из `main` объект разбирается
в обратном порядке: сначала тело ~`C`, затем ~`B`, затем ~`A`.

Это позволяет производному классу при своём уничтожении ещё обращаться
к живой базовой части. После тела деструктора уничтожаются поля класса
в обратном порядке их объявления, затем его обычные базы.

### Почему здесь не нужен `virtual` для правильного порядка

Локальная переменная объявлена как `C c`, и уничтожается именно `C`.
Виртуальный деструктор нужен для другого сценария — удаления производного
объекта через указатель на базу. Этот случай рассматривается в уроке [«105. Виртуальный деструктор»](../lesson-105-oop-virtual-destructor/README.md).

Деструктор не вызывают вручную перед обычным выходом из области видимости:
повторное автоматическое уничтожение нарушило бы время жизни объекта.
В редких сценариях ручного размещения объектов управление временем жизни
явное, но обычным локальным переменным это не требуется.
