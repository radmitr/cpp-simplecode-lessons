## Как это работает

Для `FlyingCar` : `public Car`, `public Airplane` сначала создаётся `Car`,
затем `Airplane`, затем выполняется тело конструктора `FlyingCar`.
После этого `main` вызывает методы обеих уже готовых базовых частей.

Порядок определяется списком баз в **объявлении класса**.
Даже если записать их инициализаторы в конструкторе в обратном порядке,
`Car` всё равно будет создан первым; компилятор может предупредить о расхождении.

Общая последовательность создания сложного объекта:
виртуальные базы → обычные прямые базы → поля по порядку объявления →
тело конструктора. В этом уроке виртуальных баз нет.

Если конструктор второй базы выбросит исключение, первая успешно созданная
база будет уничтожена. Деструктор всего `FlyingCar` при неудавшемся создании
не вызывается. Не используйте поля или базы до завершения их инициализации.
