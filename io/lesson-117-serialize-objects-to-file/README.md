# Урок 117. Бинарная запись представления объекта

## Версия C++

`std::string` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Предварительно: Уроки [«115. Запись в файл: `ofstream`»](../lesson-115-file-output-ofstream/README.md) — [«116. Чтение из файла: `ifstream`»](../lesson-116-file-input-ifstream/README.md), классы, sizeof и представление данных.

## Примеры

- [main.cpp](main.cpp): Дописывает представление `Point` в `point.dat` и читает записи блоками `sizeof(Point)`.

Каждый `main*.cpp` — отдельная программа.

## Как это работает

`write` получает адрес начала области байтов и число `sizeof(Point)`.
`reinterpret_cast` меняет представление указателя для интерфейса потока,
но не строит переносимый сериализатор полей.

read запрашивает полный такой же блок. В цикле печатаются только полностью
полученные объекты. Если файл заканчивается частью записи, read завершится
неуспешно; текущий код не различает это с обычным окончанием списка записей.

Повторный запуск с app добавляет ещё один `Point`, поэтому число строк чтения
может увеличиваться. `point.dat` — создаваемые данные, а не C++-исходник.

Даже для trivially-copyable объекта совместимость требует согласованного
представления и формата. Для долговременного файла задайте заголовок/версию,
длины, размеры полей и порядок байтов явно:
[бинарный формат](../bonus/02-portable-binary/README.md).

## Сборка и запуск

[Запуск в VS Code](../../README.md#сборка-и-запуск-в-vs-code).

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5/Ctrl+F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "io/lesson-117-serialize-objects-to-file/main.cpp"
```

На Linux используйте `scripts/build-linux.sh` с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Каждый запуск добавляет `Point(487, 212, 946)`, затем печатает все полные записи `point.dat`.

## Типичные ошибки

Этот `Point` состоит из `int` и допускает копирование представления, но формат зависит от размеров `int`, padding и порядка байтов. Нельзя обобщать запись `sizeof(object)` на объекты со `string`, указателями или виртуальными функциями. Неполный последний блок здесь не диагностируется отдельно. Для явного формата см. [Явный бинарный формат вместо записи объекта целиком](../bonus/02-portable-binary/README.md).
