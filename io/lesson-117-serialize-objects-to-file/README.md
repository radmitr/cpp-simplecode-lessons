# Урок 117. Бинарная запись представления объекта

Предварительно: Уроки 115–116, классы, sizeof и представление данных.

## Примеры

- [main.cpp](main.cpp): Дописывает представление Point в point.dat и читает записи блоками sizeof(Point).

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "io/lesson-117-serialize-objects-to-file/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Каждый запуск добавляет Point(487, 212, 946), затем печатает все полные записи point.dat.

## Что важно понять

Этот Point состоит из int и допускает копирование представления, но формат зависит от размеров int, padding и порядка байтов. Нельзя обобщать запись sizeof(object) на объекты со string, указателями или виртуальными функциями. Неполный последний блок здесь не диагностируется отдельно. Для явного формата см. бонус 02-portable-binary.
