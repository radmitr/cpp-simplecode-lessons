# 04. Строгое преобразование чисел

## Версия C++

`std::string_view`, `std::from_chars`, `std::to_chars`, структурированные привязки — **C++17**.
`std::array`, `auto` — **C++11**.
`std::exception`, `std::invalid_argument`, `std::size_t` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

`from_chars` не пропускает начальные пробелы и не выбрасывает исключения:
он возвращает позицию и код ошибки. Успешный префикс 123 в строке 123abc ещё
не означает корректность всей строки. Интерфейс обёртки здесь переводит ошибки
в `invalid_argument`. `to_chars` записывает диапазон без обязательного завершающего
нуля. Пример использует целые числа; поддержку и особенности floating-point
перегрузок проверяйте отдельно для конкретной библиотеки.

## Как это работает

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Каждый исходник здесь — самостоятельный исполняемый пример.

`parse_integer` принимает 123 и -7, но отклоняет пустую строку, 123abc,
слишком большое число и начальный пробел перед 12.
Проверка error == `std::errc`{} сама по себе недостаточна:

~~~cpp
error == std::errc{} && end == text.data() + text.size()
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Первое условие проверяет преобразование, второе — что не осталось хвоста.
Для целочисленного `from_chars` начальный + и пробелы автоматически не пропускаются.
Недостаток цифр и выход за диапазон отражаются разными errc.

`to_chars` получает готовый буфер и возвращает конец записанного диапазона.
Код выводит `string_view` с точной длиной и получает 123.
Не передавайте буфер как нуль-терминированную строку без явного завершающего нуля.
Обе функции независимы от локали, что удобно для протокола и машинного формата.

### Результат и проверка

После показанных в коде значений последняя строка — `OK 04-charconv`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section io/bonus`
(на Linux команда Python обычно называется python3).
