# 05. Форматирование и состояние потока

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Стандарт и компилятор: c++17. Каждый исходник здесь — самостоятельный исполняемый пример.

## Что показывает пример

fixed и setprecision управляют представлением числа, setw обычно
действует только на следующее форматируемое поле, setfill сохраняется.
Пользовательская функция не должна незаметно оставлять чужому потоку другие
flags/precision/fill. quoted экранирует кавычки для своего формата, но не
заменяет правила CSV или JSON. Для стабильных машинных данных задавайте
locale::classic и формат явно.

## Разбор кода и полезные варианты

fixed с setprecision(2) печатает 1.25 с двумя знаками после точки.
setw(4) и setfill('0') оформляют 7 как 0007; итог: 1.25 0007.

Ширина setw обычно относится только к следующему полю.
flags, precision и fill сохраняются в потоке дольше, поэтому функция
форматирования должна вернуть чужому потоку прежние настройки.

~~~cpp
const auto flags = out.flags();
// Изменение оформления...
out.flags(flags);
~~~

Одних flags недостаточно для восстановления precision/fill: пример сохраняет
их отдельно. При exceptions для автоматического восстановления используют
RAII-охранник. quoted записывает пробелы и кавычки в собственном формате
потокового обмена; он не является кодировщиком JSON или универсального CSV.

## Запуск

Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh io/bonus/05-iomanip/main.cpp
./build/io/bonus/05-iomanip/main
```

На Windows / MSYS2 Bash используйте scripts/build-windows.sh и расширение .exe.
В VS Code открывайте main.cpp и нажимайте F5: доступны корневая и локальная конфигурации.
Рабочая папка F5 — папка исходника. Особенности компилятора и зависимостей
описаны в [README раздела](../README.md).

## Результат и проверка

После показанных в коде значений последняя строка — `OK 05-iomanip`.
Проверки check(...) выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с NDEBUG.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section io/bonus`
(на Linux команда Python обычно называется python3).
