# 13. UTF-8, BOM, переводы строк и char8_t

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Стандарт и компилятор: `c++20`. Каждый исходник здесь — самостоятельный исполняемый пример.

## Что показывает пример

u8-литерал C++20 имеет элементы char8_t. Просмотр его представления
через `const char*` позволяет передать UTF-8-байты byte-oriented API, но сам
char8_t не делает произвольные данные корректным Unicode. Проверка отвергает
обрезанные/избыточные последовательности, суррогаты и значения вне диапазона.
Валидность UTF-8 не означает нормализацию, регистронезависимость или число
видимых символов: это отдельные задачи Unicode-библиотеки. BOM удаляется
только в начале; CRLF преобразуется явно, одиночный CR здесь сохраняется.

## Разбор кода и полезные варианты

u8"ёж" в C++20 имеет элементы char8_t. Полученный диапазон содержит
четыре UTF-8-байта, хотя видимых букв две. Копирование байтов в `std::string`
не является перекодированием: данные остаются UTF-8.

`valid_utf8` распознаёт длины последовательностей, проверяет продолжения,
минимальный код, отсутствие surrogate и верхнюю границу Unicode.
В `main` отклоняются overlong, surrogate, код выше U+10FFFF и оборванный символ.

Для известного входа с BOM первые три байта снимаются вручную.
Затем CR перед LF пропускается: line1\r\nline2\n превращается в LF-строки.
Произвольный CR без LF этот алгоритм сохраняет.

Проверка валидности UTF-8 не выполняет нормализацию Unicode, подсчёт графем,
языковую сортировку или преобразование регистра.
BOM нельзя удалять без проверки у любого файла. Кодировка имени файла,
содержимого и терминала — три самостоятельные настройки.

## Запуск

Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh io/bonus/13-utf8/main.cpp
./build/io/bonus/13-utf8/main
```

На Windows / MSYS2 Bash используйте `scripts/build-windows.sh` и расширение .exe.
F5 — запуск с отладчиком; Ctrl+F5 — без отладчика.

В VS Code открывайте `main.cpp` и нажимайте F5/Ctrl+F5: доступны корневая и локальная конфигурации.
Рабочая папка при F5/Ctrl+F5 — папка исходника. Особенности компилятора и зависимостей
описаны в [README раздела](../README.md).

## Результат и проверка

После показанных в коде значений последняя строка — `OK 13-utf8`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section io/bonus`
(на Linux команда Python обычно называется python3).
