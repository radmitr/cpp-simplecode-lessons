# 14. CSV с кавычками и многострочными полями

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Стандарт и компилятор: c++17. Каждый исходник здесь — самостоятельный исполняемый пример.

## Что показывает пример

CSV нельзя корректно разбирать простым split по запятой или getline
по строке: разделители и переводы строк могут находиться в кавычках. Этот небольшой
парсер поддерживает выбранный диалект с запятой, двойными кавычками и LF/CRLF,
сохраняет пустые поля и диагностирует незакрытую кавычку. Пробелы после закрывающей
кавычки не допускаются. Число столбцов и типы полей проверяются отдельно моделью.
Для недоверенных больших файлов добавьте лимиты; для полного промышленного
решения выбирайте специализированную библиотеку и явно согласуйте диалект.

## Запуск

Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh io/bonus/14-csv/main.cpp
./build/io/bonus/14-csv/main
```

На Windows / MSYS2 Bash используйте scripts/build-windows.sh и расширение .exe.
В VS Code открывайте main.cpp и нажимайте F5: доступны корневая и локальная конфигурации.
Рабочая папка F5 — папка исходника. Особенности компилятора и зависимостей
описаны в [README раздела](../README.md).

## Результат и проверка

После показанных в коде значений последняя строка — `OK 14-csv`.
Проверки check(...) выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с NDEBUG.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section io/bonus`
(на Linux команда Python обычно называется python3).
