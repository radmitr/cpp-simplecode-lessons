# 01. Состояния потока и восстановление ввода

Нужны циклы, строки, >>, getline и основы потоков из уроков 115–118.
Стандарт — C++17. Для воспроизводимости основной пример работает
с istringstream: это поток чтения из строки без внешнего файла.

## Флаги и результат операции

- eofbit означает, что операция встретила конец входа.
- failbit означает, что ожидаемое извлечение не удалось, например слово вместо числа.
- badbit обозначает серьёзную ошибку ввода-вывода.
- good() требует отсутствия всех флагов; проверка if (stream) означает отсутствие failbit/badbit и допускает eofbit после успешного извлечения.

EOF заранее не предсказывает успешность следующего чтения. Поэтому используйте
while (input >> value), а для строк — while (getline(input, line)).

## main.cpp

Из строки 10 20 bad 30 успешно читаются два числа. Следующее извлечение int
натыкается на bad и устанавливает failbit. clear() снимает флаги, но не
потребляет токен: программа отдельно читает bad как строку и продолжает.

Ожидаемый вывод:

```text
number: 10
number: 20
fail: true, eof: false
skipped: bad
number: 30
fail: true, eof: true
last: 42, eof: true, fail: false
```

Последний пример показывает важное различие: число 42 успешно прочитано,
но eofbit уже установлен. Проверка eof() до обработки результата потеряла бы
это число. Ещё одна попытка извлечения после конца входа установит и failbit.

## main2.cpp

Программа просит неотрицательное количество и строковую метку. После неверного
токена выполняются clear() и ignore(..., '\n'). После успешного числа остаток
строки также удаляется перед getline. Например, введите:

```text
bad
-1
3
three items
```

После двух повторных запросов последняя строка вывода содержит
count: 3, label: three items. Если вход закончился до получения количества
или метки, программа возвращает 1, а не повторяет запрос бесконечно.
Это пример форматированного извлечения числа; остаток строки после него
игнорируется, а не проверяется на отсутствие дополнительных токенов.

## Запуск

Из корня на Linux:

```bash
bash scripts/build-linux.sh io/bonus/01-stream-state/main.cpp
./build/io/bonus/01-stream-state/main
bash scripts/build-linux.sh io/bonus/01-stream-state/main2.cpp
printf 'bad\n-1\n3\nthree items\n' | ./build/io/bonus/01-stream-state/main2
```

На Windows / MSYS2 Bash используйте build-windows.sh и расширение .exe.

Упражнение: замените цикл чтения в копии урока 119 на while (fs >> point)
и проверьте пустой файл, последнюю строку без перевода строки и повреждённые данные.
