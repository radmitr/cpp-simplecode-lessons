# 03. Строковые потоки и разбор записей

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Стандарт и компилятор: `c++17`. Каждый исходник здесь — самостоятельный исполняемый пример.

## Что показывает пример

`istringstream` читает из строки теми же операциями, что `ifstream`,
`ostringstream` формирует строку. После формального успеха проверьте лишний хвост.
Для повторного использования отдельно замените буфер через `str` и сбросьте
состояние через `clear`: это разные действия. Разбор по пробелам не поддерживает
произвольные строки с пробелами и не является CSV/JSON-парсером.

## Разбор кода и полезные варианты

`istringstream` оборачивает строку 7 Ada 42 в обычный интерфейс чтения.
Цепочка >> заполняет `id`/name/score, `std::ws` потребляет хвостовые пробелы,
а eof после этого подтверждает отсутствие дополнительного содержимого.

`ostringstream` делает обратную операцию: собирает текст 7:Ada:42.
Это удобно для проверки точного вывода без перенаправления глобального `cout`.

~~~cpp
input.clear();
input.str("9 Bob 10");
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

`str` меняет исходный текст, `clear` сбрасывает флаги прежнего чтения.
Это разные действия: замена строки не является универсальным сбросом состояния.
`operator>`> для `string` читает слово; имя с пробелами требует другого формата,
например `getline` с разделителем или CSV/JSON.

## Запуск

Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh io/bonus/03-string-streams/main.cpp
./build/io/bonus/03-string-streams/main
```

На Windows / MSYS2 Bash используйте `scripts/build-windows.sh` и расширение .exe.
F5 — запуск с отладчиком; Ctrl+F5 — без отладчика.

В VS Code открывайте `main.cpp` и нажимайте F5/Ctrl+F5: доступны корневая и локальная конфигурации.
Рабочая папка при F5/Ctrl+F5 — папка исходника. Особенности компилятора и зависимостей
описаны в [README раздела](../README.md).

## Результат и проверка

После показанных в коде значений последняя строка — `OK 03-string-streams`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section io/bonus`
(на Linux команда Python обычно называется python3).
