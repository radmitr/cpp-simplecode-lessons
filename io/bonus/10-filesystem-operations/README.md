# 10. Каталоги, файлы, симлинки и error_code

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Стандарт и компилятор: `c++17`. Каждый исходник здесь — самостоятельный исполняемый пример.

## Что показывает пример

У filesystem есть выбрасывающие и error_code-перегрузки. Обход каталога
не гарантирует порядок: сортируйте, если он нужен. exists и последующее открытие
не являются одной атомарной операцией — состояние может измениться между ними.
На Windows создание симлинков может требовать дополнительных прав/Developer Mode;
пример явно сообщает недоступность, сохраняя проверки остальных операций.
Удаление ограничено собственной временной папкой. Не переносите рекурсивную
очистку на произвольный пользовательский путь без проверки назначения.

## Разбор кода и полезные варианты

Пример создаёт `a.txt` с abc, копирует его в `b.txt`, переименовывает в `c.txt`
и проверяет размер 3. directory_iterator не обещает порядок элементов,
поэтому имена перед сравнением сортируются.

`create_symlink` вызывается с error_code. На Windows право создания симлинка
может отсутствовать: тогда программа сообщает причину и продолжает остальные
проверки, а не объявляет весь пример ошибочным.

~~~cpp
std::error_code error;
std::filesystem::create_symlink(source, link, error);
~~~

Сокращённый фрагмент; полный пример: [main.cpp](main.cpp).

Перегрузка с error_code помогает обработать ошибку без обязательного исключения
filesystem_error; системные отказы и результат `bool` всё равно нужно учитывать.
`remove` удаляет один объект, remove_all рекурсивно удаляет дерево.
Не применяйте рекурсивную очистку к пути из ввода без проверки владельца/границ.

Проверка exists и следующая операция не атомарны: между ними состояние
файловой системы может измениться. Это важно для конкурентного доступа.

## Запуск

Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh io/bonus/10-filesystem-operations/main.cpp
./build/io/bonus/10-filesystem-operations/main
```

На Windows / MSYS2 Bash используйте `scripts/build-windows.sh` и расширение .exe.
F5 — запуск с отладчиком; Ctrl+F5 — без отладчика.

В VS Code открывайте `main.cpp` и нажимайте F5/Ctrl+F5: доступны корневая и локальная конфигурации.
Рабочая папка при F5/Ctrl+F5 — папка исходника. Особенности компилятора и зависимостей
описаны в [README раздела](../README.md).

## Результат и проверка

После показанных в коде значений последняя строка — `OK 10-filesystem-operations`.
Проверки `check(...)` выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с `NDEBUG`.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section io/bonus`
(на Linux команда Python обычно называется python3).
