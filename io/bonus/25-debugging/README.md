# 25. Взаимодействие с отладчиком

## Версия C++

Режим сборки — **C++26**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках. Для C++26 реализация ещё может быть неполной.

## Что изучаем

Определяем наличие отладчика и запрашиваем остановку. Нужны запуск F5 и продолжение выполнения отладчиком.

## Примеры

- [main.cpp](main.cpp) — проверка присутствия и условная остановка; значение `debugger` зависит от запуска.

## Как это работает

`is_debugger_present` сообщает, видит ли реализация присоединённый отладчик. `breakpoint_if_debugging` запрашивает остановку только при его наличии. Пример печатает состояние и вызывает эту условную остановку: при F5 продолжите выполнение ещё одним F5. Это не исключение C++, а взаимодействие с внешним отладчиком. Для явной безусловной остановки предусмотрен необязательный аргумент `--break`, вызывающий `breakpoint`.

## Сборка и запуск

[Настройка компилятора и запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).
Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh io/bonus/25-debugging/main.cpp
./build/io/bonus/25-debugging/main
```

Для остальных вариантов замените `main.cpp` и имя исполняемого файла. На Windows вызовите `scripts/build-windows.sh` через MSYS2 Bash, затем соответствующий файл `build/io/bonus/25-debugging/main.exe`. Готовые `tasks.json` и `launch.json` содержат оба варианта системы.

Если возможности нет, программа печатает `UNAVAILABLE` и возвращает `77`: это пропуск, а не успешная демонстрация. Включённая ветка примера требует совместимой реализации; один флаг стандарта не добавляет отсутствующую библиотеку.

Ввода, сетевых служб и постоянных файлов не требуется, если ниже не указано другое. Каждый пример проверяет результаты; успех — строка `OK modern-example` и код `0`, ошибка проверки — код `1`. При F5 возможна ожидаемая остановка; продолжите выполнение. Аргумент `--break` используйте только для намеренной остановки под отладчиком.

## Типичные ошибки

Не использовать breakpoint как обработку пользовательских ошибок или механизм синхронизации. Безусловная остановка без отладчика может завершить процесс сигналом. Обычный автоматический запуск выполняется без `--break` и не требует отладчика.
