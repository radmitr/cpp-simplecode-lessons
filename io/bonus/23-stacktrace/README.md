# 23. Получение стека вызовов

## Версия C++

Режим сборки — **C++23**, учебная конфигурация — GCC 16+. Версии отдельных механизмов отмечены в исходниках.

## Что изучаем

Сохраняем стек в месте события для диагностики. Нужны вложенные функции и исключения.

## Примеры

- [main.cpp](main.cpp) — ограниченный снимок и чтение кадра; число кадров и описание могут различаться.

## Как это работает

Вызов `stacktrace::current(0,16)` фиксирует до шестнадцати кадров в текущем потоке. Это снимок, а не живое представление стека. Пример получает его внутри вложенной функции и печатает описание первого кадра, если он существует. Отдельный снимок с пропуском одного кадра показывает параметр `skip`. Имена, адреса, номера строк и даже наличие кадров зависят от платформы, символов отладки и оптимизации. Снимок в обработчике исключения отражает место обработчика, а не автоматически место исходного `throw`.

## Сборка и запуск

[Настройка компилятора и запуск в VS Code](../../../README.md#сборка-и-запуск-в-vs-code).
Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh io/bonus/23-stacktrace/main.cpp
./build/io/bonus/23-stacktrace/main
```

Для остальных вариантов замените `main.cpp` и имя исполняемого файла. На Windows вызовите `scripts/build-windows.sh` через MSYS2 Bash, затем соответствующий файл `build/io/bonus/23-stacktrace/main.exe`. Готовые `tasks.json` и `launch.json` содержат оба варианта системы.

Если возможности нет, программа печатает `UNAVAILABLE` и возвращает `77`: это пропуск, а не успешная демонстрация. Включённая ветка примера требует совместимой реализации; один флаг стандарта не добавляет отсутствующую библиотеку.

Ввода, сетевых служб и постоянных файлов не требуется, если ниже не указано другое. Каждый пример проверяет результаты; успех — строка `OK modern-example` и код `0`, ошибка проверки — код `1`.

## Типичные ошибки

Не сравнивать точный текст между компьютерами. Не читать `front()` пустого снимка. Получение стека может быть дорогим и не является универсально безопасным действием в обработчике сигнала. Наличие заголовка ещё не доказывает наличие backend-библиотеки при линковке; для этой конфигурации используется `stdc++exp`.
