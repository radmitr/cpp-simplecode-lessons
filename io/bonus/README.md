# Бонусы по вводу-выводу

21 урок: состояния потоков, форматы, файловая система и сохранение данных.
Сначала изучите исходные уроки 115–119, затем бонус 01. Бонус 02 задаёт простой
бинарный формат, 16 развивает его до записей переменной длины. Остальные уроки
можно изучать по группам: потоки 03–08/11–12/18, пути 09–10, форматы 13–16,
сохранение и утилиты 17/19–20. Большинство примеров используют C++17,
UTF-8/char8_t — C++20, format/print — отдельный современный урок.

## Как работать

Открывайте нужный main.cpp и нажимайте F5. Каждый урок имеет локальные задачи
Windows/Linux и использует общие скрипты из корня репозитория. Обычные уроки
выбирают системный GCC, современные — CXX_MODERN; версии и зависимости
обозначены отдельно. Сборка всех примеров и проверка результатов:

```bash
python3 scripts/check-bonuses.py --section io/bonus
```

На Windows вместо python3 можно использовать python; запускайте из корня.
Проверки создают временные данные только в build/ и не меняют учебные файлы.
Linux ещё предстоит проверить на Ubuntu. [Статус проверки Windows и её ограничения](../../bonus/reflection/VALIDATION.md)
сохранены отдельно; воспроизводимый сценарий находится в репозитории.

## Данные и зависимости

Новые файловые примеры используют common/workspace.hpp: создают собственную
временную папку и очищают только её. Проверочный скрипт размещает эти папки
в build/, обычный F5 — в системной временной папке. Урок 02 по-прежнему создаёт
point-v1.bin в рабочей папке и при F5 использует папку исходника.

JSON требует [nlohmann/json](dependencies.md). Форматирование/печать требует
GCC 14+; на Linux выберите CXX_MODERN=/opt/gcc-16/bin/g++ после установки.
Рабочий режим урока 19 не выводит приглашений и строки OK, чтобы stdout можно
было использовать в конвейере. Для примеров повреждённых данных используются
контролируемые наборы внутри каждого урока.

Итоговые задачи: соедините CSV с charconv и моделью записи; блочное копирование
с CLI; бинарный кодек с сохранением через временный файл. Не переносите гарантии
одного компонента на весь процесс без проверки ошибок на каждом этапе.
