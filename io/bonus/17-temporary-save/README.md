# 17. Сохранение через временный файл

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Стандарт и компилятор: c++17. Каждый исходник здесь — самостоятельный исполняемый пример.

## Что показывает пример

Подготовка идёт в соседнем файле на той же файловой системе; исходный
файл меняется только после успешной записи/закрытия и проверки. На Windows
используется MoveFileExW с заменой, на Linux rename. Пример работает в собственной
закрытой временной папке и с одним писателем: проверка exists плюс открытие не
является защитой от гонки в общем каталоге. Имена временных файлов в промышленном
коде нужно получать с исключительным созданием. Замена имени и устойчивость
к сбою питания — разные гарантии; для последней нужны платформенные операции
сброса файла/каталога, которые здесь не обещаются.

## Разбор кода и полезные варианты

save_checked сначала пишет prepared.tmp рядом с назначением,
закрывает с проверкой, проверяет данные и лишь затем заменяет target.
При valid=false исходное old остаётся; удачная попытка заменяет его на new.
Обработчик удаляет временный файл при отказе подготовки.

На Windows используется MoveFileExW с MOVEFILE_REPLACE_EXISTING,
на POSIX — rename. Соседний временный файл выбирают, чтобы не требовать
переноса между файловыми системами.

Важно различать успешную замену имени и сохранность при сбое питания.
Фиксация данных/каталога на носителе требует дополнительных платформенных
действий; эта программа их не делает.

Имя prepared.tmp фиксировано, а проверка exists не является эксклюзивным
атомарным созданием. Пример работает в собственном LessonWorkspace,
но его нельзя без доработки считать протоколом одновременного сохранения
несколькими процессами в общий недоверенный каталог.

## Запуск

Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh io/bonus/17-temporary-save/main.cpp
./build/io/bonus/17-temporary-save/main
```

На Windows / MSYS2 Bash используйте scripts/build-windows.sh и расширение .exe.
В VS Code открывайте main.cpp и нажимайте F5: доступны корневая и локальная конфигурации.
Рабочая папка F5 — папка исходника. Особенности компилятора и зависимостей
описаны в [README раздела](../README.md).

## Результат и проверка

После показанных в коде значений последняя строка — `OK 17-temporary-save`.
Проверки check(...) выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с NDEBUG.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section io/bonus`
(на Linux команда Python обычно называется python3).
