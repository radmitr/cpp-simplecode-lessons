# 21. std::format и std::print

Предварительно: Функции, переменные и темы предыдущих уроков раздела.
Стандарт и компилятор: GCC 14+ и c++23. Каждый исходник здесь — самостоятельный исполняемый пример.

## Что показывает пример

std::format возвращает строку (C++20), print/println выводят её без
привычной цепочки operator<< (C++23). Этот объединённый пример требует
libstdc++ с print, поэтому минимум GCC 14; только format появился в GCC 13.
Проверка литеральных форматных строк может выполняться при компиляции,
для runtime-строки используется vformat с обработкой format_error.
На Ubuntu с GCC 11 урок требует CXX_MODERN, остальные обычные бонусы — нет.

link-libraries.txt подключает stdc++exp. В MinGW это требуется для реализации
терминального вывода std::print; отсутствие библиотеки даёт ошибку линковки,
хотя заголовок print уже найден. Общие скрипты добавляют -lstdc++exp после
исходников. [Параметры libstdc++](https://gcc.gnu.org/onlinedocs/libstdc++/manual/using.html).

## Запуск

Из корня проекта, Linux:

```bash
bash scripts/build-linux.sh io/bonus/21-format-and-print/main.cpp
./build/io/bonus/21-format-and-print/main
```

На Windows / MSYS2 Bash используйте scripts/build-windows.sh и расширение .exe.
В VS Code открывайте main.cpp и нажимайте F5: доступны корневая и локальная конфигурации.
Рабочая папка F5 — папка исходника. Особенности компилятора и зависимостей
описаны в [README раздела](../README.md).

## Результат и проверка

После показанных в коде значений последняя строка — `OK 21-format-and-print`.
Проверки check(...) выбрасывают исключение при нарушении ожидаемого результата;
в таком случае программа печатает причину и возвращает 1. Они работают и с NDEBUG.
Адреса, диагностические имена типов, размеры и время могут отличаться между системами.
Проверка всего раздела: `python scripts/check-bonuses.py --section io/bonus`
(на Linux команда Python обычно называется python3).
