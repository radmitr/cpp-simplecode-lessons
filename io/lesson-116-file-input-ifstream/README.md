# Урок 116. Чтение из файла: ifstream

Предварительно: Урок 115, строки и циклы.

## Примеры

- [main.cpp](main.cpp): Читает по символам через while (fin.get(ch)).
- [main2.cpp](main2.cpp): Читает слова, используя учебный цикл while (!fin.eof()).
- [main3.cpp](main3.cpp): Читает строки с предварительной проверкой eof().
- [main4.cpp](main4.cpp): Читает строки в char[50] через getline с проверкой результата.

Каждый main*.cpp — отдельная программа.

## Механизм и разбор

get(ch) извлекает очередной символ, включая пробелы и переводы строк.
operator>> для string обычно пропускает ведущие пробелы и читает слово.
getline читает до разделителя, удаляя его из потока, но не добавляя в результат.

~~~cpp
std::string line;
while (std::getline(input, line)) {
    std::cout << line << '\n';
}
~~~

Проверка операции стоит после попытки чтения. eof сообщает о предыдущем
обнаружении конца, а не о том, что следующее извлечение точно получится.
Поэтому while(!eof()) из части вариантов не является надёжным образцом.

Буфер char[50] в main4 ограничивает длину одной извлекаемой строки.
std::getline в std::string позволяет динамическую длину, но для внешних
данных всё равно нужны разумные ограничения памяти.
Наличие файла не гарантирует права доступа или корректный формат содержимого.

## Что важно понять

В main2.cpp/main3.cpp проверяется eof() до чтения: возможна лишняя итерация, а failbit без EOF может привести к зацикливанию. Предпочтительны while (fin >> word) и while (getline(fin, line)); см. бонус 01-stream-state. Строка длиннее буфера main4.cpp устанавливает failbit и останавливает цикл.
