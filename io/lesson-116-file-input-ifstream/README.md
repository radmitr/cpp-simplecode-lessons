# Урок 116. Чтение из файла: ifstream

Предварительно: Урок 115, строки и циклы.

## Примеры

- [main.cpp](main.cpp): Читает по символам через while (fin.get(ch)).
- [main2.cpp](main2.cpp): Читает слова, используя учебный цикл while (!fin.eof()).
- [main3.cpp](main3.cpp): Читает строки с предварительной проверкой eof().
- [main4.cpp](main4.cpp): Читает строки в char[50] через getline с проверкой результата.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "io/lesson-116-file-input-ifstream/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Варианты выводят содержимое myFile.txt по символам, словам или строкам. Запускайте из папки урока, где лежит этот файл.

## Что важно понять

В main2.cpp/main3.cpp проверяется eof() до чтения: возможна лишняя итерация, а failbit без EOF может привести к зацикливанию. Предпочтительны while (fin >> word) и while (getline(fin, line)); см. бонус 01-stream-state. Строка длиннее буфера main4.cpp устанавливает failbit и останавливает цикл.
