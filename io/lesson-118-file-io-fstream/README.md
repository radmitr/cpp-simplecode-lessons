# Урок 118. Чтение и запись: `fstream`

## Версия C++

`std::string` — **C++98**.

Сборка примеров: **C++17**. Это режим проекта,
а не дата появления всех использованных конструкций.

## Что изучаем

Предварительно: Уроки [«115. Запись в файл: `ofstream`»](../lesson-115-file-output-ofstream/README.md) — [«116. Чтение из файла: `ifstream`»](../lesson-116-file-input-ifstream/README.md), меню, строки и `getline`.

## Примеры

- [main.cpp](main.cpp): Меню 1/2: дописывает одно слово или читает все слова.
- [main2.cpp](main2.cpp): Работает с целыми строками через `getline` в режиме binary.
- [main3.cpp](main3.cpp): Использует wfstream/wcin/wcout и преобразование UTF-8 через locale/codecvt.

Каждый `main*.cpp` — отдельная программа.

## Как это работает

`fstream` объединяет интерфейсы чтения и записи. Режим in|out|app разрешает
читать и дописывать. `seekg(0)` перемещает чтение в начало, но app продолжает
направлять последующие записи в конец.

В меню 1 выбирает запись, 2 — чтение. В `main.cpp` >> msg читает одно слово,
в `main2.cpp getline` сохраняет пробелы. `ignore()` снимает один символ после
числа меню; для сложного неверного ввода этого может быть недостаточно.

После чтения с ошибкой перед новым позиционированием/чтением обычно нужен
`clear`, а при переключении чтения и записи — необходимые `flush()` и позиционирование.
Файл, кодировка и рабочая папка должны соответствовать выбранному варианту.

wfstream в main3 работает с wchar_t через преобразующий facet.
Ширина wchar_t зависит от платформы, а сам широкий тип не является
универсальным обещанием UTF-8. В C++17 codecvt-вариант полезен как
исторический разбор; современную обработку UTF-8 изучайте отдельно.

## Сборка и запуск

[Запуск в VS Code](../../README.md#сборка-и-запуск-в-vs-code).

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5/Ctrl+F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "io/lesson-118-file-io-fstream/main.cpp"
```

На Linux используйте `scripts/build-linux.sh` с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Введите 1 и сообщение для записи либо 2 для чтения. Файл `myFile.txt` находится в рабочей папке; app сохраняет старые записи и добавляет новые.

## Типичные ошибки

binary отключает платформенные преобразования текстового режима, но не задаёт структуру данных или кодировку. `main2.cpp/main3.cpp` пропускают один символ через `ignore()`: это предполагает обычный ввод пункта меню с Enter. codecvt устарел и не является универсальным современным решением Unicode. В `main3.cpp` на Windows стандартные потоки переведены в широкий UTF-8-режим, на Linux используется locale терминала.
