Уроки 115–119 исходного курса собраны в отдельный раздел с сохранением номеров.
Начальные примеры остаются базовыми; раздел объединяет их с дальнейшими
темами работы с данными. Потоки используются для файлов, консоли и строк.

## Запуск и файлы

Стандарт — C++17, компиляторы и GDB те же, что в [общем README](../README.md).
В VS Code откройте корень или отдельный урок, затем нужный main*.cpp и нажмите F5.
Каждый main*.cpp — самостоятельная программа; номера вариантов описаны в README уроков.

Из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh io/lesson-116-file-input-ifstream/main.cpp
(cd io/lesson-116-file-input-ifstream && ../../build/io/lesson-116-file-input-ifstream/main.exe)
```

На Linux замените build-windows.sh на build-linux.sh и уберите .exe.
В F5 рабочая папка — папка исходника. При ручном запуске используйте такую же
папку, чтобы программа нашла учебный myFile.txt. Запись может изменять эти
отслеживаемые Git файлы: app добавляет данные, остальные режимы могут их стереть.
Для экспериментов из терминала можно выбрать временную рабочую папку с копией файла.
Сгенерированный point.dat урока 117 и point-v1.bin бинарного бонуса игнорируются Git.

## Ограничения, которые важно разобрать

- Проверяйте результат чтения, а не только eof(): варианты из уроков 116 и 119 показывают, почему.
- Открытие файла и успешная запись — разные проверки. Ошибка может обнаружиться при сбросе буфера или закрытии.
- binary не делает формат переносимым и не выбирает кодировку текста.
- Запись представления Point из урока 117 зависит от платформы и не подходит для произвольных классов со string или указателями.
- В широком варианте 118 используется устаревший codecvt; настройка терминала и кодировка файла — отдельные задачи.
