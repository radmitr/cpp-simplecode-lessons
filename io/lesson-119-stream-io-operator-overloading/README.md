# Урок 119. Потоковые операторы для своего типа

Предварительно: Классы, `friend`, перегрузка операторов и урок 118.

## Примеры

- [main.cpp](main.cpp): Определяет ostream << `Point` и istream >> `Point`; записывает `Point` в файл.
- [main2.cpp](main2.cpp): Читает ещё один `Point` с клавиатуры, записывает его и читает файл с начала.

Каждый `main*`.cpp — отдельная программа.

## Механизм и разбор

`operator<`< оформляет `Point` как последовательность координат в любом ostream.
`operator>`> извлекает координаты из istream. Возврат ссылки на исходный поток
позволяет цепочку out << p1 << `p2` и условие `while(input >> point)`.

~~~cpp
while (input >> point) {
    std::cout << point << '\n';
}
~~~

Сокращённый фрагмент; полный пример: [main2.cpp](main2.cpp).

Это дополнительная корректная форма цикла, а не описание активного
`while(true)` из `main2.cpp`. Поток остаётся ответственным за состояние,
оператор не должен объявлять успех, если чтение нужного поля не удалось.

Если читать сразу в поля объекта, ошибка на третьем числе может оставить
уже изменённые первые два. Для требования «всё или ничего» сначала
разбирают временный `Point`, проверяют его и затем присваивают.
Собственный формат вывода должен быть согласован со своим форматом чтения;
декоративный текст не становится автоматически читаемым обратно.

## Что важно понять

Возврат ссылки на поток позволяет цепочки операций и проверку результата. В `main2.cpp` цикл проверяет только `eof()` после чтения: при повреждённых данных failbit без EOF может зациклить программу. Корректная форма — `while` (`fs` >> `p3`). Простой `operator>`> меняет поля по мере чтения; при ошибке объект может оказаться частично изменён.
