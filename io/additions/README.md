## Данные и зависимости

Файловые примеры с `common/workspace.hpp` создают собственную
временную папку и очищают только её. Проверочный скрипт размещает эти папки
в `build/`, обычный F5/Ctrl+F5 — в системной временной папке.
[Явный бинарный формат](18-portable-binary/README.md) создаёт
`point-v1.bin` в рабочей папке и при F5/Ctrl+F5 использует папку исходника.

JSON требует [nlohmann/json](dependencies.md). Общая конфигурация урока форматирования и печати требует
GCC 16+; на Linux используется `CXX_MODERN`, по умолчанию `/opt/gcc/16/bin/g++`.
Рабочий режим [консольной утилиты](21-console-tool/README.md) не выводит
приглашений и строки `OK`, чтобы `stdout` можно
было использовать в конвейере. Для примеров повреждённых данных используются
контролируемые наборы внутри каждого урока.

Итоговые задачи: соедините CSV с charconv и моделью записи; блочное копирование
с CLI; бинарный кодек с сохранением через временный файл. Не переносите гарантии
одного компонента на весь процесс без проверки ошибок на каждом этапе.

Откройте корень проекта или папку урока и выберите нужный исходник.
[F5, Ctrl+F5 и команды терминала](../../README.md#сборка-и-запуск-в-vs-code).

В списке выше дан **режим сборки**; даты появления отдельных возможностей объясняются в уроках.
