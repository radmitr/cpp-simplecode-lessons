# Урок 115. Запись в файл: ofstream

Предварительно: Строки и потоковый вывод; для main3.cpp также классы, деструкторы и исключения.

## Примеры

- [main.cpp](main.cpp): Открывает myFile.txt с app и дописывает данные.
- [main2.cpp](main2.cpp): Перезаписывает файл, проверяет открытие и состояние после записи.
- [main3.cpp](main3.cpp): Оборачивает ofstream в некопируемый FileWriter.
- [main4.cpp](main4.cpp): Записывает три строки; необязательный первый аргумент задаёт имя файла.

Каждый main*.cpp — отдельная программа.

## Запуск и результат

Откройте папку урока или корень проекта, затем нужный исходник и нажмите F5.
Сборка из корня в MSYS2 Bash на Windows:

```bash
bash scripts/build-windows.sh "io/lesson-115-file-output-ofstream/main.cpp"
```

На Linux используйте scripts/build-linux.sh с тем же аргументом.
Подробности запуска из терминала и рабочей папки — в [README раздела](../README.md).

Создаётся или изменяется текстовый файл. main.cpp дописывает, остальные варианты заменяют содержимое.

## Что важно понять

Рабочая папка F5 — папка исходника: учебный myFile.txt изменяется при запуске. Успешное открытие не гарантирует успешную запись/закрытие. main2.cpp не включает exceptions(): ошибки потока обычно остаются флагами, а не попадают в catch. Не считайте errno универсальной диагностикой iostream.
