# Учебный маршрут

Внутри каждого авторского раздела читайте папки по номерам с `01`.
Этот порядок совпадает с README раздела и [общим каталогом](../LESSONS.md):
сначала необходимые знания, затем связанные применения и сложные дополнения.
Версия C++ — дополнительный ориентир, поэтому связанная группа может включать
несколько стандартов. [Указатель версий](cpp-versions.md) ведёт на те же исходники.

Исходный курс SimpleCode сохраняет свои папки, номера и порядок. Бонусы продолжают
соответствующую тему; если предварительные знания уже есть, к ним можно перейти сразу.
Каждый README урока уточняет нужную подготовку, варианты программ и ограничения.

## 1. Основы языка и время жизни

[Курс основ](../basics/README.md) даёт переменные, выражения, функции, массивы,
указатели и ссылки. Для примеров с владением дополнительно нужны классы,
конструкторы и деструкторы из раздела ООП.

[Бонусы основ](../basics/bonus/README.md) идут в порядке:
типы и инициализация → ссылки и вывод типов → строки → RAII и перемещение →
умные указатели → лямбды и вызываемые объекты → операции с типами → константные
вычисления → устройство программы → время → диагностика и сложные дополнения.

## 2. Классы и интерфейсы

Изучите [ООП курса](../oop/README.md): создание и уничтожение объектов,
копирование, операторы, наследование и виртуальные функции.
[Бонусы ООП](../oop/bonus/README.md) продолжают тему связями объектов,
декрементом, явным параметром объекта и новыми формами операторов.

## 3. Шаблоны и ограничения

После [шаблонов курса](../templates/README.md) переходите к
[бонусам шаблонов](../templates/bonus/README.md): вывод параметров → специализация
и CTAD → свойства типов → пакеты → пробрасывание аргументов → concepts →
перенос квалификаторов и индексирование пакета.

## 4. Ошибки и гарантии состояния

После [`try`, `throw` и `catch` курса](../exceptions/README.md) пройдите
[бонусы исключений](../exceptions/bonus/README.md): виды ошибок → сохранение
причины → `noexcept` → гарантии состояния после неудачной операции.
Эти знания нужны при изучении контейнеров, IO и асинхронных результатов.

## 5. Контейнеры, представления и результаты

Сначала изучите [STL курса](../stl/README.md): контейнеры, итераторы и алгоритмы.
[Бонусы STL](../stl/bonus/README.md) развивают создание контейнеров, представления
строк и массивов, результаты операций, диапазоны, способы хранения,
вызываемые обёртки, ресурсы памяти и численные вычисления.

`optional` предшествует `expected`, затем идут `variant` и `any`.
`string_view` предшествует `span`, ranges — своим новым адаптерам.
Для политик выполнения сначала нужны основы многопоточности;
для `mdspan`, SIMD и линейной алгебры — многомерные данные и численные операции.

## 6. Ввод-вывод и сохранение данных

После [потоков и файлов курса](../io/README.md) читайте
[IO-бонусы](../io/bonus/README.md): состояние и разбор → форматирование →
файловые операции → пути и кодировки → текстовые и бинарные форматы →
сохранение → консольные утилиты и журнал → диагностика.
Новые способы хранения требуют проверки ошибок и времени жизни данных.

## 7. Многопоточность

После [потоков и мьютексов курса](../multithreading/README.md) пройдите
[бонусы многопоточности](../multithreading/bonus/README.md): передача объектов →
локальные данные → захват мьютексов → ожидание и очереди → результаты и пул →
остановка → координация → атомики → вывод и измерения.
Дополнительные варианты, использующие более поздний механизм, имеют ссылку
на него в README своего урока.

## 8. Самостоятельные направления

- [Модули](../bonus/modules/README.md) — после заголовков, ODR и раздельной компиляции.
- [Корутины и генераторы](../bonus/coroutines/README.md) — после RAII, ссылок и исключений.
- [Контракты](../bonus/contracts/README.md) — после функций и проверки входных данных.
- [Рефлексия](../bonus/reflection/README.md) — от RTTI и ручных описателей к статической рефлексии и её применениям; нужны шаблоны и константные вычисления.
- [Senders и планировщики](../bonus/execution/README.md) — после многопоточности, времени жизни и отложенного выполнения.
- [Сети](../bonus/networking/README.md) — адреса и транспорт → надёжность соединения → HTTP/TLS → асинхронные протоколы → итоговый чат.
- [PostgreSQL](../bonus/databases/postgresql/README.md) — подключение и запросы → транзакции и ограничения → производительность и блокировки → эксплуатация.

В каждом направлении сохраняется собственная последовательность с `01`.
Внешние библиотеки, службы и доступность новых API проверяйте по его инструкции.
[Карта покрытия](cpp-coverage.md) отличает разобранные сценарии от частичных
и пока недоступных примеров.
