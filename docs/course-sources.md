# Курс и учебные примеры

Проект основан на уроках **Сергея Журавлёва (#SimpleCode)**:
[YouTube](https://www.youtube.com/@SimpleCodeIT),
[Udemy](https://www.udemy.com/user/zhuravliov-sergei/).
Это личный учебный справочник, а не официальный репозиторий автора курса.

## Уроки курса и бонусы

Уроки курса сохраняют свои номера и тематические каталоги.
README каждого урока объясняет фактический код, необходимые знания,
ожидаемый результат и запуск на Windows/Linux.

Дополнительные учебные сценарии находятся в `bonus/` соответствующего раздела.
Новые направления, например сети и базы данных, размещены в корневом `bonus/`.
Разные файлы с `main()` запускаются как отдельные программы.

## Оформление и переносимость

Примеры используют стандартную точку входа `int main()`.
Обычная настройка UTF-8-консоли вынесена в
[общий заголовок](../common/README.md).
Проверки ввода, ограничения числовых диапазонов и освобождение ресурсов
объясняются в конкретных уроках.

Версия появления возможности языка и режим сборки проекта могут отличаться:
см. [версии C++](cpp-versions.md).
Требования к компилятору, библиотекам и способу запуска находятся в README урока
и [общей инструкции](../README.md#требования).

## Проверка начальных уроков

Из корня проекта:

~~~bash
python scripts/check-intro-lessons.py --jobs 2
~~~

На Linux используйте `python3`. Скрипт собирает 71 программу и проверяет
104 сценария: обычный и неверный ввод, код завершения, вывод, границы факториала,
диапазоны случайных значений и отношения адресов.
Сценарии заданы в `scripts/intro-lessons.json`.

Режим `--build-only` выполняет только сборку.
Результаты сохраняются в `build/intro-checks/`.
Подробности: [проверки начальных уроков](../scripts/README.md#проверка-начальных-уроков).
