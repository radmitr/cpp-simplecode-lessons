# Источники и адаптация начальных уроков

За основу проекта взят курс **Сергея Журавлёва (#SimpleCode)**:
[YouTube](https://www.youtube.com/@SimpleCodeIT),
[Udemy](https://www.udemy.com/user/zhuravliov-sergei/).
Владелец проекта существенно развивает его как личный справочник: добавляет
объяснения, переносимую сборку, проверки и самостоятельные бонусные темы.

## Какие исходники использованы

По просьбе пользователя код начальных уроков взят из конкретных репозиториев
`sgiman`. Они служат источниками программ; это не заявление о точном совпадении
с каждой строкой видеокурса или об авторстве самого курса у владельца репозиториев.
Сверка привязана к неизменяемым коммитам:

- [Основы C++, e7f4b0f95e13](https://github.com/sgiman/CPP_BASE_simplecode_Lessons/tree/e7f4b0f95e138357f38037832e85730f24f88820).
- [ООП, 981c0c08d677](https://github.com/sgiman/CPP_OOP_simplecode_Lessons/tree/981c0c08d6774f7f7aded3401183b66b86c2faaa).

Подготовлена **71 адаптация из 65 разных исходных файлов**:
62 темы основ и 9 тем ООП. Номера основ: 001–028, 031–044, 046–057,
060–061, 063, 066–070; ООП: 073–081.
Урок шаблонов функций находится в `templates/`, остальные основы — в `basics/`.
В каждом README есть ссылка на точный исходник и перечень изменений.
[Полный список и diff каждой адаптации](course-imports.json).

Ранее для этих тем были написаны самостоятельные программы. Теперь в папках
уроков стоят адаптации исходных демонстраций: сохранены существенные операции,
исходные значения, вызовы и порядок действий. Например, в
[заполнении массива](../basics/lesson-027-array-loops/README.md)
снова используется `rand() % 100`, а в
[передаче по значению](../basics/lesson-034-function-value-parameters/README.md) —
сумма трёх исходных значений `double`.

## Как разделены общие исходники

В источниках некоторые темы объединены в один файл. **Восемь** местных программ
представляют явно выделенные фрагменты, а не копии общего файла целиком:

- 039–041: отдельно `inline`, перегрузки и все исходные шаблоны с их вызовами.
  Повторение аргументов по умолчанию в начале общего файла здесь не дублируется:
  [исходный урок аргументов по умолчанию](../basics/lesson-038-default-arguments/README.md)
  импортирован отдельно.
- [Стек вызовов](../basics/lesson-042-call-stack/README.md) и
  [рекурсия](../basics/lesson-043-recursion/README.md) объясняют один исходный
  фрагмент `Foo(5)` с разных сторон.
  [Факториал](../basics/lesson-044-recursive-factorial/README.md) сохраняет весь
  учебный порядок общего примера: сначала `Foo(5)`, затем ввод и `Fact`.
- Из файла 060–064 выделены
  [символьные массивы](../basics/lesson-060-c-strings/README.md),
  [преобразование кодов в char](../basics/lesson-061-type-conversions/README.md) и
  [функции C-строк](../basics/lesson-063-c-string-functions/README.md).
  Существовавшие ранее уроки ASCII и `std::string` в этом проходе не заменялись.

Уроки `rand`, копирования и изменения динамических массивов, указателей
на функции и поздние темы уже имелись. Новые копии для них не создаются.
Пропуски 030, 045 и 071 этим набором источников не подтверждены.
Репозиторий [многопоточности sgiman](https://github.com/sgiman/CPP_simplecode_THREAD_Tutorial)
ранее использовался для сверки состава: его темы уже представлены в проекте.

## Какие исправления допустимы

Конкретный список дан в README каждого урока. Среди исправлений:

- `void main()` заменено на стандартное `int main()`.
- Исправлено `0! = 1`, ввод факториала ограничен диапазоном `0–12`.
- Небезопасное `b = ++a * a` разделено на два последовательных выражения.
- Добавлены пропущенные `delete[]`, проверки ввода и очистка частично
  созданной динамической матрицы.
- Уточнены неверные комментарии о размерах типов, указателях, диапазонах
  `rand() % n` и конструкторах; исправлен вывод `j` под его собственной подписью.
- Исправлены опечатки, русифицировано приветствие в первом примере.
  Убраны пустые заголовки, служебные маркеры конца и лишние пустые строки;
  порядок учебных действий сохранён.
- Зависящая от ОС локаль заменена
  [общей настройкой UTF-8-консоли](../common/README.md).
  Не переносились служебные `MyDate()`, дата и MSVC-зависимый `utils.h`.
- Конечные паузы убраны, кроме
  [урока ожидания ввода](../basics/lesson-021-console-pause/README.md):
  там сохранена пауза, но используется переносимый `cin.get()`.
- Двухаргументная `strcat_s` заменена `strcat` только для фиксированных строк,
  заведомо помещающихся в выделенный буфер; ограничение объяснено в уроке.

Случайные числа не заменяются последовательными ради точного тестового вывода.
Адреса также не подменяются константами: проверяются их отношения внутри запуска.

## Куда перенесены самостоятельные варианты

**Десять** программ сохранены отдельно:

- [Основные типы и sizeof](../basics/bonus/31-fundamental-types/README.md) —
  переменные разных типов и размер массива.
- [Трассировка стека вызовов](../basics/bonus/32-call-stack-trace/README.md) —
  обычные вложенные функции и вывод после рекурсивного возврата.
- [Хранение C-строк и управляющие символы](../basics/bonus/33-c-strings-and-escapes/README.md) —
  длина/размер строки и выполняемые примеры экранирования.
- [Скобки макроса](../basics/bonus/34-macro-parentheses/README.md) —
  сложные выражения в аргументах.
- [Ссылки, const и время жизни](../basics/bonus/03-references-and-lifetime/README.md) —
  сравнение `int* const` и `const int*` в `main2.cpp`.
- [Числовые преобразования](../basics/bonus/05-numeric-conversions/README.md) —
  расширение и усечение дробной части в `main2.cpp`.
- [RAII](../basics/bonus/02-raii/README.md) —
  обратный порядок уничтожения двух локальных владельцев в `main3.cpp`.

Варианты, менявшие только значения, имена или подписи, отдельными бонусами
не сохранялись. Например, последовательное заполнение вместо случайного
не добавляет механизма к уже имеющимся циклам. Изменения параметров по значению
уже показаны в [сравнении передачи по значению, ссылке и указателю](../basics/lesson-051-reference-parameters/README.md),
а `strcmp` выполняется в [классе String](../examples/String/README.md).
Вместо новых копий добавлены ссылки к этим реализациям.
Решение для каждого прежнего варианта записано в `previous_variant`
[файла сверки](course-imports.json).

## Как повторить проверку

Из корня проекта:

~~~bash
python scripts/check-intro-lessons.py --jobs 2
python scripts/check-bonuses.py --section basics/bonus --jobs 2
python scripts/check-docs.py
~~~

На Linux используйте `python3`. Проверяются код завершения, существенный вывод,
104 сценария нормального/неверного ввода, границы факториала, размеры и диапазоны
случайных данных, равенство связанных адресов. Таблица кодов `0–255` сравнивается
как байты: она содержит управляющие символы и не является обычным UTF-8-текстом.
Все результаты сборки и проверок создаются только в `build/`.

Также проверяется совпадение локальных исходников с зафиксированной сверкой:
`course-imports.json` содержит SHA-256 нормализованного UTF-8-текста, точные
коммиты и полный diff. При намеренном изменении адаптации нужно снова сравнить
её с источником и обновить описание и запись сверки.

Для повторного получения исходников с GitHub без сборки:

~~~bash
python scripts/check-intro-lessons.py --source-only --verify-upstream
~~~

При наличии сохранённого локального снимка вместо сети можно передать
`--upstream-cache build/source-fidelity/upstream.json`. Автоматическая проверка
фиксирует совпадение текстов и описанного diff; она не пересматривает видеокурс
и не заменяет смысловую проверку изменений человеком.
