# Проверка изменений справочника

## Проверка проекта, 2026-11-02

Среда выполнения: **Windows, MSYS2 MinGW64, GCC/libstdc++ 16.2.0**.

- Через общий скрипт собраны **486 самостоятельных программ** всех разделов.
  После заключительных исправлений повторно собраны 106 затронутых программ;
  ошибок компиляции нет. Вспомогательные `.cpp` компоновались со своими программами.
- Общая настройка консоли перенесена в `namespace console`:
  **236 программ** повторно собраны с `console::setupConsoleEncoding()`.
  Определение функции осталось только в `common/console.hpp`; одинаковые
  локальные реализации и старое имя `course::setup_console()` убраны.
- Через общий `build-windows.sh` собраны и запущены все **71 программа**.
  Пройдены **104 сценария**: обычный и неверный ввод, границы `0!`/`12!`,
  диапазоны и количество случайных значений, связи адресов, порядок вызовов,
  результаты функций и байтовая таблица кодов `0–255`. Эти 104 сценария
  повторены после перехода на `console::setupConsoleEncoding()`.
- Набор бонусов основ, шаблонов, исключений, ввода-вывода и рефлексии прошёл
  **110 проверок**: 106 программ и четыре ожидаемых отказа компиляции.
  В том числе проверены 10 перенесённых самостоятельных примеров.
- Выполнены **86 дополнительных запусков** бонусов многопоточности, STL и ООП,
  включая два режима `std::terminate()` с ожидаемым кодом `86`.
  Два примера с намеренной гонкой данных не запускались.
- Прошли локальные интеграционные проверки сетевых уроков **01–19**:
  TCP/UDP, HTTP/HTTPS, IPv6, переподключение, подтверждения, файлы, Asio
  и WebSocket. Проверялись также отказы и таймауты. Необязательный multicast
  пропущен; внешние серверы не использовались.
- Отдельная проверка оператора присваивания из урока ООП подтвердила
  самоприсваивание, независимость копий, цепочку присваиваний и сохранение
  прежнего массива при искусственно вызванном `std::bad_alloc`.
- Проверены **377 Markdown-файлов** и настройки **338 уроков**:
  отсутствующих локальных целей/якорей и ошибок конфигураций не найдено.
- База IntelliSense обновлена: **497 исходников**, **338 локальных конфигураций**.

Страница [«Курс и учебные примеры»](course-sources.md) описывает разделение уроков
и самостоятельных бонусов, а также проверку начальных программ.

## Как повторить

Из корня проекта:

~~~bash
python scripts/check-builds.py --jobs 4
python scripts/check-intro-lessons.py --jobs 2
python scripts/check-bonuses.py --section all --jobs 2
python scripts/check-docs.py
python bonus/networking/tests/smoke.py
python bonus/networking/tests/smoke_extended.py
~~~

На Linux используйте `python3`. Сетевые проверки используют только loopback.
Для общей сборки нужны зависимости всех разделов и современный компилятор:
см. [скрипты сборки](../scripts/README.md#сборка-всех-программ).

Отчёты находятся в `build/all-builds/report.json`, `build/intro-checks/report.json`
и `build/bonus-checks/report.json`. Дополнительные локальные прогоны сохранены
в `build/safe-checks/report.json` и `build/console-namespace/`.
Режим `--build-only` скрипта начальных уроков собирает программы без выполнения.

Общая сборка не запускает программы с бесконечными циклами, взаимной блокировкой,
неперехваченными исключениями или неопределённым поведением. Успешная компиляция
сама по себе не доказывает правильности выполнения. Предупреждения об учебных
неиспользуемых переменных, устаревших API и намеренном объявлении функции
вместо объекта сохранены. Проверки PostgreSQL с работающим сервером не запускались.

## Что проверить на Linux

**Linux-запуск в этом проходе не выполнялся.** Команды и конфигурации
Windows/Linux подготовлены; результат Windows не выдаётся за проверку Linux.

1. Настройте компилятор и GDB по [общей инструкции](../README.md#требования).
2. Из корня выполните команды выше через `python3`.
3. Проверьте F5 (отладка) и Ctrl+F5 (без отладчика). В этом проходе
   пути конфигураций проверены автоматически, сами клавиши в GUI не нажимались.
4. В [уроке паузы](../basics/lesson-021-console-pause/README.md) нажмите Enter.
   Для [аргументов запуска](../basics/lesson-070-argc-argv/README.md) передайте
   `alpha "two words"`. Учтите управляющие байты в
   [преобразовании кодов символов](../basics/lesson-061-type-conversions/README.md).

Для стандартных начальных уроков проект выбирает C++17. Некоторые прежние
бонусы основ используют C++20; их `cxx-standard.txt` учитывается скриптом.
Требования остальных разделов приведены в их README.
