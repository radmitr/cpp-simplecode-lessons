# Проверка настройки консоли Windows

Проверено 28 октября 2026 года на Windows: MSYS2 MinGW-w64 GCC 16.2.0 и GDB 17.2.

## Изменения

- В 164 исходных файлах, включая шаблон, заменены прежние блоки настройки консоли: 149 функций `setupConsoleEncoding()` и 15 блоков непосредственно в `main()`. На Windows вызываются `SetConsoleCP(CP_UTF8)` и `SetConsoleOutputCP(CP_UTF8)` вместо `system("chcp 65001 > nul")`; обычные Linux-блоки `setlocale` удалены.
- `<windows.h>` подключается только при `_WIN32`. Перед подключением определяются `NOMINMAX` и `WIN32_LEAN_AND_MEAN`, если они ещё не заданы.
- Из задач корня и урока 113 удалены явно прописанные `chcp`. Задачи запуска без сборки вызывают бинарник напрямую.
- Дополнительные профили PowerShell в `settings.json` не требуются. Локальные `settings.json` снова исключены из Git общим правилом.
- `main3.cpp` урока 118 сохранён без изменений: широкий ввод/вывод использует `_setmode` на Windows и `std::setlocale(LC_ALL, "")` на Linux. Учебный `myFile.txt` не менялся при проверке.

## Результаты

- Все 166 самостоятельных программ собраны через `scripts/build-windows.sh` с C++17.
- Все 166 программ отдельно собраны командами задач своих уроков, включая их прежние параметры стандарта C++. Ссылки задач и пути сборки/запуска проверены в 220 JSON-конфигурациях.
- В каждом полном проходе сборки осталось 20 предупреждений, как до изменения настройки консоли: неиспользуемые значения, устаревшие `auto_ptr` и `random_shuffle`, строковый литерал в параметре `char*` урока 139. Ошибок сборки нет.
- Все 24 проверки запуска прошли. Перед основными проверками консоль переключалась на CP866. Прямой запуск урока 113 и примера `String/main2.cpp` установил CP65001 для ввода и вывода и вернул ожидаемые UTF-8-байты.
- Все три варианта урока 118 записывают и читают русский текст в UTF-8 во временных папках. Неверный пункт меню `x` возвращает код 1. Отслеживаемые данные уроков сохранены.
- Задачи корня `Build and Run` и `Run (No Build)` выполнены для восьми разных примеров, включая имя исходника с пробелом, каталог со скобками, `String` и оба проекта с `src/` и `include/`. Обе задачи отдельно выполнены для открытого урока 113, также начиная с CP866.
- GDB остановился на `main()` урока 113, продолжил выполнение и получил нормальное завершение с русским выводом.

Команды задач выполнены с подстановкой переменных VS Code. Нажатия F5/Ctrl+F5 в интерфейсе редактора автоматически не проверялись; сценарий прямого запуска `.exe`, который использует Ctrl+F5, проверен из консоли с исходной кодировкой CP866. Тесты ввода использовали подготовленные UTF-8-данные через стандартный ввод.

Локальных дистрибутивов WSL нет, поэтому текущая редакция повторно не собиралась и не запускалась на Linux. Предыдущие Linux-результаты описаны в [linux-check.md](linux-check.md); широкий вариант урока 118 сохранён побайтно.

Подробные локальные команды и результаты находятся в игнорируемом `build/native-console-20261028/`.
